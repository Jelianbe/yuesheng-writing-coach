# 安全与隐私

## 我们做了什么

### 数据本地化
- 所有用户数据（稿件、诊断记录、学习画像）都存在你本地手机的 SQLite 数据库里
- 不上传任何数据到我们的服务器——我们没有服务器

### BYOK（自带 Key）
- API Key 存在你本地手机的加密存储里（Android Keystore）
- 我们不中转、不存储、不查看你的 API Key
- 你直接用自己的 Key 调大模型提供商的接口

### 隐私设计
- 稿件内容只有在你主动调 AI 的时候才会发给对应的模型提供商
- 我们看不到你的稿件、你的对话、你的诊断记录

---

## 我们防范什么

| 威胁 | 防范措施 |
|---|---|
| API Key 泄露 | 存在 Android Keystore 加密存储，不硬编码在代码里 |
| 数据被第三方窃取 | 所有数据本地存储，不上传服务器 |
| Prompt 注入攻击 | 系统提示词里有边界声明，用户消息不构成指令 |
| 依赖包漏洞 | 定期更新依赖，CI 跑安全扫描 |

---

## 我们不防范什么

| 威胁 | 为什么不防范 |
|---|---|
| 手机被物理拿到 | 这是手机系统的责任，不是 app 的责任。你应该给手机设锁屏密码 |
| 大模型提供商泄露数据 | 这是模型提供商的责任。你应该选你信任的提供商 |
| 你自己把 API Key 告诉别人 | 这是用户自己的责任 |
| 中间人攻击（HTTPS 被破解） | 理论上存在，但概率极低。所有 API 调用都是 HTTPS |

## 常见问题

**Q：我可以验证 app 真的不上传数据吗？**
A：可以。源码完全开源，你可以自己审。或者用抓包工具看 app 的网络请求——除了你主动调的大模型 API，没有其他请求。

**Q：API Key 存在哪里？安全吗？**
A：存在 Android Keystore 里——这是 Android 系统提供的硬件级加密存储，和银行 App 存密码用的是同一套机制。

**Q：我可以离线用吗？**
A：可以写、可以看历史记录，但调 AI 诊断/教学需要联网。
