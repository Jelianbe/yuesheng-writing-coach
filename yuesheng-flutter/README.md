# 月笙写作教练

> AI 驱动的中文小说写作辅导工具 · **写作教练，不是写作助手**

**定位**：不替你写句子，也不替你做创作决策——通过诊断 → 教学 → 训练 → 复盘的闭环，帮你识别写作中的系统性问题并提供针对性训练。

---

## 核心能力

- **五阶段教学状态机**：从入门到独立写作，循序渐进引导
- **诊断引擎**：分析你的写作片段，识别问题并给出针对性建议
- **五步训练法**：解说 → 举例 → 确认 → 尝试 → 反馈，不是看完就忘
- **能力画像**：基于你的写作历史，自动追踪进步轨迹
- **多模型支持**：接入 DeepSeek / Kimi / 智谱 / 豆包等主流大模型
- **隐私优先**：所有数据都存在你本地手机里，不上传服务器

---

## 快速上手

### 第一步：配置 API Key

1. 打开 app → 进入「设置」
2. 点击「添加账号」
3. 选择模型提供商（推荐 DeepSeek，性价比最高）
4. 粘贴你的 API Key（点右边的粘贴按钮可以直接从剪贴板粘贴）
5. 完成！

### 第二步：导入你的作品

1. 回到首页 → 点击「新建作品」
2. 选择「导入作品」
3. 选择本地的 txt 或 md 文件
4. 自动分章完成，开始写作！

### 第三步：开始对话

1. 点击「开始写作」进入对话
2. 把你写的片段发给 AI
3. AI 会诊断问题、给出教学、安排训练

## 常见问题

**Q：为什么要自己配 API Key？**
A：我们不做中转、不赚差价。你直接用自己的 Key 调大模型，数据更安全，成本也更低。

**Q：支持哪些模型？**
A：所有 OpenAI 兼容接口的模型都支持——DeepSeek、Kimi、智谱、豆包、通义千问等。

**Q：我的稿件会上传吗？**
A：不会。所有数据都存在你本地手机里，只有你主动调 AI 的时候才会把内容发给对应的模型提供商。
