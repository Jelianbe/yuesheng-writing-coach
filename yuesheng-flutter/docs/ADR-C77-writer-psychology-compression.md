# ADR-C77 · 消融 B2：writer-psychology 话术密度压缩 + L3 死文字清理

- **状态**：Accepted（2026-09-05，舰长「继续」授权；消融方案 B2 项）
- **类型**：Skill 注入内容变更（writer-psychology，L2 beginner + training 组）+ L3 死文字删除

## 1. 两项内容

### B2 · writer-psychology（5,591 → 预期 ≈4,100）

六障碍的「教练应对」当前为 4 步 × 引号话术示例，话术占该 skill 约 50% 篇幅，
且按 E.3 裁决第 6 级（示例话术 = 最低优先级）本就不可照念。压缩规则：

- **保留**：障碍信号（4 条/个）、「一种常见的可能 + 注意——不是诊断，要确认只能问」
  免责句（防贴标签关键，逐字不动）、每步的**方法本身**（如「十分钟限时写」「写完后
  不准删」「每天打开文档写一句话」）、信号清单全表、态度档位表、休息一下节；
- **压缩**：每步话术从「完整台词引用」改为「方法 + 一句意图」；每障碍至多保留
  1 条方法性引文（删纯语气示例）；
- **不碰**：信号清单「这张表怎么用 / 为什么这一版不写障碍名称」两段（防贴标签
  的元规则）。

### 死文字清理 · syndrome_kb_content

「### 写作技巧提示（技法库）」尾部节的「完整技法库见 SKILL-technique-library
（T001-T031，P2+ 加载）」——该 skill 不在任何 L2 组（V4.9 已证尾部节本身也不进
注入），属**永不生效的死文字**，删除该句（映射表与「引用技法名称即可」保留——
它们同样不进注入，但作为文档结构保留，零行为）。

## 2. 验收

1. 护栏：六个「不是诊断。要确认只能问」类免责句逐一在位（计数断言）；信号清单表、
   态度档位表、休息节在位；死句消失；
2. 锚点：writer-psychology 负漂移（diagnosis×2 + training×1 case 求和归因）；
   kb_content 所在 skill 微漂移；l3Inject 零变化（尾部本就不在注入）；
3. 行为采样：新增挫败场景（"写了三版都不满意，我是不是不适合写作"）×2——判据：
   不贴心理标签、不编数据、接住情绪后接回写作；
4. 六道门禁全绿。
