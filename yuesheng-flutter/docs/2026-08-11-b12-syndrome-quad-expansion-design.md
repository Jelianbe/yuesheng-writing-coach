# 设计稿：四症候扩容 P035-P038 — 叙事效率与结构硬伤（b12）

> 批次 40-44 · 2026-08-11
> 目的：①延续 D9「症候整体扩展」方向，补齐行业高频叙事硬伤缺口 ②继续用《症候增删操作手册》（b9 真源化 + b11 退役 + token 预算机制）验证的流程逐批落地

## 一、背景与选题依据

行业参考（番茄作家训练营高频雷点 / 网文编辑开放日 / 百万字长篇崩盘避坑）显示，现有 32 症候之外仍有四类高频问题无覆盖：

| 缺口 | 行业高频表现 | 现有症候覆盖情况 |
|---|---|---|
| **对话注水** | 寒暄、客套、重复确认、废话解释、明知故问；「用大量对话交代剧情、解释设定，看似推进实则注水」；对白缺乏叙事功能 | ⚠️ P011 覆盖「对话无表现力」（无潜台词/无动作/无区分度），但**信息密度维度**（灌水不推进剧情）无覆盖 |
| **流水账叙述** | 「起床—吃饭—上班—遇事」平铺直叙毫无张力；「写到几万字还在铺垫背景，有效剧情没多少」 | ⚠️ P006 覆盖「停滞无事件」、P021 覆盖「关键事件被概括」，但**事件多而平铺、无冲突聚焦**无覆盖 |
| **心理内耗** | 「冲突结束后大段内心复盘感慨→冗余注水」「反复纠结、自我怀疑、复盘过往、无进展内耗」 | ⚠️ P003（情绪词告知）、P019（情感失真）、P008（词藻堆砌）均非「内心独白篇幅失控」专项 |
| **支线涣散** | 「坑4 支线跑偏：写着写着被某个有趣的配角带跑，主要剧情反而被搁置」「为凑字数加无关日常、无关配角碎戏→主线涣散」 | ⚠️ P034 覆盖「配角无性格」（人物维度），但**剧情线不服务主线**（结构维度，连载级）无覆盖 |

本批同时验证：扩容到 36 症候后 token 占用是否仍可控（体检结论：L2/L3 与症候数无关，L3 单症候平均 ~418 tokens，预算闸门兜底）。

## 三、差异化与重叠优先级（登记进手册重叠规则表）

| 症候 | 差异化边界 | 重叠优先级 |
|---|---|---|
| P035 vs P011 | P011 对话无表现力（无潜台词/动作/区分度）；P035 对话无信息量（寒暄灌水不推进剧情） | **P011 优先**（表现力是对话质量基础，L1 < L2） |
| P035 vs P004 | P004 叙述层设定灌输；P035 对话层信息冗余 | **P004 优先**（设定交代方式先修） |

## 五、手册段 / 训练段写作要点

### 手册段（症候库 `### P0XX`，每症候一组）

统一结构：`> **position_sensitivity**: <值>` + 核心问题 / 触发信号 / 判断原则 / 严重度判断 L1-L3 / 例外情况 / few-shot 锚点（✅ 命中 + ❌ 未命中各 ≥1 例）/ 推荐教学动作（首选 = actions[0]）。

各症候 few-shot 锚点方向：
- **P035**：✅ 「你来了。」「嗯。」「怎么这么晚？」「路上有事。」（寒暄客套无信息增量）；❌ 对话每句推进剧情/升级矛盾/暴露人设（不算注水）；✅ 大段对话解释世界观设定（对话层灌设定）
- **P036**：✅ 起床—洗漱—上班—遇事，按时间全平铺；❌ 重点场景展开、过渡一句带过（有详略）；✅ 十件事九件平均写（无冲突聚焦）
- **P037**：✅ 冲突结束后大段内心复盘「我是不是不该…万一…可是…」；❌ 纠结后用动作/决策推进（有进展）；✅ 每章固定两段无进展内心独白
- **P038**：✅ 配角支线写了三章与主线无关的日常；❌ 支线埋了主线伏笔/丰富主角人设（有意义）；✅ 主线危机在即，作者去写支线恋爱情节

### 训练段（训练库 `## P0XX`，每症候一组）

统一结构：核心本质 / 教学要点（AI 自主选择展开）/ 常见误区 / 严重度判断参考 / 素材库（锚点式练习起点）。写作风格对齐现有 P028-P034 训练段。

## 七、风险与边界

- **训练段/手册段遗漏**：四库 #2/#3 直接拦截（漏写 `### P0XX`/`## P0XX` 会红）。
- **重叠优先级过度设计**：只登记 10 对（其中 3 对进 #8），不追求穷举。
- **token 影响**：L2 索引与症候数无关（体检已验证）；L3 单症候详情平均 ~418 tokens，36 症候后仍按 focus 检索注入 1 条，预算闸门兜底（批次 44 复测）。
- **不触碰**：P001/P002 历史、技法/动作库本体定义、b9/b11 已建派生函数、预算闸门逻辑。
- **ID 顺序**：P035-P038 连续递增，注册表按 ID 升序。
