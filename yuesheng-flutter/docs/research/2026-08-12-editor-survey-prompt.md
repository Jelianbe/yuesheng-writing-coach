# 市面小说写作软件「写作部分」调查提示词 — 可委托文档

**日期**：2026-08-12
**用途**：将本提示词原文复制给受托 AI，由其独立完成市面小说写作软件的写作部分调研，产出可与 [2026-08-12-editor-current-state.md](2026-08-12-editor-current-state.md) 对照的详报。
**背景基线**：我方编辑器当前只做「单章纯文本编辑 + AI 教练面板」，真人创作侧的章节树/大纲/目标/灵感记录/素材库等接近空白。本次调查目的是**向真人创作者用的小说写作软件取经，补齐写作部分的功能与布局**。

---

## 调查提示词（可直接复制）

你是一位小说写作工具的产品研究专家。请对市面上的**小说写作软件**做一次深度调研，聚焦它们「写作部分」的功能与界面布局。本次调研**只关注面向真人创作者的写作工具能力**，**明确排除**「AI 写小说 / AI 续写 / AI 生成剧情」类产品（如 ChatGPT 套壳写作、AI 自动生成小说工具），因为我们要学的不是 AI 代写，而是真人写作时的效率工具。

### 一、调研目标

回答三个问题：
1. 主流小说写作软件的「写作编辑器」界面长什么样、由哪些功能模块组成、如何布局？
2. 真人创作者在码字全流程（规划 → 写 → 改 → 管理）中最常用的功能有哪些？
3. 有哪些功能是「行业标配」（多数软件都有），哪些是「差异化亮点」（个别软件独有）？

### 二、调研范围（建议名单，可增补）

国内：起点作家助手、橙瓜码字、番茄作家助手、小黑屋云写作、壹写作、云上写作、纯纯写作、墨者写作、码字精灵、云庐。
国外：Scrivener、Ulysses、iA Writer、Novlr、Wavemaker（可放宽为「专业写作软件」维度）。

### 三、每款软件必须覆盖的维度

请对每款软件按以下固定维度输出（能查到的写，查不到标注「未知」）：

1. **编辑器布局**：写作区占据屏幕比例；工具栏（顶部/侧边/浮动）内容；正文区是否有段落/大纲/章节导航；背景/护眼设置入口。
2. **章节管理**：是否有卷-章两级目录；目录是否常驻侧栏；在写作页内能否新建/重排/跳转章节；章节卡片展示什么信息（字数/更新时间/状态）。
3. **大纲能力**：是否有大纲编辑/查看；大纲与正文是否同屏可见（边写边看）；大纲类型（文字大纲/卡片式/思维导图/软木塞）。
4. **灵感与素材**：灵感随笔/便签入口位置；素材库（人物/世界观/设定/资料）如何挂载到写作页；是否支持边写边查。
5. **目标与节奏**：目标字数设置；进度显示方式；番茄钟/专注/强制锁定；写作统计（码字速度/日字数/连续天数）。
6. **数据安全**：自动保存频率；版本回溯/时光机；本地+云端双备份；回收站。
7. **修订工具**：查找替换；错别字校对；敏感词检测；一键排版；导出格式。
8. **起名/随机工具**：人名/地名/功法等生成入口（规则型工具）。
9. **AI 相关**（仅记录有则写）：如果该软件带 AI 辅助，AI 入口如何布局（侧栏/浮层/不遮挡正文？），AI 功能与真人写作如何衔接——重点观察**是否遮挡正文**。

### 四、输出格式要求

1. **每款软件一张「信息卡」**：名称 + 一句话定位 + 上面 9 个维度的填写 + 2-3 张布局文字化描述（从上到下/从左到右描述界面结构，如「顶部章节树侧栏 240px，中间正文，右侧人物卡浮层」）+ 1 个「最值得学」亮点。
2. **横向对比表**：行 = 功能项（章节树/大纲/目标字数/番茄钟/灵感随笔/素材库/时光机/校对/查找替换/导出/起名/统计），列 = 软件，单元格 = ✅/⚠️/❌。
3. **行业标配清单**：≥60% 软件都有的功能列为「标配」，标注最简实现方式。
4. **差异化亮点清单**：≤30% 软件独有的功能列为「亮点」，说明为什么值得借鉴。
5. **给「轻量单章编辑器」产品的借鉴建议**：假如我们是一个只有「纯文本编辑器 + 无左侧栏 + 移动优先」的产品，按性价比排序，建议先补哪 8 个功能，并给出每个功能的极简交互方案（入口位置 + 布局 + 交互）。

### 五、信息源与可信度要求

- 优先：真机/客户端实测截图或录屏；其次官网/应用商店官方介绍；再次测评文章。
- 每条关键结论标注来源类型（实测/官网/测评/社区），避免把宣传话术当功能。
- 若某功能存在争议（如「时光机」实现方式），注明差异。
- 输出为中文 Markdown 文档，控制在 4000-8000 字，信息卡与表格优先，少废话。

### 六、交付物

一份 Markdown 文档，文件名建议 `editor-survey-report.md`，包含：调研范围说明 → 每款软件信息卡 → 横向对比表 → 标配/亮点清单 → 给我们的借鉴建议（8 个功能 + 极简交互方案）。
