## 第四层 · 专项（按上下文选用）

### DB / drift 专项

- [ ] schema 变更是否写了迁移？生成文件 `database.g.dart` 未手改
- [ ] 可能为空的查询是否用 `getSingleOrNull` 而非 `getSingle`？
- [ ] DB 中 JSON 字段的解析失败是否有降级 + 留痕？
- [ ] 迁移是否可逆 / 有回退方案？（R-006）

### Widget / UI 专项

- [ ] 样式是否走令牌，无裸 `fontSize` / `fontWeight` / `Color(0x...)`？
- [ ] 是否引入新的全局可变状态？（应经 Provider）
- [ ] 涉及动画 / `pumpAndSettle` 的测试是否稳定？
- [ ] 是否有超长 build 方法（函数 ≤50 行）？

### Skill / Prompt 专项

- [ ] Skill 内容改动是否经锚点比对，漂移已人工复查？
- [ ] 是否存在与既有 Skill 的重复注入？（如 `feedback-cognition` 与 `coaching-rhythm §五`）
- [ ] 新增 Skill 是否注册进 `skill_registry.dart`？
- [ ] A 类纯常量知识库用 part 拆分是否属豁免范围（无逻辑、无 override）？

## 与自动化门禁的分工

| 手段 | 覆盖 |
|:--|:--|
| `dart format` | 格式 |

| `check_circular.py` | P0-5 循环依赖 |
| `flutter test` | 行为回归 |
