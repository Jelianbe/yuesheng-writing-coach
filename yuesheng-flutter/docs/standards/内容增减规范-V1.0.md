## 一、适用范围与动作时机

**谁**：任何向四类内容组件新增 / 修改内容的改动（AI 会话或人工）。
**何时**：落笔前填头（防「写的时候没被问到」），提交前过一遍 §四 自查清单。
**不适用**：纯注释 / 纯文档改动；R-019 行数清偿等不触及内容语义的机械改动。

## 二、与《症候增删操作手册》的关系（S2：引用式并入，不复制）

**防 E 类（副本漂移）从规范自己做起**：本规范**不复制**手册内容，只做分工约定——

- 症候 / 技法 / 索引的**增删步骤**（注册表记录、手册段、训练段、退役机制、自动派生表）
  → **以手册为唯一细则**，手册更新不受本规范转正影响；
- 任何知识库条目在走手册步骤之外，**仍需按本规范 §三 填元数据头**（手册管「怎么改对
  结构」，本规范管「改之前问过自己没有」）；
- 手册头部已挂反向链接指向本规范，双头入口就此打通。

## 三、元数据头（S1 核心）

### 3.1 存放约定（使机检成为可能）

元数据头写在**内容常量上方的 Dart 注释**里（`//` 行注释，随内容同文件同 commit）：

```dart
// ### <内容ID> · <一句话职责>
// | 字段 | 值 |
// |:--|:--|
// | 归属组件 | 教学 |
// | 加载范围 | P1_PRACTICE_LOOP，仅 beginner_yuesheng / beginner_doubao |
// | 依赖数据 | 无 |
// | 数据缺失兜底 | 无依赖 |
// | 引用目标 | §三（P1 阶段加载，P0 档不可见属正常） |
// | 冲突与优先级 | 与 l1_core_p1:185 跳级规则冲突时以本条为准 |
// | 副本登记 | V-05 #8（beginner_p3:51） |
// | 示例标注 | 无示例 |
// | 校验方式 | coaching_rhythm_phase_slice_test 护栏 + 扫描器 ref-integrity |
final String kSomeTeachingContent = '''...''';
```

**为什么放注释**：① 注释不进入模型输入（V4.13 口径：锚定生效位置——prompt 字符串
里的内容才是生效内容，头是给作者和扫描器看的）；② 与内容同文件同 diff，改 A 忘 B
的概率最低；③ 扫描器可按行解析，无需第二份登记文件。

### 3.2 九个必填字段

与前身文档一致的 9 字段：**归属组件 / 加载范围 / 依赖数据 / 数据缺失兜底 / 引用目标 /
冲突与优先级 / 副本登记 / 示例标注 / 校验方式**。所有字段必填，无内容写「无」——
留空等于没检查。各字段的防缺陷映射（A~F 类）见前身文档 §三，此处不重复。

### 3.3 机检（S4）

`python scripts/check_content_metadata.py` —— advisory 巡检：

- 扫描内容分片（`skills_*.dart` / `*_knowledge_base.dart` / `progressive_diagnosis.dart`
  等内容常量文件）中的元数据头，**有头才校验**（9 字段齐全、无空值占位）；
- **存量内容无头 = 零命中**（存量豁免，同门禁 5 止血模式逻辑——只管新增，不追溯存量）；
- 默认 advisory：报告问题但退出码 0，不拦提交；`--strict` 时问题即退出码 1（留给
  晋升硬卡口后接门禁用）；
- `--file <path>` 支持单文件扫描（脚本自身的变异验证即由此完成，不污染 `lib/`）。

每次改完 `skills_*.dart` 建议顺手跑一遍（与 `skill_consistency_scan.py` 并列）。

## 四、提交前自查清单（人工层，立即生效）

继承前身文档八条并更新门禁口径（四道 → 六道）：

1. **标识符存在性**：阶段名 / 枚举取值 / 章节号 / 报告编号——引用的每一个都要能 grep 到本体。
2. **跨档引用自含**：内容按阶段裁剪时，引用另一档章节必须写明「该章节在 X 阶段才加载，当前看不到属正常」。
3. **数据兜底**：提到任何运行时数据，同段内必须给「数据没有时怎么办」（成熟范式：`skills_l1_core_p3.dart:56` / `:62`）。
4. **数值须有来源**：示例数字必须标注为示例值，并说明真实输出要有数据支撑。
5. **冲突显式裁决**：与既有条款冲突时写明「与 §X 冲突时以 §X 为准」（B-22 家族四次教训：不写，模型随机裁）。
6. **副本同步**：改前查 `docs/standards/V-05-受控副本登记表.md`，改后跑 `python scripts/skill_consistency_scan.py` 复核 copy-drift。
7. **门禁**：六道门禁（R-027，`bash scripts/gate.sh`）+ 锚点快照 diff 逐键核对 + 码元分档自洽验证。
8. **护栏测试**：每修一条缺陷，就地加一个断言防止复发。
