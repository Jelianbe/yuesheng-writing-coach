## 〇、一句话结论

**你担心的"内容不全、承担不了教学功能"——从内容库存看基本不成立：39 个症候、31 个技法、16 个动作、训练知识五要素全部齐全，few-shot 误判反例 39/39 全覆盖，后加的症候反而更厚。真正的问题不在"内容不够"，而在两个地方：① "库存与货架脱节"——注册表扩容了、手写展示层没跟上（AI 会拿到矛盾/泛化指令）；② "几个货架是空的"——功能规划存在真实纰漏（阶段总结卡永远收不到、态度升降档大半是死代码、两类指令无数据源只能靠 LLM 编造）。**

### 2. 能不能承担教学功能？——**核心闭环能，但"沉淀与展示"端有真实断点**

教学五环节（诊断→沉淀→训练→评估→迁移）**每一环都有真实注入给 LLM 的指令，无空环节**；态度三档、N0-N4、训练执行框架（四条底线/轮次上限/降级阶梯/评估三档/强制收尾"改前改后对比"）、token 预算表 + 运行时闸门都在。

但**消费侧有断点**（见 §二 🔴）：阶段总结卡/诊断失败卡/部分认同卡 UI 接好了、生产者没接；同侪感、技法熟练度两类指令无数据源。所以"会教，但有些该沉淀展示的东西出不来看不到"。

### 3. 功能规划有没有纰漏？——**有，主要在"文档宣称 vs 实际"和"消费侧闭环"**

见 §二。最典型：态度三档文档宣称"负反馈降档/正反馈升档/安全词无条件降档"，实际代码层检测函数是死代码，这套规则大半失效——这正是 RN 版 A9 教训（文档宣称与默认行为脱节）在 Flutter 版的复现。

## 二、🔴 功能规划纰漏（最该修，主会话已亲自验证）

1. **三卡"有 UI 无生产者"**——`message_card_service.dart:518/543/560` 的 `insertPartialAgreementCard / insertPhaseSummaryCard / insertDiagnosisFailedCard` 全库零调用点，但 dispatcher 已按 `phase_summary / partial_agreement / diagnosis_failed` 渲染、chat_page 回调已接好。**学员对话中永远收不到这三类卡片**。待办清单 L608/L633 自己承认"三卡消息当前仍无生产者"。
2. **同侪感指令无数据源**——`skill_registry.dart:2622-2642` 指示 AI 输出"这个进度比很多学员都快""大多数人需要练 3-5 次"，但单机单学员架构下**无任何群体统计代码**，LLM 只能编造群体对比。
3. **P3/P4 技法熟练度 gating 无数据**——`skill_registry.dart:5248-5303` 用"技法熟练度 ≥60%/≥80%"做模板选择与 P2→P3 迁移条件，但代码只跟踪**学员整体 proficiency** 和**症候级 FSM**，**无技法级（T001-T031）熟练度数据**。
4. **态度升降档规则大半是死代码**——`shared_constants.dart:266/278` 的 `isSafetyWordRequest / containsNegativeFeedback` 全库无调用；`suggestAttitudeAdjustment` 唯一调用点（`chat_attitude.dart:59`）不传正/负反馈计数（恒 0），`attitude_advisor.dart:74-77` 的升降档分支永不触发。文档宣称的"负反馈降档/正反馈升档/安全词降档"实际只剩 severity 阈值一条路径 + LLM 自觉。

## 七、教学逻辑专项评估（教学机/训练机能否支撑教学行为）

> 评估方法：第一手通读运行时真正注入的三块核心——`syndrome_skill_levels.dart`（介入级别）、`skill_registry.dart` training-loop-v2（训练循环）、coaching-actions-v2（16 个教学动作）。

### 7.1 结论先行

**逻辑底子成熟且专业，足以支撑教学；但运行层有 6 个断点会让"纸面成熟"打折扣，其中态度升降档死代码最伤实际教学体验。**

### 7.2 底子是站得住的（不是纸面功夫）

1. **介入级别 = 教育学"渐进式责任转移"（Gradual Release of Responsibility）**：`syndrome_skill_levels.dart:83-149` 的 `interventionLevelForTrainingCount` 是完整的脚手架机制——0-1 次→I do（示范）→ 2-3 次→We do（标注引导）→ ≥4 次→You do（独立），并叠加双向修正（复发/L3 强制回退 I do、连续 3 次未达标强制回 I do、全通过提前升档），规则顺序 `D3 > G1 > G2 > G3 > 基础档 > G4 > G5` 明确。**"什么时候该扶、什么时候该放手"是算清楚的，不是拍脑袋。**
2. **训练循环四条底线 = 好教学标准动作**：练习锚定学员原文（不用通用例句）、一次只练一个点、给完成标准、按实时反应调整；评估顺序"学员自评 → 改前改后对比 → AI 评估"（自评在前，练元认知）；未达标不判失败、换方式重新引导；超限先"降维干预"再挂起。
3. **16 个教学动作是真干预，不是空标签**：A003 五问法（谁在/发生了什么/为什么/接下来/读者在等什么）、A006 感官全开（五感各写一细节、禁用情绪词）、A013 情节复盘（"因为…所以…"链找巧合）、A016 高频词清扫（区分意图性重复 vs 无意识重复）——每个都可执行、锚定学员文本。

### 7.3 运行层断点（削弱实际教学行为）

| 断点 | 对教学行为的伤害 |
|---|---|
| 态度升降档死代码（B4） | 教练该温柔不温柔、该严格不严格——负反馈降档/安全词降档全失效，只剩 LLM 自觉，**最伤体验** |
| 动作"适用症候"13/16 与注册表脱节（B6） | AI 拿到两套矛盾信息，可能给症候选错动作 |
| 三卡无生产者（B1） | 学员练完收不到阶段总结，阶段性反馈缺失 |
| 同侪感话术无数据源（B2） | 虚假鼓励（"你比大多数学员快"是编的） |
| 技法熟练度无数据（B3） | P3/P4"熟练度≥60%"门槛形同虚设，AI 只能跳过 |
| 新症候训练模板走兜底（B5） | P021-P041 训练时拿泛化框架而非定制锚点，质量参差 |

### 7.4 一个"伪问题"澄清

审计把"v1 富话术版永不加载"列为问题，但**这符合宪法 §一设计原则**（"内容做锚点与边界，不给 AI 大段照念话术"）。v2 做成"方法目录（适用+方法）"而非"话术库"是**对的选择**，大模型有能力自主组织话术。真正要改的是《资产清单》§四"含教练话术/练习模板"的过时描述，不是把 v1 话术版加载回来。
