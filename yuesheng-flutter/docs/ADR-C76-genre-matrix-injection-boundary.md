# ADR-C76 · B1 修复：genre-guide 体裁技法矩阵的注入边界自含化

- **状态**：Accepted（2026-09-05，舰长「继续」授权；消融方案 B1 项）
- **类型**：Skill 注入内容变更（genre-guide，L2 diagnosis + advanced 组）
- **来源**：`docs/plans/prompt减法批次-消融实验方案-2026-09-05.md` B1 查证
  （2026-09-05 升级为「悬空引导」）。

## 1. 问题

genre-guide §三「体裁×症候→技法」矩阵推荐 P003→T003/T005/T008、P006→T019/T027、
P011→T006/T007/T023，而：

1. **L3 注入**（`getTechniquesBySyndrome`）只取注册表映射的**前两个**技法全文——
   与矩阵推荐**零交集**（P003 注册表是 T001/T002/T020/T031）；
2. **technique-library-index**（技法索引）只挂在 **training 组**（`skill_layers.dart:66`）——
   genre-guide 所在的 **diagnosis / advanced 组没有任何技法索引**；
3. 结果：模型照矩阵推荐技法时，既无详情也无索引，只能**凭空编技法内容**
   （C57 悬空引用同族，条件性触发：体裁确认 + 矩阵技法被采用时）。

**连带发现（登记缓修）**：`syndrome_kb_content.dart:149`「完整技法库见
SKILL-technique-library（T001-T031，P2+ 加载）」——该 skill **不在任何 L2 组**，
L3 注入的症候知识里存在一个永远无法兑现的指引。因改它要动 injectL3 锚点，
爆炸半径更大，本 ADR 只登记，另批处理。

## 2. 裁决（C57 修法同款：让引用自含，不删不扩结构）

在 §三 矩阵表后追加「注入边界」段：

- 声明本表与注册表默认映射是**有意分层**（消 D 类误判）；
- 明确未注入时的合法行为：**按技法名字面方法教学，或退回已注入的默认映射技法**；
- 明确禁止行为：**不虚构技法详细步骤、不向学员提及「完整技法库」**。

否决项：注册表加体裁维度（大改 + 动四库一致性测试，收益不成比例）；
把 technique-library-index 加进 diagnosis 组（+900 token/场景，与减法方向相反）。

## 3. 验收

1. 护栏：新增断言（注入边界段存在、三句关键约束在位）；
2. 锚点：genre-guide 漂移仅影响 diagnosis×2 + advanced×2 case，等量归因；
3. 扫描器候选数不新增；
4. 行为采样：本改为**纯增量指引**，无既有场景触达矩阵（无基线可对比），
   以护栏 + 锚点 + 门禁盖章；真机采样待下轮回归补（如实标注）；
5. 六道门禁全绿。
