## 一、背景与裁决

### 1.1 V-05 #11（范例 1 假断言的整改）

规范 V1.0 范例 1 写「副本登记 | V-05 已登记（attitude:36-38 与 beginner_p1:175-177）」，
2026-09-06 收尾批核验：**V-05 现行 10 对中无此条**——「已登记」为未回查登记表的断言
（规范自己要防的 A 类缺陷，作者即规范作者，教训入台账）。

考古修正定性（核实会话 git -S + diff）：范例 1 所指的副本对在写作时点（09-04）**真实
存在过三处**——措辞 1 本体（l1_core_p3）+ attitude-doubao（C55 前已有）+ beginner_p1
灵感缺失段（**C55 `1f24cbf9` 引入**）；**ADR-C77（`179a3dc6`）压密时第三副本随话术
段整段收敛删除**（话术自组替代，合规收敛，非漏改）。范例 1 的错误因此是两层：
「已登记」始终不实 + 未随 C77 收敛更新第二侧。

**裁决**：按现行形态补登 **V-05 #11**（两处：本体 ↔ attitude-doubao 引用式自含），
登记行内记录第三副本的 C77 收敛史（防未来考古误判「漏改删除」）；范例 1 同步更正。

### 1.2 loadWhen 自述过时 ×2（补头照出的说谎自述）

`teaching-modes`（p2:163「loadWhen: P1+ 必加载」）与 `core-product-identity`
（p3:119「loadWhen: P2+ 必加载（P0/P1 不加载）」）的自述与 `skill_layers.dart` 现状
（L1 常驻，9 场景全注入）不符——**在注入字符串内，模型读得到**，beginner_p3 先例
同族。裁决：自述修正为「L1 常驻，全 phase 注入」+ 锚点重生成 + 逐 case 归因。

### 1.3 token_budget 注释过时（「8 项」）

`lib/config/token_budget_table.dart:37` `l1Core = 'L1 核心 skill（8 项）'` 与 :9 注释
「实测 8 项 9323」为过时派生副本（实际 L1 = 9 命名 + 3 attitude）。**裁决：只改注释
文字，不派生 `l1SkillIds.length`**——config 层 import services 层是依赖倒置，不为
消灭一条注释引入反向依赖。

### 1.4 B-2 最小修（P011×P035 掩蔽）——**设计约束显式裁决**

补课批 S-8 实测：纯净寒暄对话 1/3 被判 P011，P035 零命中（掩蔽）。本批**只做**：

- **P011 手册段补镜像消歧句**（与 P035 侧既有消歧句对称——P035 核心问题段已写
  「与 P011（对话无表现力……）不同，P035 是对话信息密度问题」，P011 侧无镜像）。
- **作用域论断（已核实）**：手册段走 V4.9 切片注入（`_extractSyndromeSection` 按
  `### P0XX` 段提取），镜像消歧句只在 **P011 被选为焦点后**的 L3 注入生效——
  **它管不到初始选择面的误选**（S-8 采样中模型在症候清单阶段选 P011 不选 P035，
  发生在 L3 注入之前）。
- **根治方案不在本批**：初始选择面的消歧要动分块/诊断路径的症候清单注入方式
  （注册表派生消歧标注 or 选择性注入），是结构性改动，影响面 = 全部诊断路径，
  **另立 ADR 裁决**。本批镜像句的价值：焦点锁定后的 L3 教学资源里双向消歧完备
  （防选错后持续强化），+ 手册语义完备（B-2 登记的文档层闭环）。
