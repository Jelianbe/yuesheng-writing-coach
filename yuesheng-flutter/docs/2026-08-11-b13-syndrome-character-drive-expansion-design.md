# 设计稿：三症候扩容 P039-P041 — 角色驱动层（b13）

> 批次 45-48 · 2026-08-11
> 目的：①补齐「角色驱动力/动机层」行业高频缺口（内外部证据双向印证）②补 motivationDeficit 类型真空（图谱体检空缺 1）③延续《症候增删操作手册》（b9 真源化 + b11 退役 + b12 四症候流程验证）逐批落地

## 一、背景与选题依据

### 1.1 内部图谱体检空缺（本会话产出）

- **空缺 1（最大）**：注册表 `motivationDeficit` 类型仅 P009 一个，角色目标/欲望/主动性/对手动机维度无独立症候；教学分组「动机/意图缺失型」仅 3 个（P009/P018/P034），且 P018/P034 注册表类型并非 motivationDeficit。
- 冗余/风险记录（不修）：P006 重叠枢纽 9 条、P005/P013 单技法依赖、commercialAppeal 7 症候同质（已靠 position 细分缓解）。

### 1.2 行业研究高频问题（2026-08 编辑拒稿 / 读者弃书实证）

| 缺口 | 行业高频表现 | 现有症候覆盖情况 |
|---|---|---|
| **目标/欲望模糊** | 「主角目标太模糊无法追踪（想变好、找到自己的位置）」「新手爱写'想变强/要复仇'空话」「角色欲望 = 具体目标 + 明确数量 + 截止时间 + 失败代价」「缺乏主要欲望目标，读者会觉得无聊」 | ⚠️ P009 覆盖「行为无动机/换角色剧情依然成立」，但**有动机而目标不具体/无期限无代价**维度无覆盖 |
| **被动主角/木偶式** | 「剧情需要主角去哪就去哪，没有理由、没有顾虑、没有权衡」「主角完全被动，爽点完全偏移，主角变成配角」「上一个目标未成型也未得反馈之前建立新场景新目标」 | ⚠️ P016 覆盖「情节靠巧合」、P009 覆盖「动机缺失」，但**主角不主动决策、被剧情拖着走**维度无覆盖 |
| **降智反派/对手无动机** | 「为坏而坏」「反派全员弱智，放着资源不用非要跟小人物拼命」「高手博弈只为利益和活路——利益冲突到位矛盾自然爆发」 | ❌ 现有 36 症候**零覆盖**对手/反派塑造维度 |

### 1.3 综合结论

内外部双向印证：**角色驱动层（目标/主动性/对手动机）是当前 36 症候最大缺口**。本批 3 症候全部落 `motivationDeficit` 类型，首次将该类型扩到 4 个。

## 三、差异化与重叠优先级（登记进手册重叠规则表）

| 症候 | 差异化边界 | 重叠优先级 |
|---|---|---|
| P039 vs P009 | P009 行为整体无动机（换角色剧情成立）；P039 有动机但目标不具体（想变强但没期限没代价） | **P009 优先**（动机整体缺失更深） |
| P039 vs P040 | P039 目标模糊（欲望本身不清）；P040 目标清但主角不主动（被剧情推） | **P039 优先**（目标立住后主动性自然提升，同族共诊） |
| P040 vs P016 | P016 情节靠巧合推进；P040 主角不主动决策（巧合多往往是被动表现） | **P016 优先**（沿用 P016 vs P009 先例：先修可见的因果链，再挖角色动机） |
| P040 vs P009 | P009 核心角色动机缺失；P040 核心角色不主动 | **P009 优先**（动机整体缺失更深） |
| P041 vs P012 | P012 冲突无分量（结果）；P041 反派无利益动机（根因之一） | **P041 优先**（沿用 P032 vs P012 先例：对手利益到位，张力自然恢复） |
| P041 vs P009 | P009 核心角色动机缺失；P041 对手角色动机缺失 | **P009 优先**（核心角色先于对手） |

四库一致性 #8 的 pairs 保留互斥/根因语义，本批新增 **3 对进 #8**（同构互斥，validation 层防 AI 对同一段重复标注）：P039/P040、P040/P016、P041/P012。其余 3 对（P039/P009、P040/P009、P041/P009）登记进手册即可（优先级关系不硬拦截）。

## 五、手册段 / 训练段写作要点

### 手册段（症候库 `### P0XX`，每症候一组）

统一结构：`> **position_sensitivity**: <值>` + 核心问题 / 触发信号 / 判断原则 / 严重度判断 L1-L3 / 例外情况 / few-shot 锚点（✅ 命中 + ❌ 未命中各 ≥1 例）/ 推荐教学动作（首选 = actions[0]）。

各症候 few-shot 锚点方向：
- **P039**：✅ 「他想变强」（无数量/期限/代价，读者无可期待）；❌ 「他需要 38 万，下周三前到账，否则妹妹的肾移植手术要被划掉」（具体目标+数量+期限+代价）；✅ 开篇立了目标但中段忘记，阶段目标断档（serial 表现）
- **P040**：✅ 剧情需要主角去哪主角就去哪，无权衡无顾虑；❌ 主角面临选择时有自己的考量与代价评估；✅ 被反派设计入局后，主角只是被动挨打等待反转
- **P041**：✅ 反派被怼两句就无脑死磕，放着资源不用非要拼命；❌ 反派有利益动机（夺舍/抢机缘/保命），算计有铺垫；✅ 全篇反派都「为坏而坏」无一个立场站得住

### 训练段（训练库 `## P0XX`，每症候一组）

统一结构：核心本质 / 教学要点（AI 自主选择展开）/ 常见误区 / 严重度判断参考 / 素材库（锚点式练习起点）。写作风格对齐现有 P034-P038 训练段。
