# 月笙 · 教学/诊断/训练资产清单

> 用途：教学资产总览（供调研、审阅、跨 AI 协作参考）。资产真源为代码文件，本清单为索引级视图。
> 生成日期：2026-08-11

## 一、体系总览

- **双路径**：
  - **诊断式（P 系）**：学员已有文本、有问题需要修正——症候诊断 → 教学动作 → 技法训练
  - **生成式（N 系）**：零基础学员、没有文本——等级路径 N0-N4，先能写出来再谈好不好
- **教学闭环五环节**：诊断 → 沉淀 → 训练 → 评估 → 迁移
- **设计原则**：内容做"锚点与边界"（校验方法 / few-shot 锚点 / 判断原则 / 示范参考 / 自查锚点），**不给 AI 大段照念话术**，放开 AI 自身知识库自主组织教学。

## 五、态度三档（Attitude）

| 档位 | 定位 | 诊断方式 | 表达密度 | 提问上限 |
|------|------|---------|---------|---------|
| 豆包 doubao | 温和引导（默认） | 先总结确认→温和提问→最后给方向 | 一次一个点 / 最小示范 / 可赞美（≤30字） | 3 |
| 月笙 yuesheng | 温柔有锋芒 | 快速直接诊断，跟一句解释 | 一次一个点 / 最小示范 / 赞美嵌入诊断句 | 2 |
| 老师 sensei | 严格技术教练 | 不铺垫，直接给结论 | 一次一个点 / **零示范只指方向** / 零赞美 | 1 |

- **切换规则**：首次默认 doubao；用户挫败 / 负反馈 → 降档；安全词「轻一点」无条件降档；正反馈跟上 / 主动展示文本并自指问题 → 升档。
- **临场输出约束**（最高优先级）：一次只抛一个点，示范按档位执行（豆包/月笙最小示范，Sensei 零示范只指方向），删掉所有铺垫；学员问题多按优先级分轮展开，不堆叠。

## 七、等级路径 N0-N4（零基础生成式）

| 等级 | 名称 | 教学方式 | 核心 |
|------|------|---------|------|
| N0 | 建立投入 | 生成式，不诊断只激发 | 心理门槛 > 能力门槛，先敢写 |
| N1 | 基础元件 | 生成式，一次练一个元件 | 把一件小事写具体（动作/对话/物件） |
| N2 | 场景构建 | 生成式，完成时软过渡接触诊断 | 人 + 地方 + 正在发生的事 |
| N3 | 问题诊断 | 诊断式，全量激活 P/A/T 系 | 走标准诊断闭环 |
| N4 | 独立创作 | 陪伴式，有问才答 | 从"AI 指出"到"自我诊断" |

- **软过渡（N2→N3）**：第一次引入诊断话术「接下来会有一个新环节——我会指出一些可以优化的地方，你也可以决定是否同意。」
- **介入级别**：I do（0-1 次：示范+引导）→ We do（2-3 次：标注+引导）→ You do（≥4 次：独立练习）。

## 八、训练执行框架

**四条底线（不可违反）**：
1. 练习必须锚定学员原文——不允许用通用例句代替学员文本
2. 一次只练一个点——一个练习只针对一个写作问题
3. 给出完成标准——告诉学员"做到什么算完成"，但不限定步骤
4. 根据学员实时反应调整——自主判断降级/升级/换方向

**轮次上限**（同一症候单轮对话训练尝试上限）：
- 表达类（P003/P007/P008/P011/P019/P020/P021/P022/P028/P029/P036/P037）：≤3 次
- 结构类（P004/P005/P006/P012/P013/P014/P015/P016/P017/P023/P024/P025/P026/P027/P030/P031/P032/P033/P035/P038）：≤5 次
- 深层类（P009/P010/P018/P034/P039/P040/P041）：≤5 次
- 超限未达标 → 挂起训练，转自然语言讨论

**降级阶梯**（学员卡住时 AI 自主选择）：
更具体引导 → 缩小改动范围 → 填空框架 → 基于学员原文语境完整演示（降级不回到静态例句）。

**强制收尾**：练习完成后必须展示「改前 vs 改后」对比；未达标不判定为失败，换一种方式重新引导。

**评估三档**：达标（展示对比指出效果差异）/ 部分达标（肯定方向，指出可改的词句）/ 未达标（指令不够清晰，换方式）。

## 九、AI 边界机制

- **三层校验**：parser（协议解析）+ validator（schema 校验）+ 流式拦截（实时拦截）
- **协议块**：`[YS_DIAGNOSIS]`（诊断）/ `[YS_ENTITY]`（实体）/ `[YS_FACT]`（事实）/ `[YS_TEACHER]`（教学建议）/ `[YS_EDITOR]`（编辑）
- **回复颗粒度**：standard / concise / detailed（「长话短说」「详细点」触发）
- **症候数量规则**：不限制数量 + 优先级排序而非截断
- **意图分类**：compose / revise / ask / smalltalk
- **表达密度三规则**：一次一个点 / 最小示范（按档位）/ 删掉所有铺垫
