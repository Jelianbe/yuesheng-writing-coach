## 一、方法与局限（先读这个再读结论）

- **导出新鲜性**：临时 flutter test 复用 `kPromptCases` 调 `buildSystemPromptV2`
  现场重导出 13 case，len 与 `test/snapshots/skill_prompt_anchor.json` **逐 case 一致
  （13/13）**——排除 A.12.12 式过期事故及其 C75/C77 变体（台账「采样导出件过期更正」
  的首个强制项，本批即为其补验）。临时脚本已删。
- **多轮模拟方式**：链式场景每轮一个独立采样代理，对话历史（含前轮诊断块）以文件
  拼入「用户消息」，代理只读 system prompt 文件 + 输入文件两个文件，不告知在测什么。
- **模型差异**（同先例）：采样模型为 GLM 系子代理，**不是生产 DeepSeek**。强约束
  结论（协议块有无、枚举、编号泄漏、逐字判据）可信度高；语气节奏类判据只作参考。
- **漂移归因限制**：本轮与旧样品（WALK-B）的注入面同构（teaching-strategy 为 L1
  常驻，C72 与 C77 导出件均含症候类型表），故 §四 B-1 的行为漂移**不能归因于
  C75/C77 内容变更**；子代理模型版本差异亦无法排除。定性为「行为漂移、成因待查」。
- **D 链历史近似**：链历史 T1 轮取 C72-N1_r1 作激活轮回复（原 CHAIN-T1 样品未存档），
  T2/T3 用 CHAIN-T2/T3 原件；三条链历史相同、新采样轮独立。
- 判分规则：同场景 3 采样中预期行为命中 ≥2 → 通过；1/3 → 观察项；0~1/3 且措辞级
  一致 → 失败。

## 三、逐场景判分

### 场景 A · 会话二回归（C71 修复验证）——通过

输入沿用 `input_WALK-A-T1.txt`（「前几天写过三句话练习，今天继续」）。

| r | 衔接行为 | 要求重新自报水平 | 失忆话语 | 块 |
|:--|:--|:--|:--|:--|
| 1 | 直接布置「往细里写」新练习 | 无 | 无 | 无 |
| 2 | 「前几天跟着引导写了几个三句话的小练习」+ 三个方向选择 | 无 | 无 | 无 |
| 3 | 「上次把三句话写完了……玩法换一下」+ 最小块 | 无 | 无 | 有（syndromes 空 + N1_ELEMENTS） |

- **A-1 无需重新自报水平**：3/3。三例均默认掌握「学员在做三句话练习」的上下文
  （beginner-path 随 beginner 组注入可见），无一致问「你写过什么吗」类 N0 激活问题。
- **A-2 对照旧样品**：旧 WALK-A-T1（none_p0_yuesheng = 失忆态）2/2 诚实承认失忆；
  新采样（beginner 组 = C71 继承后的注入态）3/3 直接衔接。**F1 修复的行为面改善成立**
  （该结论以「注入组切换正确反映继承」为前提，App 侧继承代码已由 ADR-C71 测试覆盖）。
- 观察（不计缺陷）：会话二首触 1/3 发最小块（r3 基于学员自述「完成过三句话练习」
  填 N1_ELEMENTS，符合字段说明的推进信号定义；r1/r2 不填亦可解释）。块在此场景
  本就条件性，无一致性要求。

### 场景 B · OC 多轮换轨——部分通过（1 失败项 + 2 通过项）

T1 = `input_WALK-B-OC.txt` 原文；T2 = 出场片段（~270 字，含具体怕黑行为）；
T3 = 按反馈改写的第二稿。

**B-1 · R-009 不代改设定：通过（9/9 轮）**
三链全部轮次的自然语言均守住边界：「设定我不替你改，改出来那就是我的沈知微」/
「帮她改丰满这件事我做不了」/「改哪、怎么改，得你来定」/「是否保留怕黑设定由学员
决定」/「这个选择你来定」。零代拟设定条目。

**B-2 · 换轨到「有文本可诊断」语义：通过（T2、T3 各 3/3）**
T2 起三链全部转向文本级反馈（逐句锚定「揣着小手电，虽然楼道里灯是亮的」「把字条
翻过去扣在桌上」等原文），3/3 suggested_phase 建议推进 P1_WORLD→P2_PRACTICE_LOOP
（迁移信号正确：学员展示写作文本）。

**B-3 · 无过早完整诊断：失败（T1 3/3 违反，见 §四 B-1）**
T1（OC 设定求助、无写作文本）三链全部输出完整症候诊断块（P009 角色空心化 +
P010 OC 平面化，severity L1/L2、evidence 引设定文本、confidence 0.70–0.75）。
对照旧样品 WALK-B-OC_r1/r2 同输入 **0/2 抢诊断**——行为漂移。

**正面发现（P-1）**：跨轮诊断锁定在块通道内正常工作——T2/T3 的块持续跟踪前轮
症候且 severity 随文本进步降级（P009/P010 L2→L1）、措辞出现「保持锁定」「上轮锁定
的动机外置问题明显缓解」「空心化持续缓解」。锁定→跟踪→降级链路首次获得多轮证据。

### 场景 C · 世界观 persona——通过（含 1 观察项）

T1 = 修仙·音乐灵力世界观求助；T2 = 设定草稿（九宗门/七境界/哑女主角）。

- **C-1 narrative-design 引导启动：6/6**。全部轮次以提问引导（「谁说了算」「五音
  不全的人怎么过日子」「哑女靠什么强」「鸣音大会那天她在哪」），从学员既有规则
  内部生长设定。
- **C-2 不代构世界观（7.3 红线）：6/6**。「这两样我不替你定，从别人手里拿来的门派
  是死的」「门派、等级我不替你定」「加什么我不替你列」。
- **C-3 不给「黄金三章」类模板：6/6**。零模板话术，且反向劝阻设定扩张（「先别急着
  加」「等故事需要它们的时候，细节会自己冒出来」）。
- **观察项 O-1**：C_ch3_T2 对设定草稿启动 P039 目标模糊症锁定（teaching_plan.
  current_teaching_focus_id=P039，1/3）；ch1/ch2 明说「尚无文本层面症候可诊断」
  「不启动症候锁定」（2/3）。与 B-1 同族（见 §四）。

### 场景 D · N1→N2→N3 后段链——通过（含 2 观察项）

从 CHAIN-T3 状态续链：T4 = 元件练习 150 字（动作+对话+物件）→ T5 = 场景构建
300 字 → T6 = 问「是不是入门了、接下来学什么」。

- **D-1 N1 完成标志被识别：3/3**。三链都围绕完成标志做判定（「从三句话到150字，
  这一步是你自己往前走的」「到这儿，元件这一关算过了」「你自己报的三样……确实都在」）。
- **D-2 N2 软过渡：3/3**。T5 起三链全部执行软过渡三要素：用学员自己的 N2 文本解释
  诊断功能、给予控制权（「想试就说一声……你选哪头都行」「两条路你挑」）、正向为主
  零症候点名。9 轮块 syndromes 全空、confidence 0.2–0.4 如实标低。
- **D-3 N0–N2 不诊断铁律：守住（9/9 轮）**。全部块 syndromes 空、自然语言零症候名、
  零编号泄漏（自动判分 27/27 佐证）。
- **观察项 O-2 · N1→N2 推进门槛分裂**：beginner-path 的 N1 完成标志为三条量化锚点
  「全部达成即通过」（150 字三元件关联 / **AI 提问后能补感官细节** / 元件分离 ≥3 次）。
  链1/链2（2/3）在 T4 即建议 N2_SCENE——漏判第二完成条件（学员尚未做过「提问后补
  感官细节」）；链3（1/3）按字面留在 N1、先布置补笔再评估。
- **观察项 O-3 · N2→N3 推进时机分裂**：链1 在 T5（轻诊断 3 次尚未发生）即建议
  N3_DIAGNOSE；链2/链3 保持 N2_SCENE。T6 三链均以选择权收尾（继续写 / 开始首次
  轻诊断），无越权全量诊断。另记链3-T6 有轻微语义回退（场景达成后又布置「把几句话
  长成完整小场景」），不影响铁律。

## 四、新发现（登记候选，本轮不修）

### B-1 ·（候选新 C 号）零基础/OC 设定求助场景 3/3 输出完整症候诊断块，违反 §7.3「诊断引擎不启动」

- **规则依据**：§7.3「从零构建模式下，诊断引擎不启动（用户还没有可诊断的内容）」；
  §3.9 撞车裁决第二行「从零构建引导进行中识别出写作问题 → 不附加，把观察揉进引导
  提问里带出」。OC 设定求助（用户在构建角色、尚无写作文本）落在 7.1 适用场景
  （「从世界观/主角/开头开始构建」）内。
- **行为证据**：B-T1 三链 3/3 输出完整诊断块（P009+P010，非最小激活块形态——
  syndromes 非空、含 severity/evidence/root_cause_analysis/teaching_plan）。
- **漂移**：旧样品 WALK-B-OC（C72 后导出件、同输入、注入面同构）0/2 抢诊断。
  C75/C77 未改动相关文本（teaching-strategy 症候类型表两代导出件逐字一致），注入面
  无法解释漂移；子代理模型版本差异待排除。**建议正式归因时先在生产模型复跑本场景。**
- **与 ADR-C72 修复的张力**：C72 给 §3.9 加的「最小激活块」例外（syndromes 空）被
  模型扩张成了「可以发完整块」——例外条款被泛化的形态。
- **影响**：块由系统取走解析，跨轮锁定/阶段迁移会被错误启动；零基础学员在设定期
  被 P 系语义（suggested_phase P1_WORLD）接管，beginner-path 的 N 系推进可能被
  抢占（本轮 B 链内 suggested_beginner_level 全程未出现）。
- **修法方向（供裁决）**：§3.9 撞车裁决第二行补「设定/大纲类文本不算『展示写作
  文本』」的显式判据 + 7.3 增加对块通道的约束句（7.3 目前只约束自然语言侧语义，
  模型把「诊断引擎」理解为自然语言行为，块仍按 §3.9 必附加清单第三条
  「你在对话中识别出了写作问题」输出）。

### 正面发现（回归确认，改的时候不能碰坏）

- **P-1** 跨轮诊断锁定（锁定→severity 跟踪→降级）在多轮块通道内正常工作（B 链）。
- **P-2** C71 修复后场景 A 3/3 无失忆衔接——F1 的行为面改善成立。
- **P-3** C77 压缩后 writer-psychology 骨架完整：本批零心理标签泄漏（自动判分 27/27），
  佐证台账「需重验」项中该子结论可解除。
- **P-4** 软过渡三要素（解释诊断功能用学员文本 / 给控制权 / 正向单观察）3/3 稳定
  执行——N2→N3 教学设计的核心机制首获多轮行为证据。
