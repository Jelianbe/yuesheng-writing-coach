## 四、消融方法论（每族一批）

1. **基线采样**：固定场景包 = `docs/audits/_prompt_dump/after_b8_2026-09-04/samples/`
   全部 20+ 输入（已含 R0 回归 9 场景 + WALK + C72）。每输入 ×3 采样，按既有判分脚本
   （块出现性/枚举合法/编号泄漏/模板句式）+ 语气人工抽检。
2. **消融采样**：删除候选规则 → 重导出 prompt → 同输入同数采样。
3. **等价判据**：判分脚本结果与基线**逐场景同向**（≥2/3）且人工抽检无语气退化 →
   **删**；任一场景出现行为差 → **保留**（或改合并措辞重试一轮）。
4. **越界检查**：锚点漂移必须 = 删除字节数（负等量），skillContent 仅目标 skill 漂移。
5. **每批产物**：一个 commit + 锚点重生成 + 六道门禁 + 台账登记（消融前后字符数、
   等价证据）。**改动的 skill 常量补内容增减规范 V1.0 元数据头**——本批是该规范
   第一次实战检验。
