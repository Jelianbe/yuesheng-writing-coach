# 资源书籍方法论提取

> 从月笙资源参考清单中提到的各本书里，提取与世界观设计、大纲设计、写作锻炼相关的方法论
> 用途：评估哪些方法可以补进月笙体系

---

## 一、《小说课2：偷故事的人》（许荣哲）—— 高优先级

### 1.1 七个问题公式（故事骨架）

完整版（7问）：
1. 主人公的"目标"是什么？
2. 他的"阻碍"是什么？
3. 他如何"努力"？
4. "结果"如何？（通常是不好的结果）
5. 如果结果不理想，有超越努力的"意外"吗？
6. 意外发生，情节如何"转弯"？
7. 最后的"结局"是什么？

简化版公式：**目标→阻碍→努力→结果→意外→转弯→结局**

因果逻辑线：两次"因为，但是，所以"的重复操作。

**与月笙的关系**：
- 简化版（目标→阻碍→努力→结果）已提取进Prompt作为A003备选
- 完整版7问公式比月笙现有五问法多出"意外→转弯→结局"，可以补强A003
- "原罪"概念（把"目标"改为"梦想"，"阻碍"改为"原罪"）更接近心灵层面，适合处理亡妻控/自我感动型用户

### 1.2 两难设计

**封闭式绝境**：情境万分紧急，只有两个选项，不管选哪个都会带来可怕的后遗症。一旦选了其中一个，另一个就会变成噩梦。

**双重的两难**：两难的转换中，第一重和第二重的意义相互影响，有了第二重，第一重的意义变得不一样。

**与月笙的关系**：
- 可以用于A003五问法的进阶——当用户故事缺乏冲突时，引入"两难"概念
- "双重的两难"适合处理感情线+主线并行的故事结构

### 1.3 想象力方法

联系两个极端的东西，经过N次交换：吻→羊；眼泪→宝藏；火柴→爱情；饭粒→王位。

**与月笙的关系**：
- 可以作为A007翻转拆解的灵感来源——把看似无关的东西联系在一起

### 1.4 层次

有层次感的故事，随着故事进展，可以看到一层又一层不同的风景。借由反复问同一个问题，通过剧情发展得到不同答案，来有效深化层次。

**与月笙的关系**：
- 与月笙"闭环设计"（主角发现差异→怀疑→探究→发现更多差异）高度一致
- 可以作为A003/A005的补充理论

### 1.5 其他值得注意的概念

| 概念 | 内容 | 与月笙的关系 |
|------|------|------------|
| 虚构 | 报信者的底层心事——隐瞒了什么不能说的秘密 | 对话潜台词，A004现实锚点 |
| 象征 | 最珍贵的宝藏与最深的恐惧绑在一块 | 角色塑造深度 |
| 好奇心→悬疑 | 利用好奇心制造悬疑推进情节 | 节奏控制 |
| 敌人 | 强大的敌人是激发主人公活力的最佳对手 | A002回归主角的冲突设计 |
| 打赌 | 最简单有效但不负责任的人物动机 | 角色动机设计 |

## 二、《这样写出好故事》（詹姆斯·斯科特·贝尔）—— 低优先级（谨慎使用）

### 2.1 LOCK系统（情节框架）

- **L**ead（主角）：值得追随的主角
- **O**bjective（目标）：目标分为两部分——想取得某样事物，想逃离某样事物
- **C**onfrontation（冲突）：情节冲突
- **K**nockout（冲击结尾）：让人热血的结局

**与月笙的关系**：
- 与月笙A003五问法有重叠（目标、阻碍）
- "想取得/想逃离"的二分法可以补强目标设计
- 月笙不给套路，LOCK作为诊断工具可以用，作为模板不建议推

### 2.2 三幕结构+两扇门

**三幕结构**：
- 开头（1/4）：场景设定、时代背景、调性、说服读者继续读、介绍对手
- 中段（1/2）：冲突、加深角色关系、铺陈最后一战
- 结尾（1/4）：收梗、创造余韵

**两扇门**：
- 第一扇门：主角的一般世界很满足，必须有事把他推过门口
- 第二扇门：从中段进入结尾，必须发生重大线索或重大挫折

**与月笙的关系**：
- 三幕结构是通用知识，月笙不需要教这个
- "两扇门"概念可以用于诊断大纲——用户的大纲是否有"推力"把主角推入故事
- 谨慎使用：月笙不给结构模板

### 2.3 场景四和弦

1. 行动（主和弦）：主角要达成目标，就会行动
2. 反应（主和弦）：主角碰上事情所产生的情绪反应
3. 铺陈（辅助和弦）：让随后的场景更合理
4. 深化（辅助和弦）：像在食物中加调料

**场景三要素**：引子、紧张程度、推手

**与月笙的关系**：
- "行动→反应"交替与月笙"刺激和反应"概念一致
- "每个场景都要出人意料"可以用于诊断节奏停滞（P006）
- 强化场景的三种方法：晚进入、早离开、制造惊喜

### 2.4 对话技巧

- 行动中的对话（对话融入行动）
- 善用破折号
- 别给对话贴太多标签
- 语气和风格一致性

**与月笙的关系**：
- "行动中的对话"与月笙A004现实锚点一致
- 可以作为训练任务的补充素材

### 2.5 情节头脑风暴20法

包括：如果、书名、列表、议题、亲眼去看、亲耳去听、角色优先、向大师取经、推翻类型、预测趋势、报纸挖宝、研究、"其实我真正想写"、偏执、开场白、写序章、联想图、感动人心的结尾、职业、绝望。

**与月笙的关系**：
- "角色优先"与月笙A002回归主角一致
- "其实我真正想写"（写10分钟热身）适合处理写作障碍
- 整体偏"灵感激发"，月笙更偏"诊断根因"，谨慎使用

### 2.6 情节模式

远征、复仇、爱情、冒险、追逐、永不妥协、遗世独立、权力、寓言。

**与月笙的关系**：
- 月笙不给套路，不推荐作为教学工具
- 可以作为诊断参考（识别用户的故事属于哪种模式）

## 三、《小说写作工具箱》（詹姆斯·斯科特·贝尔）—— 中优先级（提及式）

### 3.1 目录结构（125个技巧分类）

| 类别 | 技巧数量 | 与月笙相关的内容 |
|------|---------|----------------|
| 情节和结构 | ~15个 | 情节生成过程、让主人公拒绝冒险、渴望与创伤、构思结局、次要情节 |
| 人物 | ~12个 | 情绪和态度、令人刻骨铭心的人物、内心冲突、给人物一个梦想、让人物有个性 |
| 场景 | ~15个 | 刺激和反应、三种类型的开头、闪回、打斗场面、强化场景的三种方法 |
| 对话 | ~8个 | 行动中的对话、善用破折号、别贴太多标签、语气和风格 |
| 语气和风格 | ~10个 | 眼睛说明了一切、形容词、新鲜的细节、新鲜的俗套、多余的词 |
| 修订 | ~10个 | 修订清单、系统性的修改 |
| 作家心态 | ~10个 | 相信你是一个作家、克服写作障碍、成功作家的七个习惯 |

### 3.2 重点技巧提取

**人物塑造**：
- 写场景前预想两件事：人物面对这个场景会如何反应 + 给人物加入颜色（态度和情绪）
- 内心冲突：人物内在矛盾比外在冲突更有深度
- 成长的人物：人物弧线描述角色的内心发展

**场景搭建**：
- 三种类型的开头
- "把平凡的一天搞砸"——在开头制造突发事件打破日常
- 晚进入、早离开
- 每个场景都要出人意料
- 按照场景而不是章节来思考

**闪回技巧**：
- 必须有必要性
- 要使场景紧凑又充满冲突
- 在当下场景加入强烈刺激感官的细节

**打斗场面**：
- 具体技巧（需阅读原文，网上信息有限）

**细节描写**：
- 新鲜的细节（避免陈词滥调）
- 眼睛说明了一切（通过眼神传达情绪）

**与月笙的关系**：
- 125个技巧太多，不适合全部整合
- 可以按需提取：当用户需要具体技巧训练时提及
- 重点可提取的：场景搭建方法、人物情绪预想法、闪回技巧

## 四、《小说写作：叙事技巧指南》—— 低优先级（仅提取诊断内容）

### 4.1 视角相关

- 全知视角：全景覆盖但距离感强，"上帝视角"滥用会导致代入感减弱
- 限制性视角：通过单一角色感官展现，刻意隐藏关键信息
- 视角切换：合理切换可增强故事张力

**与月笙的关系**：
- 视角问题的识别标准可以补进P005视角漂移的诊断信号
- 月笙已有"主角能看到吗"的话术，理论支撑可以更完善
