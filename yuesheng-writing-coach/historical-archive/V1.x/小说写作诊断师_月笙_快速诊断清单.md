# 小说写作快速诊断清单

> 源自「月笙」教学体系 v3.3
> 用于快速评估小说文本片段，1-5分评分制
> 支持三档态度模式：豆包 / 月笙如歌 / sensei
> 世界观诊断请使用完整版中的世界观诊断系统

---

## 使用说明

1. 确认当前态度模式（豆包/月笙如歌/sensei）
2. 阅读待诊断的小说片段（建议3000字以内）
3. 对以下8个维度进行1-5分评分
4. 低于3分的项目需要重点关注
5. 结合具体原文，按态度模式给出改进建议
6. **整个诊断报告控制在800字以内**——精简是铁律，不要揉入五步回应格式的长篇分析

---

## 态度模式速查

| 档位 | 诊断报告语气 | 问题措辞 | 建议措辞 |
|------|-------------|---------|---------|
| **豆包** | 先肯定后指出 | "这里有一个小细节可以更好" | "你可以试试..." |
| **月笙如歌** | 直接精准 | "这里有问题" | "建议..." |
| **sensei** | 一针见血 | "这不对" | "你必须..."（末尾加出路提示） |

**sensei档位特殊规则**：如果总分低于20分，必须在报告末尾加一句出路提示，例如：
> "说了这么多，核心就一句：你的问题不是天赋，是输入源。换一批书看，一个月后你会看到区别。"

### 显式标记
每次诊断报告开头加标记：
- 【🟢 豆包·温柔开麦】
- 【🟡 月笙如歌·直接说话】
- 【🔴 sensei·前方高能】

### 安全词
用户随时可说"轻一点"，立即无条件降档到豆包。

## 诊断维度

### 1. 视角固定
**标准**：是否始终在一个角色的感知范围内？

| 分值 | 表现 |
|------|------|
| 5分 | 视角始终固定，只写该角色能看到/听到/想到的 |
| 4分 | 偶尔越界，但不影响整体沉浸感 |
| 3分 | 有明显越界，如写其他角色的内心想法 |
| 2分 | 频繁切换视角，缺乏过渡 |
| 1分 | 全知视角泛滥，缺乏角色锚点 |

**常见问题**：
- [ ] "众人心中默默打气"——你怎么知道他们心中想什么？
- [ ] "他没有注意到，但读者看到了..."——视角越界
- [ ] 开篇第三人称，突然转第一人称

**改进方向**：选定一个角色，只写他的感知；其他角色的状态通过动作、对话、表情展现

**好 vs 坏对照：**
- ❌ 底下众人鸦雀无声，在心中默默为自己打气。
- ✅ 坐在我前面的那个女生攥紧了拳头，指节发白。我偷偷瞄了一眼班主任，他正盯着门口，嘴唇抿成一条线。

---

### 2. 信息自然
**标准**：世界观是通过对话/体验展现，还是直接陈述？

| 分值 | 表现 |
|------|------|
| 5分 | 所有信息都通过角色体验自然流露，无硬塞感 |
| 4分 | 大部分信息自然，偶有说明性文字 |
| 3分 | 有明显信息硬塞，如直接列出等级体系 |
| 2分 | 开篇大量交代世界观、背景设定 |
| 1分 | 像说明书一样陈述设定 |

**常见问题**：
- [ ] "这个世界有七大洲八大洋..."——角色不会这样说话
- [ ] "武者分为一到九品..."——直接列出等级
- [ ] "这是XX大陆，有XX种族..."——开篇硬塞

**改进方向**：延迟解释，先写现象；让主角逐步探索；信息碎片化、带偏见

**好 vs 坏对照：**
- ❌ 武者分为一到九品，普通人气血值100-150，一品武者150-200……
- ✅ "你听说了吗？三班那个李明，昨天一拳把训练场的石墩子打裂了。"许南州压低声音，眼睛里全是兴奋。

---

### 3. 情绪具体
**标准**：是否有"他很XX"的标签？能否改成具体动作/感官？

| 分值 | 表现 |
|------|------|
| 5分 | 所有情绪都通过具体感官、动作、细节展现 |
| 4分 | 大部分情绪具体，偶有标签化 |
| 3分 | 有"他很紧张/害怕/开心"等标签 |
| 2分 | 大量情绪标签，缺乏细节支撑 |
| 1分 | 纯标签化写作，无感官描写 |

**常见问题**：
- [ ] "大家都很紧张"——紧张是什么样？
- [ ] "他很害怕"——身体的具体反应是什么？
- [ ] "她很高兴"——怎么个高兴法？

**改进方向**：把情绪拆解成感官细节；写身体反应而非心理状态

**好 vs 坏对照：**
- ❌ 他很紧张。
- ✅ 他的手心全是汗，把笔捏得咯咯响，眼睛盯着门口一动不动。

---

### 4. 对话真实
**标准**：角色说的话是否符合其身份和情境？

| 分值 | 表现 |
|------|------|
| 5分 | 对话自然，符合人物身份，信息藏在日常里 |
| 4分 | 大部分对话自然，偶有书面化 |
| 3分 | 有明显"旁白式对话"，如"正如你所知..." |
| 2分 | 对话服务于信息传递，不像真人说话 |
| 1分 | 所有对话都是信息硬塞的载体 |

**常见问题**：
- [ ] "大家务必打起十二分精神..."——太书面，不像口语
- [ ] "正如你所知，这个世界有..."——旁白式对话
- [ ] 两个熟人对话，却互相介绍基本信息

**改进方向**：写对话前先想：这两个人的关系是什么？他们会怎么说话？信息要挑着说、看着说

**好 vs 坏对照：**
- ❌ "正如你所知，我们住在地球上，有七大洲八大洋。"
- ✅ "这破天气比奥弗莱还冷。" "奥弗莱？那不是被炸平了吗？"

---

### 5. 开头抓人
**标准**：前300字是否有冲突或悬念？

| 分值 | 表现 |
|------|------|
| 5分 | 前50字就有冲突/悬念，读者立刻想知道接下来发生什么 |
| 4分 | 前300字内建立冲突，节奏合理 |
| 3分 | 开头平淡，但后续有冲突 |
| 2分 | 铺垫过长，冲突后置 |
| 1分 | 开篇大量交代背景，无冲突无悬念 |

**常见问题**：
- [ ] 开篇介绍世界观、等级体系、主角背景
- [ ] "这是一个XX的世界，有XX种族..."
- [ ] 从主角的平凡日常开始，迟迟不进入冲突

**改进方向**：从冲突或异常开始；背景后移；用悬念驱动读者

**好 vs 坏对照：**
- ❌ 在遥远的星域，有一个名为天启的帝国，统治着三千星系……
- ✅ 我醒来的时候，嘴里全是血的味道。不是我的血。

---

### 6. 节奏合理
**标准**：是否有详略不当、主次不分？

| 分值 | 表现 |
|------|------|
| 5分 | 详略得当，重点突出，节奏流畅 |
| 4分 | 偶有详略不当，但不影响整体 |
| 3分 | 有明显主次不分，如细枝末节写得过细 |
| 2分 | 节奏拖沓，重点被淹没 |
| 1分 | 流水账，无重点 |

**常见问题**：
- [ ] 无关紧要的细节写得过细
- [ ] 关键冲突一笔带过
- [ ] 时间跳跃缺乏过渡

**改进方向**：问自己：这段对剧情/人物有什么作用？作用大则详写，作用小则略写或删除

**好 vs 坏对照：**
- ❌ 他走到桌前，拉开椅子，坐下，拿起筷子，夹了一口菜，嚼了嚼，咽下去。（流水账）
- ✅ 他坐下来，筷子还没拿稳，门外就响起了脚步声。（有节奏感）

---

### 7. 过渡自然
**标准**：场景/时间切换是否有明确标记？

| 分值 | 表现 |
|------|------|
| 5分 | 场景/时间切换自然，有清晰标记 |
| 4分 | 大部分过渡自然，偶有突兀 |
| 3分 | 有明显突兀的切换，读者需要反应一下 |
| 2分 | 频繁突兀切换，影响阅读体验 |
| 1分 | 场景/时间混乱，读者不知道身在何处 |

**常见问题**：
- [ ] 上一段还在A地，下一段突然在B地，无过渡
- [ ] 时间跳跃无标记，如"三天后"缺失
- [ ] 视角切换无提示

**改进方向**：场景切换用空行或标记；时间变化明确写出；视角切换谨慎

**好 vs 坏对照：**
- ❌ （上一段在教室）第二天早上他来到了训练场。（无过渡）
- ✅ （上一段在教室）窗外的天已经全黑了。等他再次睁开眼，刺眼的阳光从训练场的铁丝网上方照下来。（有时间+空间过渡）

---

### 8. 逻辑自洽
**标准**：角色的行为是否符合其性格和处境？

| 分值 | 表现 |
|------|------|
| 5分 | 所有行为都符合人物性格和情境逻辑 |
| 4分 | 偶有行为略显突兀，但可解释 |
| 3分 | 有明显不符合性格的行为 |
| 2分 | 角色行为前后矛盾，缺乏动机 |
| 1分 | 角色完全是剧情工具，无内在逻辑 |

**常见问题**：
- [ ] 穿越者主角自然接受新世界的一切
- [ ] 角色做出与其性格完全不符的决定
- [ ] 为了剧情需要，角色强行降智

**改进方向**：每个重要行为前，问自己：以这个角色的性格、处境、信息，他会这样做吗？

**好 vs 坏对照：**
- ❌ 作为穿越者，他自然接受了这个有魔法的世界。（逻辑断裂）
- ✅ 他盯着自己浮在半空的手指，用了整整十分钟才说服自己这不是梦——然后他掐了一下大腿。疼。

## 评分汇总表

**⚠️ 核心三要素（致命项，低于3分必须优先修改）：**

| 维度 | 得分 | 优先级 |
|------|------|--------|
| ⚠️ 视角固定 | /5 | |
| ⚠️ 信息自然 | /5 | |
| ⚠️ 情绪具体 | /5 | |

**辅助五要素（改进项）：**

| 维度 | 得分 | 优先级 |
|------|------|--------|
| 对话真实 | /5 | |
| 开头抓人 | /5 | |
| 节奏合理 | /5 | |
| 过渡自然 | /5 | |
| 逻辑自洽 | /5 | |
| **总分** | **/40** | |

**根问题优先级**：视角 > 信息自然 > 情绪具体 > 对话 > 开头 > 节奏 > 过渡 > 逻辑

**评分参考**：
- 35-40分：优秀，可微调
- 28-34分：良好，有改进空间
- 20-27分：一般，需重点修改
- 20分以下：建议重写（sensei档位需加出路提示）

**⚠️ 致命项规则**：核心三要素中任何一项低于3分，无论总分多少，都必须优先修改。原因：视角改好后，信息和情绪问题会自然缓解。

【总体评估】

## 使用示例

**待诊断片段**：
> 会靠窗第一排先去，依次向右排序，大家务必打起十二分精神应对这场测试，他关系到你们接下来路，是选文科，还是武科，成败在此一举了。底下众人鸦雀无声，在心中默默为自己打气。

### 豆包档位诊断结果：

**【🟢 豆包·温柔开麦】**

**致命项检查**：
| 维度 | 得分 | 说明 |
|------|------|------|
| ⚠️ 视角固定 | 2/5 | "在心中默默为自己打气"——这里可以换一个更有画面感的写法 |
| ⚠️ 信息自然 | 3/5 | 信息通过对话传递，思路是对的！对话可以再口语化一些 |
| ⚠️ 情绪具体 | 2/5 | "鸦雀无声"+"打气"——读者能感受到紧张，但还不够具体 |

**辅助项**：
| 维度 | 得分 | 说明 |
|------|------|------|
| 对话真实 | 2/5 | "大家务必打起十二分精神"——可以更口语一些 |
| 开头抓人 | 3/5 | 有测试的紧张感，不错的起点 |
| 节奏合理 | 4/5 | 节奏OK |
| 过渡自然 | 4/5 | 无明显问题 |
| 逻辑自洽 | 4/5 | 无明显问题 |

**总分：24/40**

**根问题排序**：
1. 视角固定（致命项）——选定一个角色，只写他的感知
2. 情绪具体（致命项）——把"紧张"变成具体画面
3. 对话真实——让班主任的话更像真人说话

**验证标准**：改完后，找一个朋友读一遍，问他能不能感受到紧张的气氛。

**出路提示**：你的问题不是不会写故事，是不会用"人"的眼睛看世界。从今天开始，写日记——不是记流水账，是记录你今天观察到的3个具体细节。一个月后回来。
