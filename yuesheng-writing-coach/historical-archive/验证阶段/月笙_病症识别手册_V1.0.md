## 详细识别标准

### P001：世界观膨胀

**核心特征**：设定超过主角，主角目标不明确

**识别信号**：

| 信号类型 | 具体表现 | 权重 |
|---------|---------|------|
| 数量信号 | 世界观专有名词超过5个 | +1 |
| 比例信号 | 世界观描述篇幅超过主角描述3倍 | +2 |
| 目标信号 | 主角目标不明确或未确定 | +2 |
| 表达信号 | 用户说"世界观有点杂""太大了" | +1 |
| 构思信号 | 用户说"主角都没确定" | +2 |

**严重度分级**：

| 严重度 | 信号总分 | 表现 | 处理方式 |
|--------|---------|------|---------|
| L1 轻度 | 1-2分 | 世界观略多，主角有雏形 | 轻度引导，问"主角是谁" |
| L2 中度 | 3-4分 | 世界观明显过多，主角模糊 | A001缩小范围，给选择 |
| L3 重度 | 5分+ | 世界观庞大，主角完全未确定 | A001+A005组合，假设降门槛 |

**触发条件**：
- 信号总分≥2 → 触发A001
- 信号总分≥4 → 触发A001+A005组合

**真实案例**：
- C001：达维莱特"世界观有点杂，主角没确定" → 信号总分4 → L2 → A001
- C002：达维莱特"世界观太大，是人是鬼都没确定" → 信号总分5 → L3 → A001+A005

### P002：角色工具人化

**核心特征**：角色缺乏独立动机，只为衬托主角

**识别信号**：

| 信号类型 | 具体表现 | 权重 |
|---------|---------|------|
| 功能信号 | 角色存在只为"告诉主角某事" | +2 |
| 动机信号 | 角色行为缺乏独立立场 | +2 |
| 表达信号 | 用户说"角色没有人味""像NPC" | +2 |
| 尝试信号 | 用户尝试用"割裂写作"解决 | +1 |

**严重度分级**：

| 严重度 | 信号总分 | 表现 | 处理方式 |
|--------|---------|------|---------|
| L1 轻度 | 1-2分 | 角色略有工具人倾向 | 轻度引导，问"这个角色会怎么做" |
| L2 中度 | 3-4分 | 角色明显工具人化 | A004现实锚点，现场演示 |
| L3 重度 | 5分+ | 角色完全无独立人格 | A004+A003组合，五问法理清动机 |

**触发条件**：
- 信号总分≥2 → 触发A004
- 信号总分≥4 → 触发A004+A003组合

**真实案例**：
- C003：达维莱特"角色没有人味，像NPC" → 信号总分4 → L2 → A004

### P003：情绪标签化

**核心特征**：用概括词代替具体描写

**识别信号**：

| 信号类型 | 具体表现 | 权重 |
|---------|---------|------|
| 词汇信号 | 出现"紧张""害怕""难过""愤怒"等情绪词 | +1 |
| 缺失信号 | 情绪词后无具体神态/动作描写 | +2 |
| 数量信号 | 单段出现≥3个情绪标签词 | +1 |
| 表达信号 | 用户说"大家很紧张""他很害怕" | +1 |

**常见情绪标签词**：
- 紧张、害怕、恐惧、慌张、焦虑
- 难过、悲伤、痛苦、心碎
- 愤怒、生气、恼火、暴怒
- 开心、快乐、兴奋、激动
- 惊讶、震惊、意外

**严重度分级**：

| 严重度 | 信号总分 | 表现 | 处理方式 |
|--------|---------|------|---------|
| L1 轻度 | 1-2分 | 偶尔使用情绪词，有部分描写 | 轻度引导，问"紧张是什么样" |
| L2 中度 | 3-4分 | 频繁使用情绪词，缺乏描写 | A004现实锚点，拆解示范 |
| L3 重度 | 5分+ | 全文依赖情绪词，无任何描写 | A004+训练任务组合 |

**触发条件**：
- 信号总分≥2 → 触发A004
- 信号总分≥4 → 触发A004+训练任务

**真实案例**：
- C006：锦泠"大口吞食"缺乏细节 → 信号总分3 → L2 → A004
- C008：哒哒哒"大家很紧张"无描写 → 信号总分4 → L2 → A004（部分成功，需处理辩驳）

### P004：信息硬塞

**核心特征**：世界观直接陈述，不嵌在场景中

**识别信号**：

| 信号类型 | 具体表现 | 权重 |
|---------|---------|------|
| 位置信号 | 开篇第一段直接交代世界观 | +2 |
| 形式信号 | 世界观通过旁白/说明交代，非对话/场景 | +2 |
| 内容信号 | 出现"XX分为...""XX是..."等说明句 | +1 |
| 表达信号 | 用户说"怕读者看不懂" | +1 |

**常见信息硬塞句式**：
- "这个世界..."
- "武者分为一到九品..."
- "XX是..."
- "在XX的世界里..."

**严重度分级**：

| 严重度 | 信号总分 | 表现 | 处理方式 |
|--------|---------|------|---------|
| L1 轻度 | 1-2分 | 偶尔说明，大部分嵌在场景 | 轻度引导，问"主角是怎么知道的" |
| L2 中度 | 3-4分 | 开篇直接说明，缺乏场景嵌入 | A002回归主角，改写示范 |
| L3 重度 | 5分+ | 全文依赖说明，无场景嵌入 | A002+A006组合，对比展示 |

**触发条件**：
- 信号总分≥2 → 触发A002
- 信号总分≥4 → 触发A002+A006组合（处理辩驳）

**真实案例**：
- C004：锦泠开篇交代世界观 → 信号总分4 → L2 → A002
- C007：哒哒哒"武者分为一到九品" → 信号总分4 → L2 → A002（部分成功，需A006处理辩驳）

### P005：视角漂移

**核心特征**：视角切换生硬，上帝视角泛滥

| 信号类型 | 具体表现 | 权重 |
|---------|---------|------|
| 切换信号 | 第三人称→第一人称切换生硬 | +2 |

| 穿越信号 | 主角能看到别人内心/知道不该知道的事 | +2 |
| 表达信号 | 用户说"视角混乱"被指出 | +1 |

**常见视角漂移句式**：
- "大家都很XX"
- "众人心中XX"
- "所有人XX"
- "每个人XX"

**严重度分级**：

| 严重度 | 信号总分 | 表现 | 处理方式 |
|--------|---------|------|---------|
| L1 轻度 | 1-2分 | 偶尔全知描写，大部分主角视角 | 轻度引导，问"主角能看到吗" |
| L2 中度 | 3-4分 | 频繁全知描写，视角切换生硬 | A002回归主角，给具体方法 |
| L3 重度 | 5分+ | 全文上帝视角，无主角视角 | A002+训练任务组合 |

**触发条件**：
- 信号总分≥2 → 触发A002
- 信号总分≥4 → 触发A002+训练任务

## 识别流程

```
用户输入 → 扫描信号 → 计算总分 → 判断严重度 → 触发动作
```

**扫描优先级**：
1. 先扫描表达信号（用户自己说的话）
2. 再扫描文本信号（文本中的具体表现）
3. 最后扫描数量信号（计数）

**多病症处理**：
- 单次对话最多识别2个病症
- 优先识别总分最高的病症
- 相关病症可以组合处理（如P001+P006）

---

## AI执行规则

1. **不输出病症编号**：内部识别，不告诉用户"你犯了P001"
2. **不输出评分**：内部计算，不告诉用户"你得了4分"
3. **直接触发动作**：识别后直接执行对应动作
4. **跨轮次保持**：诊断结果在会话内保持，不每轮重新诊断
