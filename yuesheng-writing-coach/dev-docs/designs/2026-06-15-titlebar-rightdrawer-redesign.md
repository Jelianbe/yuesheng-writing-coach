## §1 动机

本轮设计解决三个核心 Issue：

| Issue | 标题 | 描述 |
|:-----:|------|------|
| #8 | 窗口控制键缺失 | 当前 `frame: false` 模式下无最小化/最大化/关闭按键 |
| #4 | 右侧栏 header 溢出 | 标签过多时 header 内容溢出，结构需重新规划 |

## §2 整体布局

### 2.1 核心规则

- 三分栏是**独立窗口模型**（不是叠加覆盖），共同挤占屏幕
- 三个栏各自拥有独立的 header 区
- 三个 header 区共享同一背景色，底部全宽深色分割线，视觉上形成"header 层"效果
- header 区始终存在（不随栏收起/展开消失），只是宽度变化
- 所有栏都有 min/max 宽度限制
- `[─][□][✕]` 为窗口控制键，**窗口级独立渲染**（`position: fixed` + 最高 z-index），不嵌套在任何栏的 DOM 中。视觉上位于右侧栏 header 最右端，与 `[⤢]` 形成连续序列

### 2.2 三栏状态表

| 栏 | 展开态 | 收起态 |
|:--|:-------|:-------|
| 左侧栏 | 显示 header + 内容区，min=180px, max=380px（默认 240px） | 完全隐藏（无窄条） |
| 中间栏 | 始终占据剩余空间，无显式 header | 始终占据剩余空间，无显式 header |
| 右侧栏 | 显示 header + 内容区，min=320px, max=560px（默认 420px） | 内容区隐藏，header 保留，min=约 160px（仅 header 按钮宽度） |

### 2.3 展开态布局

```
 ┌─────────────┬──────────────────────────┬──────────────────────────────┐
 │ 月笙[▶]     │                          │ [标签1][标签2][＋] [⤢][─][□][✕]│ ← 三个 header 区
 ├─────────────┤                          ├──────────────────────────────┤ ← 深色分割线
 │ [对话] [项目]│                          │ [项目/会话标签层]             │
 │             │    中间栏                │                              │
 │  左侧栏     │    (对话区)              │  右侧栏内容                  │
 │  SessionList│                          │  - 有工具 → 展示内容         │
 │  /          │    无 header             │  - 无工具 → 工具网格         │
 │  WorkTree   │                          │                              │
 │  Panel      │                          │                              │
 └─────────────┴──────────────────────────┴──────────────────────────────┘
```

### 2.4 收起态布局

```
 ┌─────────────────────────────────────────────────────────────────────┐
 │ 月笙[▶]                            [＋][⚙][⤢][─][□][✕]           │ ← header 层（收缩）
 ├─────────────────────────────────────────────────────────────────────┤ ← 深色分割线
 │                                                                     │
 │                          中间栏 (全屏)                               │
 │                                                                     │
 └─────────────────────────────────────────────────────────────────────┘
```

**说明：**
- 左侧栏展开态：[▶] 在 header 右端，点击收起
- 左侧栏收起态：[▶] 紧邻月笙右侧，作为展开入口
- `[─][□][✕]` 窗口级独立渲染（`position: fixed`），始终位于窗口右上角，不随任何栏的收起/展开变化
- `[⤢]` 始终存在，左邻 [─]

### 2.5 按钮位置与功能表

| 按钮 | 位置 | 视觉样式 | 功能 |
|:----:|:-----|:---------|:-----|
| `[＋]` | 左侧栏展开态 Tabs `[对话][项目]` 右侧 | `var(--accent)` + 背景亮显 | 新建对话/项目 |
| `[▶]` | 收起态：月笙右侧；展开态：header 右端 | `var(--text-secondary)` | 左侧栏展开/收起 |
| `[＋]` | 中间栏右上角 | `var(--text-secondary)` | 新建对话 |
| `[⚙]` | 中间栏右上角，[＋] 右侧 | `var(--text-secondary)` | 设置 |
| `[标签1][标签2]` | 右侧栏 header 左端 | 居中高亮当前标签 | 切换右侧栏工具/内容 |
| `[＋]`（标签） | 右侧栏标签最右端 | `var(--text-secondary)`，hover `var(--accent)` | 添加新标签 |
| `[⤢]` | 右侧栏 header 右端（左邻窗口三键） | `var(--text-secondary)`，hover `var(--accent)` | 右侧栏内容区展开/收起 |
| `[─]` | 窗口右上角（窗口级独立渲染） | 独立配色，动态变色 | 最小化窗口 |
| `[□]` | 同上 | 同上 | 最大化/还原 |
| `[✕]` | 同上 | 同上 | 关闭窗口 |

### 2.6 中间栏右上角行为

- 右侧栏**展开态**：`[＋][⚙]` 对齐右侧栏左边界
- 右侧栏**收起态**：`[＋][⚙][⤢]` 对齐中间栏右边界（三键连续排列）
- `[⤢]` 在收起态从右侧栏迁移到中间栏右上角，展开时回到右侧栏 header

### 2.7 Z-index 层次

```
z-index 自上而下：
┌──────────────────────────────────────────────┐
│ 右上: [─][□][✕]（窗口级，position: fixed）   │  最高层 — 始终固定，不可覆盖
├──────────────────────────────────────────────┤
│ 左上: ⦿月笙[▶]（收起态独立悬浮）            │  第二层 — 始终可见
├──────────────────────────────────────────────┤
│ 右上: [⤢]（右侧栏 header）                   │  第三层 — 始终可点
│ 左上: 月笙（左侧栏 header）＋ [▶]（右端）    │  同层次
├──────────────────────────────────────────────┤
│ 三栏内容区（左侧栏 tab+内容 / 中间栏 /       │  基础层
│ 右侧栏标签层+内容层）                        │
└──────────────────────────────────────────────┘
```

**说明：**
- `[─][□][✕]` 位于最高 z-index 层，窗口级 `position: fixed`，不嵌套在任何栏的 DOM 中。始终位于窗口右上角，不随任何栏的收起/展开隐藏或移动
- `⦿月笙` 品牌图标独立于三分栏体系之外，位于第二 z-index 层
- 收起态时 [▶] 紧邻月笙右侧，作为展开入口；展开态时 [▶] 在 header 右端
- `⦿月笙[▶]` 收起态独立悬浮，展开态融入左侧栏 header（月笙在左端，[▶] 在右端）
- 为后续 Solo（纯写作）/ IDE（全功能）两种工作模式切换预留
- 左侧栏和右侧栏 header 在同一 z-index 层

### 2.8 样式规则

- 各栏宽度变化时，分割线跟随各栏宽度
- header 区顶部对齐（top: 0），高度一致

### 2.9 窗口三键动态变色

| 当前状态 | 背景 | 图标颜色 |
|:---------|:-----|:---------|
| 展开态（浅色背景） | `var(--surface-primary)` 或 `var(--bg-primary)` | `var(--text-secondary)` |
| 收起态（深色背景） | `var(--bg-inverse)` 或 `var(--surface-inverse)` | `var(--text-inverse)` `#fff` |

- 通过 `useUiLayoutStore` 监听右侧栏展开/收起状态
- 颜色切换不使用 CSS `:has()` 选择器，通过 React 条件判断动态添加 class
- 过渡：`color 150ms ease, background 150ms ease`

## §3 左侧栏

### 3.1 收起态

- **去掉 44px 窄条**，收起时完全隐藏
- 展开入口：左上角 `⦿月笙[▶]` 中的 [▶] 按钮（月笙品牌+展开箭头）
- `⦿月笙[▶]` 在收起态独立悬浮在窗口左上角（z-index 第二层）
- 点击 [▶] 展开左侧栏，月笙品牌回到左侧栏 header 左端

### 3.2 展开态

- Header 左端：`月笙`（无品牌图标）
- Header 右端：`[▶]`（点击收起）
- Tabs：`[对话][项目]` + `[＋]`（新建）
- 内容区：SessionList（对话模式）/ WorkTree（项目模式）

### 3.3 宽度限制

- 最小宽度：180px
- 最大宽度：380px
- 默认宽度：240px
- 拖拽 handle 位于右侧边缘

## §4 右侧栏

### 4.1 整体结构

右侧栏从上到下分三个区域：

```
 ┌──────────────────────────────┐
 │ [标签1][标签2][＋]    [⤢]   │ ← Header 区（始终存在）
 ├──────────────────────────────┤ ← 标签分隔线
 │ [当前选中标签的内容]          │ ← 标签层（工具 tab 导航）
 ├──────────────────────────────┤
 │ 内容区域                      │ ← 内容层
 │ - 有工具 → 展示工具内容       │
 │ - 无工具 → 工具网格           │
 └──────────────────────────────┘
```

### 4.2 收起态

- 隐藏内容区（标签层 + 内容层）
- Header 区保留，显示 `[标签1][标签2][＋]` 和 `[⤢]`
- 收起宽度约 160px（仅 header 按钮占据）
- 点击 [⤢] 重新展开内容区

### 4.3 Header 排布

- 左端（左对齐）：`[标签1][标签2]……[＋]`
  - 标签随点击切换右侧栏内容
  - 最后一个标签右侧放置 [+]，用于添加新标签
  - 标签过多时内部可横向滚动（overflow-x: auto），不溢出到按钮区域
- 右端（右对齐）：`[⤢]`（展开/收起图标）
  - `[⤢]` 始终存在，固定在最右端

### 4.4 拖拽缩放

- 缩放 handle 位于右侧栏**左边缘**（非右边缘）
- 交互区域：4px 不可见区域
- 鼠标悬停显示 `col-resize` 光标
- 行为：`mousedown` → `mousemove`（触发宽度更新）→ `mouseup`
- 范围：320px ~ 560px（默认 420px）

## §5 窗口控制 + 品牌图标

### 5.1 品牌图标

- 位置：窗口左上角，独立于三分栏 DOM 结构之外
- 收起态：`⦿月笙[▶]` 独立悬浮
- 展开态：`月笙` 位于左侧栏 header 左端，[▶] 在右端
- z-index：最高层（仅次于窗口三键）

### 5.2 窗口三键

- `[─][□][✕]` 窗口级独立渲染（`position: fixed; top: 0; right: 0` + 最高 z-index）
- 不嵌套在任何栏的 DOM 中
- 视觉上位于右侧栏 header 最右端（右侧栏需预留 padding-right 避免重叠）
- 独立配色方案，不继承各栏背景色
- 展开态：浅色背景 + 深色图标
- 收起态：深色背景 + 浅色图标
- 过渡动画：`color 150ms ease, background 150ms ease`
- 通过 Zustand store（`useUiLayoutStore`）监听右侧栏状态实现颜色切换

### 5.3 IPC 通道

```typescript
// renderer → main: 通过 ipcRenderer.send 调用
// 通道格式遵循 domain:action 规范
ipcRenderer.send('window:minimize');
ipcRenderer.send('window:maximize');
ipcRenderer.send('window:close');
```

- `frame: false` 下需要自己处理窗口拖拽
- `[─][□][✕]` 组件不依赖任何栏的 DOM，在 `AppShell` 层的 `WindowControls` 独立组件中注册

## §6 交互与动画

### 6.1 收起/展开动画

| 栏 | 动画 |
|:--|:-----|
| 左侧栏 | `width 280ms cubic-bezier(0.4, 0, 0.2, 1)` |
| 右侧栏 | `width 200ms ease-out` |
| 中间栏 | 不做独立动画，被左右栏宽度变化推挤 |

- 使用 CSS transition，不通过 JS 动画库

### 6.2 左侧栏 [▶] toggle

- 收起态：月笙右侧，图标方向 `▶`（向右），点击 = 展开
- 展开态：header 右端，图标方向 `▶`（向右），点击 = 收起
- **说明**：展开态的 [▶] 方向指向右但动作向左（收起），是故意保留的图标-动作映射不一致（用户确认接受）

### 6.3 ⤢ 键

- 颜色：`var(--text-secondary)`，与 `[＋] [⚙]` 统一
- hover：`var(--accent)`
- 过渡：`color 120ms ease`
- 始终位于右侧栏 header 最右端，左邻窗口三键 `[─][□][✕]`
