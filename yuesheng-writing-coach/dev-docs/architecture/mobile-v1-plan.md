# 移动端 V1 方案 — 前端重构

> 对齐设计 HTML（`未命名.html`） + PRD V1.0（三层架构）
> 目标：移动端优先（375px），桌面端为宽屏居中拉伸
> 状态：已批准 | 跟随 GStack: Plan → Build → Review → Ship → Reflect

---

## 1. 哲学锚点（来自 PRD）

1. **教学中心** — 月笙不是写作工具，是 AI 教学系统
2. **意图驱动** — 用户不选择模式，AI 自动路由（诊断/教学/训练/闲聊）
3. **前端极简，后台复杂** — 对话入口极简，后端能力不精简
4. **用户永远面对老师** — 界面形态是"教学对话"，不是"功能操作台"

## 3. 页面栈结构

```
App
 └── PageStackRouter (Context + Zustand)
      ├── 375px clamp 容器
      │
      ├── [TabBar 可见] 首页栈
      │    ├── 📚 BookshelfPage     — 书架（默认首页）
      │    ├── 💬 ConversationsPage — 对话列表
      │    └── 🧩 AppsPage          — 应用中心
      │
      ├── [TabBar 隐藏] 子页面栈 (push/pop)
      │    ├── ProjectSpacePage     — 项目空间（从书架进入）
      │    └── ChatPage             — 教学对话（从项目/对话列表进入）
      │
      └── TabBar (3 tab: 书架 | 对话 | 应用)
```

**路由规则**：
- TabBar 只在根页面（Bookshelf/Conversations/Apps）显示
- Push 子页面时 TabBar 隐藏，显示返回箭头
- Pop 回根页面时 TabBar 恢复

## 4. 页面规格

### 4.1 BookshelfPage（书架 — 默认首页）

**Navbar**：
- 左："书架"标题
- 右：🔍 搜索按钮 + ➕ 新建按钮

**内容区**：
- 3 张书卡（渐变色封面 46×60px，紫色系渐变）
- 每张卡：封面 | 书名 | 元数据（字数/章节） | 成长指示点
- 底部虚线"新建学习项目"按钮

**数据**：`useProjectStore`（暂用 mock，后续对接 IPC）

### 4.2 ProjectSpacePage（项目空间）

**Navbar**：
- 左：‹ 返回按钮
- 中：项目标题
- 右：⋯ 更多

**统计区**：
- 6 次诊断 | 4 次训练 | 23 学习天（mock 数据）

**能力雷达图**（SVG）：
- 五维：人物塑造/情节节奏/环境描写/对话设计/叙事视角
- 1-5 分，底色为浅紫，填充为紫色渐变

**CTA**：
- "开始新的学习"按钮（主色填充 + 阴影）

**最近记录**：
- 学习记录卡片（3 条）
- 作品章节卡片（3 条）

### 4.3 ChatPage（教学对话 — 核心页面）

**Navbar**：
- 左：‹ 返回按钮
- 中：作品标题 + "人物动机学习·进行中"副标题
- 右：⋯ 更多

**欢迎引导区**（首次进入或新会话）：
- 月笙头像（56px，渐变紫色圆形）
- "嘿，今天想从哪里开始？"
- 3 个快捷引导按钮

**消息气泡**：
- 用户消息：紫色填充 `#8A7A9E`，白色文字，右对齐，圆角 12px
- AI 思考中：三点脉冲动画 + "我整理一下核心问题…"
- 诊断教学气泡：
  - "诊断分析"标签（紫色底白色字）
  - 3 个编号问题列表（动机问题/对话平淡/节奏拖沓）
  - 引导按钮区（"先看改写示例"/"好，讲讲"）

**输入栏**：
- 工具条（📝文字/🖼️图片/📄文档/⚙️设定）
- 圆角输入框（8px，浅紫背景 `#F5F2F9`）
- 条件激活发送按钮（有内容时变为主色）

### 4.4 ConversationsPage（对话列表）

**Navbar**：
- "对话"标题

**列表**：
- 每条显示：标题 | 摘要 | 时间 | 作品关联
- 空状态：引导创建新对话

### 4.5 AppsPage（应用中心）

**Navbar**：
- "应用"标题

**网格**：4×4 图标网格
- 成长报告 | 训练计划 | 技法库 | 素材库
- 下方工具列表：结构拆解 | 设定管理 | 导出作品

## 5. 数据流

```
View (Page)
  ↓  dispatch
Store (Zustand + persist)
  ↓  invoke
IPC Handler (main)
  ↓
Backend Service
```

**当前阶段**：View ← mock data（Store 层保持接口兼容，后续替换为 IPC）

**直接用现有 Store**（无需新建）：
- `useProjectStore` — 项目列表/当前项目
- `useChatStore` — 消息列表/加载/流状态
- `useSessionStore` — 会话列表
- `useTeachingStateStore` — 教学阶段

## 7. 门禁标准 (DoD)

1. `npm run typecheck` 零错误
2. `npm run test` 全绿（现有测试不受影响）
3. `npm run lint` 零 error
4. 375px 容器正确约束，移动端可滚动
5. TabBar 3 tab 切换正确
6. push/pop 导航正确（子页面 TabBar 隐藏）
