## 一、项目背景

**月笙**是一个AI写作教练系统，定位为"教练"而非"助手"：
- 不替用户写
- 不替用户决定
- 帮用户看清问题，让用户自己解决

**核心方法论**：找根因，不是找错误。治根因，表象自然消失。

**目标用户**：网文/小说创作者，从新手到有一定基础的作者。

## 三、发现的问题

### 3.1 验证阶段发现（5个）

| 问题 | 表现 | 影响 |
|------|------|------|
| A008阅读拓展动作缺失 | P007能识别但无对应动作 | 无法处理"只读网文"型用户 |
| 辩驳处理单一 | 只有A006对比展示，缺少"直接解释原因" | 处理方式僵化 |
| 多病症优先级缺失 | 同时触发4个病症时不知先处理哪个 | 诊断混乱 |
| 月笙如歌强度上限 | 对亡妻控/自我感动型用户温和语气无效 | 需要sensei模式 |
| 测试方法污染 | AI复述已知答案而非独立生成训练任务 | 训练任务生成能力未真正验证 |

### 3.2 规则膨胀风险（核心担忧）

**当前Prompt长度**：约5000字
**规则数量**：核心原则+七个动作+七个病症+六个场景规则+态度档位+禁忌+外部资源规则

**风险表现**：
- Prompt可能膨胀到8000字以上
- AI可能变成"识别病症→查表→选模板→输出"的流程执行
- 机械化诊断：用户说一句话就立刻诊断病症
- 动作触发僵化：同一病症在不同情境下可能需要不同动作，但规则太死

**核心矛盾**：方法论完善 ≠ 教学效果好。真实月笙的教学是"有方法论，但不机械执行"。

### 3.3 外部资源整合的两难

**已提取的可补充内容**：
- 七问公式扩展（目标→阻碍→努力→结果→意外→转弯→结局）
- 双重的两难（两重困境相互影响意义）
- 两扇门（判断主角是否被推入故事）
- 晚进入/早离开（场景搭建技巧）
- 人物情绪预想（写场景前先想反应+颜色）

**两难**：
- 如果整合进Prompt → 规则膨胀，AI僵化
- 如果不整合 → 方法论不完整，可能遗漏有效工具

## 四、待决策选项

### 4.1 规则膨胀问题（核心决策）

**问题**：如何平衡方法论完善与AI灵活性？

**选项A：控制总量**
- 设定Prompt上限6000字
- 新内容用"提及式"而非"整合式"
- 只在需要时提及书名，不把具体方法塞进Prompt

**选项B：分层规则**
- 核心层（必须遵守）：第一性原理、禁忌、态度档位
- 参考层（按需调用）：动作库、病症识别手册
- 素材层（提及式）：外部书籍、具体技巧
- AI先遵守核心层，参考层和素材层只在需要时查阅

**选项C：强调"倾听优先"**
- Prompt开头明确：先倾听用户说完，再判断要不要介入
- 不要用户说一句话就立刻诊断
- 真实月笙节奏：用户说一堆→确认/选择→继续说→判断时机→介入

**选项D：动作触发留白**
- 病症→可选动作范围（而非强制触发）
- 比如：P001世界观膨胀，可选A001/A002/直接指出，AI根据情境选择

**选项E：定期清理**
- 每次添加新规则时问：是否重复？是否让AI更僵化？是否有更简洁表达？

**推荐**：组合A+B+C——控制总量+分层规则+强调倾听优先
