## 4. 关键设计

### 4.1 拖拽状态机（无频繁 React state 更新）

```ts
// store
resizing: null | 'sidebar' | 'rightPanel'
startResize(target) → resizing = target
endResize() → resizing = null

// 组件: 用 ref 记录起始位置（避免 state 频繁更新）
const dragStateRef = useRef<{target, startX, startWidth}>(null);

// mousedown: startResize + 记录 ref
// mousemove: 直接 setSidebarWidth / setRightPanelWidth (zustand 自动 re-render)
// mouseup: endResize
```

**优势**：mousemove 时只更新 zustand 内部状态，不触发 React 组件 re-render。性能 < 100ms。

### 4.2 CSS 变量传递宽度

```css
.sidebar {
  width: var(--sidebar-width, 240px);
  transition: width 300ms cubic-bezier(0.25, 0.1, 0.25, 1);
}
.rightPanel {
  width: var(--right-panel-width, 420px);
  transition: width 300ms cubic-bezier(0.25, 0.1, 0.25, 1);
}
```

```tsx
// AppShell.tsx
style={{
  ['--sidebar-width' as string]: `${sidebarWidth}px`,
  ['--right-panel-width' as string]: `${rightPanelWidth}px`,
}}
```

**优势**：CSS 集中管理过渡 + TS 集中管理数值，职责清晰。

### 4.3 拖拽时禁用过渡

```css
.shellDragging .sidebar,
.shellDragging .rightPanel {
  transition: none;
}
```

**理由**：拖拽时如果有过渡，mousemove 频繁更新会产生视觉滞后。拖拽结束后自动恢复。

### 4.4 < 1280px overlay 模式

```css
@media (max-width: 1279px) {
  .rightPanel {
    position: absolute;
    top: 0; right: 0; bottom: 0;
    z-index: 100;
    box-shadow: -4px 0 16px rgba(0, 0, 0, 0.2);
  }
  .rightPanelCollapsed {
    transform: translateX(100%);
  }
}
```

**触发**：`window.matchMedia('(max-width: 1279px)')` 监听变化，切换 `.rightPanel` className。

## 6. 关键决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 拖拽性能优化 | `dragStateRef` (useRef) | mousemove 不触发 React re-render |
| 宽度传递方式 | CSS 变量 (--sidebar-width) | CSS 集中过渡 + TS 集中数值 |
| 拖拽时过渡 | 禁用 (.shellDragging) | 避免视觉滞后 |
| overlay 触发 | matchMedia (max-width: 1279px) | 标准响应式 API |
| 边界裁剪 | store 层 clamp (clamp helper) | 单一来源(SSOT) |
| 单文件 < 300 行 | store 77 / CSS 160 / AppShell 237 | R-019 规范 |
