### 关键设计决策
- **zustand 化决策**: `useRightPanelStore` 设为无 state store,所有读写委托给 drawer / panel-session / chapter 三个 store。X-01 协议未变,SSOT 不变,仅统一入口从 service 改为 store。
- **自引用修复**: openEditor / openTraining 内部递归调用 useRightPanelStore.getState() 会导致 zustand create 推断失败（TS7022/TS7023）。改为直接调用底层 3 个 store 的 action,保持语义一致。
- **空 State 标注**: `type RightPanelState = unknown` 而非 `Record<string, never>` 或 `interface {}`,避免 R-019 禁止空接口 + TS2322 赋值失败的双重问题。
