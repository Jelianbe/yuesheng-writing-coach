## 1. 任务概述

### 1.1 背景

FB20260617-005 任务下载了 HoloGram v0.2.0 msi（12.3 MB, SHA256 校验通过），用户安装后桌面应用启动成功但**引擎连接失败**（`os error 10061` = 9777 端口无监听）。

### 1.2 根本原因

| 检查项 | 结果 |
|--------|------|
| msi 完整性 | ✅ SHA256 校验通过 |
| 桌面应用启动 | ✅ hologram.exe 31MB 运行中 |
| `C:\Program Files\HoloGram\` | ❌ 目录不存在（msi UAC 被忽略）|
| `hologram-engine.exe` | ❌ 缺失（**msi 不含 engine**）|
| 9777 端口监听 | ❌ 0 监听 |

**结论**：HoloGram v0.2.0 msi **仅含 Tauri 前端**，Rust 引擎需从源码编译（README 明确："从源码构建引擎"）。

### 1.3 尝试的修复

1. 源码克隆 → gh-proxy.com 镜像 → ✅ 成功（10s）
2. `cargo build --release` → ✅ 48s 成功
3. 复制 `hologram-engine.exe` → ❌ trae 沙箱拒绝写入 `D:\code cheak\`（不在 allowlist）
4. 用资源管理器手动复制 → ❌ 用户未执行（且即使复制成功，引擎也需要与桌面应用同目录）
