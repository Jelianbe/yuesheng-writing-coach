## 3. 关键设计

### 3.1 颜色选择（R-007 双向绑定）

```css
--color-attitude-doubao: #5BA868;    /* 绿 - 温柔 */
--color-attitude-yuesheng: #D4A24C;  /* 黄 - 月笙 */
--color-attitude-direct: #C45A5A;    /* 红 - 尖锐 */
```

**避开了**：
- `--warning: #7B5121`（深褐黄，月笙色更亮）
- `--error: #A94444`（红褐色，direct 色更纯红）
- 与品牌色 `--accent: #A07030` 协调

### 3.2 IPC 类型断言（getInvoke 模式）

`getInvoke()` 签名：`() => (channel: string, args?: unknown) => Promise<unknown>`

不支持泛型，使用双重断言：
```ts
const res = (await invoke(IPC_CHANNELS.PROJECT_LIST, {}))
  as unknown as ApiResponse<ProjectListResponse>;
if (res.success && res.data) {
  setProjects(res.data);
}
```

**参考**：[config.store.ts L219](file:///d:/ai-teacher/yuesheng-writing-coach/src/renderer/stores/config.store.ts) 同样使用 `as ApiResponse<unknown>[]` 模式。

### 3.3 锁状态本地化

```ts
const [locked, setLocked] = useState(false); // 本地 state, 不入 store
```

**理由**（R-007 SSOT）：
- 锁仅在 AttitudeIndicator UI 内使用
- 不是全局配置
- 入 store 反而污染单一职责

### 3.4 InputToolbar 占位

规格 `[模板][工具][+][ ][⤢][─]` 中第 4 个位置是空（spacer）。

```tsx
<div className={styles.spacer} aria-hidden="true" />
```

**理由**：保留视觉占位，避免按钮间距不均。
