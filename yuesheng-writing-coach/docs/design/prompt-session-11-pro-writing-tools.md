# 会话11：专业写作工具结构管理分析（T-030 扩展）

## 项目背景

月笙写作教练（Electron + React + TypeScript + SQLite），教学 Agent 系统。
已在 T-030 中评估了 8 个 AI 工具设计，现扩展到**专业写作工具的结构管理功能**。

**你的任务**：分析以下专业写作/编剧工具中与"结构管理"相关的功能，提取可影响月笙设计的功能概念。

---

## 分析对象

| 工具 | 类型 | 核心分析价值 |
|------|------|-------------|
| **Scrivener** | 长篇写作软件 | 线索板（Corkboard）、大纲视图（Outliner）、场景卡片、编译系统、目标追踪 |
| **Final Draft** | 专业编剧软件 | 场景列表（Scene List）、Beat Board、大纲视图、结构分析报告 |
| **Manuskript** | 开源写作软件 | 情节工具（情节网/三幕结构）、角色卡系统、世界观构建向导 |
| **yWriter** | 长篇写作软件 | 章节/场景管理器、项目笔记、计时目标 |

---

## 分析维度

对每个工具，提取以下内容：

### 1. 结构管理机制
- 用户如何组织长篇内容？（场景/章节/线索的管理方式）
- 有什么视图或工具帮助作者"看到"结构？
- 如何追踪多个叙事线的状态？

### 2. 可借鉴设计概念
- 描述一个可借鉴的具体设计
- 这个设计解决了用户的什么痛点？
- 如果轻量化到月笙中，最小版本应该是什么样？

### 3. 与已有功能的关联
- 对应月笙现有功能中的哪一块？
- 是否与 T-030 已评估的 F-01~F-08 中的设计互补？
