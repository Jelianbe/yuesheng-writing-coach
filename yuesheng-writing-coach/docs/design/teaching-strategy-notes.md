# 教学策略层分析

> 来源：外部深度分析
> 日期：2026-06-04
> 标签：教育学、教学策略、人格偏移

---

## 核心洞察

**发现问题 ≠ 教会别人解决问题**——这中间隔着整个教育学。

## 三层架构

| 层级 | 职责 | 示例 | 月笙状态 |
|------|------|------|----------|
| **诊断学** | 发现问题 | "人物动机不足" | ✅ 已实现 |
| **训练学** | 怎么练 | "做专项训练" | 🟡 规划中 |
| **教育学** | 怎么教 | "用什么方式让这个人愿意做训练" | ❌ 刚触及 |

## 关键问题：陪伴化偏移

月笙最危险的偏移不是 Agent 化，而是**陪伴化**。

大模型默认擅长的是"陪伴学"（共情、鼓励、认可），不是教学。

### 豆包式 vs 老编辑式

| | 豆包式 | 老编辑式 |
|--|--------|----------|
| 用户说"我不会" | "没关系哦~说明你很有潜力" | "你不是缺灵感，你缺筛选标准。发三个出来。" |
| 核心目标 | 让用户舒服 | 推进创作 |
| 价值 | 情绪价值 | 教学价值 |

### 用户类型矩阵

| 类型 | 特征 | 教学方式 |
|------|------|----------|
| 新手 | 16岁/缺自信 | 鼓励+分步引导 |
| 老手 | 写了100万字老扑街 | 直接反馈，不说废话 |
| 理工型 | 喜欢逻辑 | 问题→原因→证据→方案 |
| 感性型 | 感性创作者 | 案例→感受→示范 |

## Teaching Strategy 教学策略层

不是决定**说什么**，而是决定**怎么说**。

```json
{
  "userType": "newbie",
  "confidence": "low",
  "thinkingStyle": "emotional",
  "teachingStyle": "encouragement_first"
}
```

或

```json
{
  "userType": "experienced",
  "confidence": "high",
  "thinkingStyle": "analytical",
  "teachingStyle": "direct_feedback"
}
```

同一个诊断，输出完全不同。

## 月笙核心信念

- 月笙最终教的不是**小说**，而是**人**
- 人有：学习动机、学习风格、认知水平、抗压能力、目标差异
- 这比小说复杂得多

## 落地建议

不用一开始研究整个教育学（无底洞）。

**拆老师**：找老编辑、老作者、写作老师、培训讲师，问：
> "当一个学生犯这个错误时，你会怎么教？"

## 结论

月笙未来最大的资产，可能不是**写作知识库**（什么是对的），而是**写作教学知识库**（怎样让别人学会）。

后者往往比前者难得多。
