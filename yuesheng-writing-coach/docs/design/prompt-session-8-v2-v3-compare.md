# 会话8提示词：V2.2 ↔ V3.4 Prompt 对比提取丢失精华

## 任务

对比月笙写作教练的两个 Prompt 版本——V2.2（单一 Prompt 架构）和 V3.4（多 Agent 架构的 Agent Prompt），提取 V2.2 中有而 V3.4 中丢失的教学逻辑、流程约束和话术模板。

## 必须读取的文件

1. `historical-archive/月笙_Agent_Prompt_V2.2.md` — 旧版 Prompt（约 480 行，14 个章节）
2. `resources/prompts/yuesheng-prompt-v3.md` — 当前 Prompt（V3.4，约 180 行，10 个章节）

## 执行步骤

### Step 1：逐章节对比

逐章节对比两份 Prompt，标记每个内容块的保留状态：

| 标记 | 含义 |
|:----:|------|
| ✅ 保留 | V3.4 有等价或更强的内容 |
| ⚠️ 弱化 | V3.4 有但简化了（丢失了细节/示例/约束）|
| ❌ 丢失 | V3.4 完全没有 |

### Step 2：提取丢失精华

对标记为 ⚠️ 或 ❌ 的内容，提取原文并评估是否需要补回 V3.4：

每条提取至少包含：
- **章节**：V2.2 的章节名
- **丢失程度**：完全丢失 / 弱化
- **原文内容**：关键原文摘录
- **为什么重要**：这个内容解决什么问题
- **补回建议**：建议补回 V3.4（修改当前 Prompt）/ 建议转为代码逻辑 / 建议丢弃

### Step 3：输出提取报告

### 6 个关键丢失

| 优先级 | 丢失内容 | 为什么重要 |
|:------:|---------|-----------|
| P0 | **四层架构 + Layer 1 不可见铁律** | 这是产品哲学的核心。没有这个铁律，AI 可能在实际对话中输出诊断编号/评分给用户，破坏"隐性诊断，显性成长"的设计原则 |
| P0 | **教学动作触发逻辑映射表** | V2.2 有"P003 情绪标签化→A004 现实锚点→如果是真人第一反应会是什么？"的完整映射。V3.4 只有动作列表没有映射，AI 需要自己判断哪个动作对应哪个症候 |
| P0 | **三阶段教学流程 + 可验证标志** | V2.2 的每个阶段都有结束标志（"用户至少说了一句'对'"），这是教学进度控制的关键 |
| P1 | **场景详细话术（特别是辩驳和改写）** | V2.2 有逐句对照格式、按态度的结尾方式、改写 3 种情况的完整话术。V3.4 只有一句话规则 |
| P1 | **教学边界声明** | 首次对话的固定声明是建立教学关系的起点 |
| P2 | **外部资源提及规则 + 防幻觉命令** | 防止 AI 编造出版物内容 |

## 核心原则

1. **对比对象是 V2.2 和 V3.4**。其他版本（V1.x、V2.1 等）不需要参与
2. **客观对比，不预设结论**。如果 V3.4 某个部分实际更强（比如态度系统从两档升级为三档），如实标注而非一味说"丢失"
3. **补回建议要可行**。标注"建议改 Prompt"还是"建议转为代码逻辑"，不要只说"应该保留"，要说清楚"怎么保留"

### 补回建议的判断标准

| 建议类型 | 适用场景 |
|---------|---------|
| **改 Prompt** | 需要 AI 在对话中自主判断的内容（话术、流程、映射） |
| **转为代码逻辑** | 可以精确判定和执行的内容（如"一次只聚焦一个问题"已在 V3.4 的回复控制中实现）|
| **转为配置** | 可以结构化存储的内容（如教学动作映射、外部资源清单）|
| **丢弃** | 已被代码取代（如记忆系统）或不再适用 |
