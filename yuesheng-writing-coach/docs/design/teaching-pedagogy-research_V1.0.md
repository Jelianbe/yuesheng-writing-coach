# 文字创作教学方案教育学调研（V1.0）

> 调研类型：教育学 / 教学法调研（"怎么教人写作"）
> 范围：优秀文字创作教学方案 → 短篇小说教学 → 小说人物教学 → 动漫角色设计教学 → 游戏 / NPC 角色刻画教学
> 目的：为「月笙写作教练」补充"教学方法层"的资产，与既有 `education-theory-fragments.json`（理论碎片）和 `teaching-method-inventory.json`（方法盘点）对齐，找出可复用的教练行为。

## 0. 调研结论速览（给舰长先看）

1. **所有优秀方案都在做"渐进释放责任"（I do → We do → You do）**：教师先示范，再陪练，最后放手。这与本项目的"不替用户写、不替用户决定"哲学完全兼容——关键是把"教师示范"改造成"AI 展示范例（非用户文本）"，而非替用户起草。
2. **"由内而外"是跨域通用内核**：小说、动漫、游戏三类角色设计，无一例外都是"先定心理 / 动机 / 原型 → 再定外部表现（文字行为 / 视觉造型）"。这与本项目的 `C2-002 Want/Need/Lie/Wound/Truth` 人物卡同构。
3. **"展示而非告知"是跨域统一练习法**：小说用"只写动作不写情绪"的行为练习，动漫用"剪影测试 / 姿态传达态度"，游戏用"用行为而非描述揭示特质"。直接对应本项目 `P007 展示与告知`。
4. **矛盾与缺陷制造真实感**：小说用"矛盾地图"，动漫用"色彩 / 姿态反差"，游戏用"正面 + 负面特质的平衡 + 矛盾特质"。直接对应本项目 `P010 OC 平面化`。
5. **引导式提问比告知更有效**：最反复出现的教练行为是"接下来发生什么？这个选择如何影响角色？"——一类可沉淀为诊断 / 引导提问库（补 `teaching-method-inventory` 的 C 类缺失）。

## 1. 教育学底层基石（所有方案共享）

### 1.1 过程写作法（Process Writing）
- **Donald Murray**《Teach Writing as a Process Not Product》(1972)：写作不是成品，而是"一系列理性的决策与步骤"；主张自由写作（freewriting）与多稿迭代，让意义在写作中浮现（"我们写作不是为了沟通，而是为了理解"）。
- **Peter Elbow**《Writing Without Teachers》(1973)：自由写作 + 同伴互评，用来绕过自我审查；核心洞见是"生成"与"批评"两种心智模式互相干扰，必须分开。
- **Janet Emig**(1971)：用出声思维（think-aloud）证明写作是递归的，而非线性。
- **Lucy Calkins**《The Art of Teaching Writing》(1983/1986)：把过程法落地为儿童写作工作坊（workshop），核心是"所有孩子都能学写作"，主张给孩子"声音"与"属于自己的故事"。
- **National Writing Project (NWP)**：教师即写作者、教师教教师；理论基础是过程理论 + 社会建构主义。

### 1.2 写作工作坊模型（Writing Workshop Model）
源自 **Donald Graves**（1970s，观察到孩子只被教"接收"信息而非"发送"），由 Calkins 普及。典型结构：
- 迷你课（mini-lesson，教师示范一个技巧）
- 独立写作（学生实践）
- 一对一晤谈（conferring，教师问"你的核心点是什么？"）
- 分享（share）

### 1.3 渐进释放责任（Gradual Release of Responsibility）
**Pearson & Gallagher**(1983)：教学节奏 = 教师示范（I do）→ 引导练习（We do）→ 独立创作（You do）。这是 1.1–1.2 的方法论命名，也是本项目最该吸收的教学节奏。

### 1.4 元认知与反思（Metacognition & Reflection）
- **Writer's Memo（作者备忘录）**：源自 Elbow / Donald Graves / Calkins 谱系，要求学生交稿时附一份"我做了什么决策、为什么改"的备忘录；不评分，用来培养元认知（Flavell）与反思性实践（Schön）。
- 映射到本项目：`R-003 / R-014`（高级用户 → 反思驱动 + 自我诊断）。

### 1.5 社会建构主义与同伴互评（Social Constructivism & Peer Review）
- 过程写作的协作传统源自 **Vygotsky** 社会文化理论（学习发生在社会互动中）。
- 经典互评协议："两颗星 + 一个愿望"（two stars and a wish）——先给两个优点，再给一个改进建议。
- 映射到本项目：`R-004`（展示力不足 → 社会学习 Bandura）。

### 1.6 认知负荷与图形组织者（Cognitive Load & Graphic Organizers）
- **Sweller** 认知负荷理论：一次只聚焦一个问题（映射到 `R-011` 单症候聚焦）。
- 故事地图（story map）/ 图形组织者：把抽象的"张力 / 结局"视觉化，降低认知负荷（Flip Education 的 Storyboard Relay 即用此法）。

### 1.7 范本阅读（Mentor Texts / Reading Like a Writer）
- **Katie Wood Ray** 一脉：让学生像作家一样读（read like a writer），用真实好文当范本，拆解作者"怎么做到的"。映射到本项目：`R-001`（初学者 → 案例驱动，先看到"好的长什么样"）。

## 2. 短篇小说教学方案

### 2.1 通用工作坊结构（8 年级示例，Educator Lab）
元素导入 → 头脑风暴 → 人物发展（建人物档案：外貌 / 性格 / 背景）→ 情节结构（ exposition / rising / climax / falling / resolution）→ 描述性语言 → 写作时间 → 同伴互评 → 修改编辑 → 分享与反思。

### 2.2 "短篇训练营"的渐进释放（learningcorner.co）
- **Big Four（四要素）**：Character（要有目标）、Setting（可制造冲突）、Conflict（故事引擎）、Resolution（赋予意义）。
- **极简三幕**：Setup(~25%) → Confrontation(~50%) → Resolution(~25%)。
- **I Do / We Do / You Do**：
  - I Do：教师用一个例子填完结构（"比赛前 10 分钟面粉用光了的面包师"）。
  - We Do：师生共填"不可能的物件"提示（锈钥匙 / 旧照片 / 单只红鞋开始做不可能的事）。
  - You Do：20 分钟限时草稿冲刺（400–600 字），完成即达标。
- **成功标准（Success Criteria）**：清晰主角 + 明确冲突 + 三幕逻辑线。

### 2.3 可视化 / 拼图式活动（Flip Education）
- **Storyboard Relay（故事板接力）**：两人六格分镜，每两分钟传递补充细节——把情节"画"出来。
- **Revision Carousel（修改旋转站）**：草稿放四个站点（结构 / 人物 / 语言 / 结尾），每组 7 分钟轮转留便利贴反馈。
- **Story Swap and Edit（互换互改）**：搭档交换初稿，用清单找"主角的冲突 + 一句描述性语言"，给一个优点 + 一个修改建议。
- **Whole Class Story Chain（全班故事链）**：教师起头，每人加一句，志愿者收尾——讨论"这个事件是否改变了角色目标？"
- **教师引导提问（贯穿所有活动）**：*"接下来发生什么？这个选择如何影响角色？"*

### 2.4 经典教案（ERIC ED249515）
- 全班共建 3 个角色（着装 / 言谈 / 环境 / 爱好 / 道德 / 行为 / 思想，写在黑板上当参照）。
- 选主角 / 反派，标动态 / 静态角色。
- 冲突头脑风暴（可能发生的事件写在黑板）。
- 朗读马克·吐温《Old Times on the Mississippi》开头，示范氛围与场景重要性。
- 初稿后同伴互改：检查视角一致、对话有效。
- 次日小组朗读，听"流畅度与情节发展"。

### 2.5 短篇 vs 长篇的训练差异（对教练的意义）
短篇强调**激光聚焦、每字必争、极简三幕**；长篇允许支线。教练在做"短篇小说专项"时应：用 Big Four + 极简三幕做"重构大纲"练习，而非套用完整英雄之旅。

## 3. 小说人物教学方案

### 3.1 Want / Need 核心问题（Joanne Furniss, Creative Spark）
- 中心问题："这个角色想要什么？又需要什么？"情节往往是否定其"想要"、给予其"需要"。
- 练习 1（秘密）：以角色口吻写"我从未告诉任何人，但是……"的私密信。
- 练习 2（三视角）：同一咖啡馆场景，写朋友 / 陌生人 / 角色自己三种视角——暴露"想要的"与"被别人看到的"之间的错位。
- 练习 3（一句话钉死）：把 want/need 压缩成一句澄清句。

### 3.2 四支柱模型（noveling.dev）
1. **Want vs Need（内在冲突引擎）**：若角色第 1 章说想要的，一实现就满足了——说明没找到 true need。Need 应指向心理创伤或错误信念。
2. **Flaw–Fear–Backstory 链条**：缺陷不是怪癖，而是防御机制（被背叛 → 怕脆弱 → 推开人）。随机缺陷 = 扁平。
3. **矛盾原则（Contradiction）**：真实的人矛盾。每个特质后加"但 also…"（忠诚，但被爱的人威胁时会质疑权威）。
4. **微刻画（Micro-Characterization）**：具体细节卖真实感（压力下按字母顺序整理香料、焦虑时数三下、口袋里永远带的东西）。

### 3.3 行为优先练习（"Breath and Bone", fiction-writing-tips）
- **Behavior-Only Scene**：500 字，只写动作 / 对话 / 物理细节，绝不写情绪词——然后识别读者"反而感受到了什么"。→ 直接训练 `P007 展示与告知`。
- **Irreversible Choice**：让角色在两个都珍视之物间选，任一选择都造成不可撤销的损失，写"犹豫"而非"决定"。
- **Backstory Pressure Test**：写一段过去背景，再写当下场景——背景一句不提，但全部通过行为被"感到"。
- **Contradiction Under Stress**：定义一对矛盾（"我重视诚实" vs "我为避免冲突而撒谎"），高压下分别按"信念"和"真实行为"写两遍，比较哪版更有张力。
- **Silent Breakdown**：不准对话 / 内心独白 / 情绪标签，只用动作 + 环境 + 感官写崩溃。
- **Wound Echo**：定义 formative wound（如被遗弃），写当下场景 + 过去场景，让读者自行连线。

### 3.4 矛盾地图与伤口—想要管线（BubbleCow）
- **矛盾地图**：列 5 个表面特质，再写反面；写 300 字场景让两面都通过行为 / 对话显现（非描述倾泻）。例：Charming↔Blunt，Loyal↔Self-preserving。
- **Wound → Lie → External Want → Real Need 管线**：创伤生出错误信念，错误信念生出可见目标，目标掩盖真实需求。写一段独白，角色为表面目标辩护却泄露深层需求，结尾让逻辑裂开一道缝。

### 3.5 15 个练习清单（writingpeers，精选）
完整人物描述 / 人物访谈（完美的幸福是什么？最大恐惧？）/ 人生事件时间线 / 情绪探索场景 / 对话练习 / 换视角重写 / 道德困境 / 人物演化小故事 / 爱好与媒介偏好 / 社交互动场景 / 现实灵感 / 提示词深挖 / 真心话大冒险 / 视觉速写 / 重要关系地图。

## 4. 动漫 / 漫画角色设计教学

### 4.1 先定人格，再定视觉（Domestika, Manga Character）
- **人格先于设计**：画之前先写——"他是谁？几岁？住哪？想要什么？怕什么？"有趣的角色生于冲突，而非造型。
- **原型 → 视觉决策**：能量型主角用更动态的线条与表情；内敛角色用收拢姿态与克制眼神。
- **眼睛传达性格**：圆亮眼 = 乐观天真；细长 / 锐眼 = 坚定 / 冷 / 神秘。
- **姿态传达态度**：自信者躯干打开、肩平；怯懦者微前倾。
- **剪影测试（Silhouette Test）**：把角色全涂黑仍要可辨认——清晰动态的剪影 = 好设计。
- **服装即视觉叙事**：当代都市 → 当代装；奇幻 → 制服 / 披风 / 符号元素。配饰（反复出现的配件 / 特定发型 / 疤）强化识别。
- **色彩心理学**：暖饱和 = 能量热情；冷 / 去饱和 = 冷静神秘。主色 2–3 个即可。

### 4.2 概念化流程（liveanime.org）
- 角色定位（英雄 / 反派 / 导师 / 搭档）→ 独特背景（来自哪？什么事件塑造了性格？梦想？）→ 色彩板（黄 / 粉 = 开朗；黑 / 藏青 = 神秘）→ 显著特征（眼形 / 发色 / 衣着）→ **MBTI 分型**（内向 / 外倾、思考 / 情感）作为性格骨架 → 关系网 → 招牌动作与表情幅度。

### 4.3 由结局反推开头 + 避免陈词滥调（WikiHow, Create-an-Anime-OC）
- 先定角色"结尾变成了谁"，再决定"开头怎么呈现"，使成长有逻辑。
- 避免"女友被杀 / 幼年孤儿 / 永远的新转学生"等启动式陈词滥调；追求原创。
- **设计线索从性格 / 历史来**：务实的女性角色穿平底而非高跟；Mako（《科拉传奇》）永远戴父亲的围巾——用细节暗示过去。

### 4.4 五步法（ihowlist）
基础认知 → 人格与背景 → 物理外观（草图探索发型 / 五官 / 体型 / 服装）→ 上色与阴影 → 练习精炼（社区求反馈）。

### 4.5 对小说教练的迁移
动漫的"剪影 / 姿态 / 色彩 / 配饰"本质是**把内在特质转译为外部符号**。小说教练可借用同一思路：引导用户为角色找"视觉化的行为符号"（如"她紧张时按字母顺序整理香料"），这正是 3.2 的微刻画。

## 5. 游戏 / NPC 角色刻画教学

### 5.1 Want / Wound / Voice 框架（ttrpg-games, Designing NPCs for Cultural Conflict）
- **每个重要 NPC 三要素**：Want（即时目标 + 深层长期动机）、Wound（塑造其决策的过往事件）、Voice（使其脱颖而出的言语 / 身体习惯）。
- **即时 want 驱动单次互动，深层 want 塑造长期关系**。
- **Deep Investment vs Shallow Investment**：主线 NPC 投资详细背景与关系；交易型背景 NPC 只给够撑场的最低细节（与 Sweller 认知负荷一致）。
- **10 秒描述测试**：一句话不用刻板印象概括角色，若做不到 = 还需独特特质。

### 5.2 One-Word / 偷点子 / 晋升系统（michaelghelfistudios, NPC Creation）
- **One-Word Method**：玩家聊到意外 NPC 时，挑一个词（如"多疑"），玩到底——第一印象要清晰不要复杂。
- **Stealing Player Ideas**：玩家猜"他肯定为盗贼公会干活"——记下最好的一个，让它成真，玩家会觉得自己"推理成功"。
- **Promotion System**：被玩家反复提及 / 牵挂的跑龙套 NPC，每次出场加一个新细节（爱吃的零食 → 怕高 → 要攒钱救的妹妹），"边飞边造飞机"。
- **Useful First, Then Humanity**：先有用（折扣铁匠 / 可靠线人），再加人性（铁匠女儿生病）；完美 NPC 无聊，有缺陷的才像朋友。
- **Voice & Mannerism Toolkit**：语速 / 音量 / 句式（完整句 vs 碎片）、姿态（农民佝偻 / 贵族挺直）、手部（摊开 / 握拳）、眼神（直视 / 闪躲）、怪癖（重复句尾词 / 用提问回答提问 / 思考时数手指）。
- **Index Card Method**：正面写名字 / 角色 / 一句话描述 / 显著特质；背面写互动笔记 / 关系 / 玩家行为。

### 5.3 动机分层与情境预案（roleplayingtips, RPT #114）
- **动机优先级**：这次遭遇想要什么 → 这周 / 月 → 12 个月 → 长期目标。
- **情境反应预案**：被攻击 / 被收买 / 被威胁 / 被背叛 / 被奉承时分别怎么反应——提前写几下，演出时顺滑。
- **反刻板**：富商之子与街头长大者态度迥异；"总道歉的国王"比"高傲疏离的国王"更难忘。
- **单一怪癖**即可让次要 NPC 出彩（嗜巧克力 / 过度多疑 / 自以为重要）。

### 5.4 特质设计原则（companyeducator, T14 Advanced NPC Design）
- 特质简单但有意义；混合特质避免刻板；特质驱动决策（贪婪者无理由不分享战利品）。
- 正负平衡（纯善扁平，纯恶无层次）；用行为 / 对话 / 环境"展示而非告知"（紧张者拨弄戒指）；特质随故事演化（懦弱守卫经历袭击后变勇敢）。

### 5.5 对小说教练的迁移
游戏的 Want/Wound/Voice 与小说的 Want/Need/Wound/Lie 几乎同构——**这是跨域最强证据**，证明本项目 `C2-002` 人物卡的内核放之四海皆准。游戏的"让玩家改变 NPC""可见的成长""用行为展示特质"可直接转化为教练的"让用户看到自己角色在关系中的变化""用场景行为而非形容词刻画"等练习。

| 4 | **渐进释放节奏** | I Do/We Do/You Do | 草图迭代 + 社区反馈 | 跑龙套→晋升系统 | `R-001/R-008` 脚手架 |
| 5 | **引导提问 > 告知** | "接下来发生什么？" | "这个选择如何影响角色？" | "他想要什么？" | 诊断 / 引导提问库（C 类缺失） |
| 6 | **反思 / 元认知** | Writer's Memo | 迭代精炼 | 玩家改变可见 | `R-003/R-014` |

**一句话总结**：无论教小说、动漫还是游戏角色，顶级方案都在做同一件事——**先帮学习者建立"内在真相"（动机 / 伤口 / 矛盾），再用具体、可观察的外部符号（文字行为 / 视觉造型 / 互动习惯）把它兑现出来**，并且全程用"示范 → 陪练 → 放手 + 反思"的节奏推进。这正是月笙教练"找根因、不替写"哲学的学科级背书。

## 8. 给月笙教练的具体落地建议

**建议 1 — 教练版渐进释放（最优先）**
把 Pearson & Gallagher 的 I/We/You 改造为：
- **I-Show（AI 展示范例）**：用"一个陌生例子"演示技巧，**不碰用户文本**（守 R-021 不替写）。
- **We-Guide（引导陪练）**：给用户一个填空式结构（如 Big Four 表 / 矛盾地图），AI 用提问帮其填，而非代填。
- **You-Do（用户独立 + 反思）**：用户写自己的，AI 用 Writer's Memo 式问题引导其自评（"你这一版和上一版，改了什么？为什么？"）。

**建议 2 — 新增「行为优先」练习动作（治 P007）**
给场景，要求"只写动作 / 对话 / 环境，不许出现情绪形容词"，再让用户自己读出"读者反而感受到了什么"。

**建议 3 — 新增「矛盾地图」练习动作（治 P010）**
让用户给角色列 3 个特质，每个加"但 also…"；再写 300 字场景让两面都通过行为显现。

**建议 4 — 把 Want/Wound/Voice 内化进 C2 人物卡与诊断提问**
在人物卡与诊断提问中显式出现 Want / Wound / Voice（或 Lie/Truth），使小说—动漫—游戏三域共用同一内核。

**建议 5 — 引导提问库（补 C 类缺失）**
沉淀 5–8 条跨域验证过的引导提问，作为诊断 / 陪练的默认话术骨架。

**建议 6 — 短篇小说专项（补 F 类缺失）**
提供"Big Four + 极简三幕重构大纲"练习，区别于长篇的英雄之旅路径。

**建议 7 — 反思即教学（强化 R-003/R-014）**
用"作者备忘录式"结构化问题替代泛泛的"写得不错"，把每次修改变成元认知训练。
