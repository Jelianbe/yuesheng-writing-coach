## 四、蒸馏流程（2阶段简化版）

### 阶段 1：定向提取

按症候选择作品和章节，阅读并标记相关写法：

1. **选择目标**：按以下优先级逐个症候蒸馏
   - P0（零覆盖）：P003 → P005 → P007 → P010
   - P1（弱覆盖）：P001 → P004 → P009
   - P2（过度覆盖，暂停）：P006、P002

2. **阅读标记**：对每个目标章节，标记与该症候相关的写法

3. **双重过滤**：
   - 必要性过滤：去掉这个手法，故事会不会变差？会→保留
   - 可教性过滤：教给新手，他能不能一个下午学会？能→beginner，需基础→intermediate/advanced

### 阶段 2：结构化入库

每条通过过滤的技法按以下格式结构化：

```markdown
### TQ-0XX：技法名称

**来源**：作品名 / 作者名
**难度**：beginner / intermediate / advanced
**适用症候**：P00X（症候名称）
**类别**：开篇/节奏/人物/世界观/情绪/对话/场景

#### 技法说明
（100-200字描述技法核心。说清楚"怎么做"，不说"为什么重要"）

#### 传统 vs 网文
| 维度 | 传统小说 | 网文 |
|------|---------|------|
| 差异点 | ... | ... |

#### 训练方法
1. 步骤一（具体可执行）
2. 步骤二（具体可执行）
3. 步骤三（具体可执行）
```

**编号规则**：
- TQ-025~099：网文特有技法（从 TQ-025 续编）
- TC-010~099：传统技法网文适配版（从 TC-010 续编）
- TN-002~099：传统技法不适用（标注即可）

## 八、工作原则

1. 只关心"是否帮助用户成长"，不关心"分析是否优雅"
2. 所有产出必须是"用户可执行的技法"，不是"文学评论"
3. 任何"需要天赋才能掌握"的手法 → 丢弃（才华不可教）
4. 优先提取"可独立教学的技法"，其次提取"可改造的思路"
5. 每条技法必须能回答：对应哪个症候？怎么练？适合谁？
6. 如果无法回答这3个问题 → 这个技法不能入库

请先确认你理解了以上要求，然后读取文件，开始从 P003（情绪标签化）蒸馏。
