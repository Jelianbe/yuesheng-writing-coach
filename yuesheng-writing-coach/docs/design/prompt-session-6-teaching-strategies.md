## 执行步骤

### Step 1：分析案例，提取教学策略（0.3d）

从 case-ayuan-rebirth-ch1.md 中，阅读完整对话，逐轮分析：

每一轮，你都要提取：
- **学员状态**（什么阶段、什么心态）
- **你使用的教学动作**（A004/A009/A010/A011 等）
- **话术模板**（你具体说了什么，可提炼为填空模板）
- **学员反馈**（效果如何、是否认知升级）
- **适用条件**（什么场景下可以用这个策略）

例如，A009 信心确认的提炼结果：

```markdown
### S-002：信心确认（来自 A009）

**来源**：case-ayuan-rebirth-ch1.md 第3轮

**适用条件**：
- 学员有正确直觉但自我审查（"我觉得拖沓"）
- 学员有设计但不敢用（"想重点写又觉得没必要"）

**话术模板**（四步法）：
1. 确认直觉："{设计元素}是你设计的，它承担了{功能}的功能，这个判断是对的。"
2. 翻转判断："你觉得{问题}，是担心{担忧}，还是它本身{问题陈述}？"
3. 功能验证："{设计元素}在{位置A}和{位置B}有双重功能，不是冗余。"
4. 信心交付："你直觉是对的，只需要找到位置。"

**效果**：学员顿悟（"我去，感觉来了"）
```

对其他动作（A004/A010/A011/方法论交付）做同样的提取。

## 核心原则

1. **忠实于真实案例**：话术模板要基于 case-ayuan 中你实际说过的话，而不是编造。可以总结归纳，但不能发明不存在的话术
2. **留出适配空间**：模板中的 {placeholder} 应该保留足够的灵活性
3. **来源可追溯**：每个策略标注来源（哪个案例、哪一轮、学员反馈如何）
4. **禁忌比方法更重要**：每个策略必须包含"什么情况不能用"，这是教育学中"不出错"比"出彩"更重要的原则（来自你在案例第4轮展示的边界校准能力）
