# 月笙诊断系统增强方案 V2.0（完整版）

## 一、方案概述

### 1.1 项目背景
月笙写作教练系统是基于大语言模型的 AI 写作教练，定位为"教练"而非"助手"：
- 不替用户写
- 不替用户决定  
- 帮用户看清问题，让用户自己解决

### 1.2 核心目标
- 提升诊断效率，实现分层智能诊断
- 建立用户成长轨迹记录系统
- 为后期个性化服务奠定数据基础
- 解决智能体上下文关联受限的技术问题

```typescript
import { Message, DiagnosisEntry, SyndromeMatch, Action, TrainingTask } from '../shared/types';

/**
 * 分析用户消息，生成诊断条目
 */
export function analyzeMessage(content: string): DiagnosisEntry | null {
  const matches: SyndromeMatch[] = [];

  for (const [syndromeId, signals] of Object.entries(SYNDROME_SIGNALS)) {
    let totalScore = 0;
    const triggeredSignals: string[] = [];

    for (const signal of signals) {
      if (signal.pattern && signal.pattern.test(content)) {
        totalScore += signal.weight;
        triggeredSignals.push(signal.keyword);
      }
    }

    if (totalScore >= 2) {
      const severity = totalScore >= 5 ? 'L3' : totalScore >= 3 ? 'L2' : 'L1';
      matches.push({
        id: syndromeId,
        name: getSyndromeName(syndromeId),
        score: totalScore,
        severity,
        signals: triggeredSignals,
      });
    }
  }

  if (matches.length === 0) return null;

  // 排序：优先级高的在前，最多保留 2 个
  matches.sort((a, b) => (ACTION_PRIORITY[a.id] || 99) - (ACTION_PRIORITY[b.id] || 99));
  const topMatches = matches.slice(0, 2);

  // 生成建议动作
  const actions = topMatches.flatMap(m =>
    (ACTION_MAP[m.id] || []).map(id => ({
      id,
      name: getActionName(id),
      description: getActionDescription(id),
      priority: ACTION_PRIORITY[m.id] || 99,
    }))
  );

  // 计算整体严重度
  const maxScore = Math.max(...matches.map(m => m.score));
  const severity = maxScore >= 5 ? 'severe' : maxScore >= 3 ? 'moderate' : 'mild';

  return {
    syndromes: topMatches,
    suggestedActions: actions,
    severity,
    confidence: Math.min(maxScore / 5, 1.0),
  };
}

/**
 * 基于最近N轮消息的综合诊断
 */
export function analyzeRecentSession(messages: Message[], windowSize = 3): DiagnosisEntry | null {
  const recentUserMessages = messages
    .filter(m => m.role === 'user')
    .slice(-windowSize);
  
  // 合并最近用户消息进行分析
  const combinedContent = recentUserMessages.map(m => m.content).join('\n');
  return analyzeMessage(combinedContent);
}

/**
 * 动态计算优先级（考虑严重度+紧急程度）
 */
function calculateDynamicPriority(matches: SyndromeMatch[]): SyndromeMatch[] {
  return matches.sort((a, b) => {
    // 第一优先级：严重度（分数高的先处理）
    if (a.score !== b.score) return b.score - a.score;
    
    // 第二优先级：紧急程度
    const urgencyOrder: Record<string, number> = {
      P004: 1, P006: 2, P005: 3, P003: 4, P001: 5, P002: 6, P007: 7,
    };
    return (urgencyOrder[a.id] || 99) - (urgencyOrder[b.id] || 99);
  });
}

 * 获取推荐训练任务
 */
export function getRecommendedTasks(syndromeIds: string[]): TrainingTask[] {

}
```

### 2.3 诊断流程设计

#### 即时诊断流程
```
用户输入文本
    ↓
渲染进程: chatStore.sendMessage()
    ↓
IPC: chat:send → 主进程
    ↓
主进程: 构建消息列表 (System Prompt + 历史 + 新消息)
    ↓
主进程: ApiProxy.chatStream() → 流式调用 AI API
    ↓
IPC: chat:stream:data → 渲染进程 (实时显示)
    ↓
流结束 → 主进程: enhancedDiagnosis() 
    ↓
诊断引擎: analyzeMessage() + analyzeRecentSession() + analyzeBasedOnUserPattern()
    ↓
生成诊断条目 + 推荐任务 + 更新用户画像
    ↓
IPC: diagnosis:update → 渲染进程 (更新诊断面板)
    ↓
主进程: 保存到 SQLite (诊断历史 + 成长轨迹)
```

## 八、数据流向与权限控制

### 8.1 数据流向
```
用户输入 → 诊断引擎分析 → 结构化数据存储 → 前端展示（过滤后）
     ↓
诊断历史积累 → 用户画像生成 → 个性化推荐 → 成长轨迹记录
     ↓
成长轨迹 → 进步可视化 → 用户成就感 → 长期使用
```

### 8.2 权限控制
- **诊断原始数据**：仅系统内部使用，不对外展示
- **用户可见内容**：经过过滤的中文描述，无技术术语
- **成长轨迹**：用户可查看自己的完整记录
- **系统内部**：包含完整的分析过程、关键判断依据
