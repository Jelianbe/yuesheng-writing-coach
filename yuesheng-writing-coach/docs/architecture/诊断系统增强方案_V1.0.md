# 月笙诊断系统增强方案 V1.0

## 一、方案概述

### 1.1 目标
- 提升诊断效率，实现分层智能诊断
- 建立用户成长轨迹记录系统
- 为后期个性化服务奠定数据基础

### 1.2 核心理念
- 诊断表不仅是后台数据，更是用户成长的见证
- 每一行记录都代表用户写作路上的一个足迹
- 最终形成完整的成长轨迹，实现陪伴式教学

## 二、分层诊断系统设计

### 2.1 数据库表结构

#### 诊断历史表 (diagnosis_history)
```sql
CREATE TABLE diagnosis_history (
  id TEXT PRIMARY KEY,
  session_id TEXT NOT NULL,           -- 会话ID
  message_id TEXT NOT NULL,           -- 消息ID
  user_input TEXT,                    -- 用户原始输入
  syndromes TEXT,                    -- JSON: 识别到的病症列表
  suggested_actions TEXT,             -- JSON: 建议动作列表
  severity TEXT,                     -- mild/moderate/severe
  confidence REAL,                   -- 0-1 置信度
  recommended_tasks TEXT,             -- JSON: 推荐训练任务
  ai_response_summary TEXT,           -- AI 实际响应摘要
  created_at INTEGER,                -- 创建时间戳
  FOREIGN KEY (session_id) REFERENCES sessions(id)
);
```

#### 用户画像表 (user_profile)
```sql
CREATE TABLE user_profile (
  id TEXT PRIMARY KEY DEFAULT 'default',
  total_sessions INTEGER DEFAULT 0,    -- 总会话数
  total_messages INTEGER DEFAULT 0,    -- 总消息数
  most_common_syndrome TEXT,          -- 最常犯的病症
  syndrome_frequency TEXT,            -- JSON: 各病症出现频率统计
  progress_trend TEXT,                -- JSON: 进步趋势数据
  preferred_attitude TEXT,            -- 用户偏好的态度档位
  active_tasks TEXT,                  -- JSON: 当前进行的任务
  created_at INTEGER,
  updated_at INTEGER
);
```

#### 成长轨迹表 (growth_journey)
```sql
CREATE TABLE growth_journey (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,              -- 用户ID
  session_id TEXT,                    -- 关联会话
  timestamp INTEGER,                  -- 时间戳
  diagnosis_summary TEXT,             -- 诊断摘要
  task_completed TEXT,                -- 完成的任务
  progress_milestone TEXT,            -- 里程碑事件
  reflection_notes TEXT,              -- 用户反思记录
  coach_feedback TEXT,                -- AI教练反馈
  created_at INTEGER
);
```

```typescript
// 诊断引擎增强版
export async function enhancedDiagnosis(
  sessionId: string,
  userMessage: string,
  recentMessages: Message[]
): Promise<DiagnosisEntry> {
  
  // 1. 即时诊断（当前消息）
  const instantDiagnosis = analyzeMessage(userMessage);
  
  // 2. 会话级诊断（最近3轮）
  const sessionDiagnosis = analyzeRecentSession(recentMessages, 3);
  
  // 3. 用户画像参考（读取用户历史模式）
  const userProfile = getUserProfile(sessionId);
  const patternBasedDiagnosis = analyzeBasedOnUserPattern(userMessage, userProfile);
  
  // 4. 合并诊断结果，动态调整优先级
  const mergedDiagnosis = mergeAndPrioritize(
    instantDiagnosis,
    sessionDiagnosis,
    patternBasedDiagnosis
  );
  
  // 5. 推荐个性化训练任务
  const personalizedTasks = getPersonalizedTasks(mergedDiagnosis, userProfile);
  
  return {
    ...mergedDiagnosis,
    recommendedTasks: personalizedTasks,
    userPattern: userProfile
  };
}
```

## 三、用户成长轨迹记录系统

### 3.1 个性化推荐引擎

```typescript
// 基于用户画像的个性化推荐
export function getPersonalizedRecommendations(userId: string): Recommendation[] {
  const userProfile = getUserProfile(userId);
  const diagnosisHistory = getDiagnosisHistory(userId);
  
  // 分析用户模式
  const patternAnalysis = analyzeUserPattern(diagnosisHistory);
  
  // 生成个性化推荐
  const recommendations = [
    {
      type: 'task_recommendation',
      content: getMostNeededTask(userProfile, patternAnalysis),
      priority: 'high',
      reason: '基于您的历史模式，这项训练最适合'
    },
    {
      type: 'focus_area',
      content: getPersistentIssue(userProfile),
      priority: 'medium',
      reason: '这是您长期存在的问题，建议加强'
    },
    {
      type: 'progress_review',
      content: getProgressSummary(userProfile),
      priority: 'low',
      reason: '您近期的进步情况'
    }
  ];
  
  return recommendations;
}
```

### 3.2 成长可视化

```typescript
// 生成用户成长报告
export function generateGrowthReport(userId: string): GrowthReport {
  const journey = getGrowthJourney(userId);
  const profile = getUserProfile(userId);
  
  return {
    summary: {
      totalSessions: profile.total_sessions,
      totalTasksCompleted: countCompletedTasks(journey),
      improvementRate: calculateImprovementRate(journey),
      persistentIssues: profile.most_common_syndrome
    },
    timeline: journey.map(entry => ({
      date: new Date(entry.timestamp),
      event: entry.progress_milestone || '常规诊断',
      task: entry.task_completed,
      feedback: entry.coach_feedback
    })),
    recommendations: getPersonalizedRecommendations(userId)
  };
}
```

## 四、实现路线图

### 阶段划分

| 阶段 | 时间 | 功能 | 价值 |
|------|------|------|------|
| **MVP** | 当前 | 基础诊断历史表<br>诊断面板展示 | 即时诊断反馈 |
| **Phase 1.5** | 后续 | 用户模式识别<br>统计分析 | 用户画像生成 |
| **Phase 2** | 再后续 | 个性化推荐<br>智能任务推荐 | 个性化服务 |
| **Phase 3** | 长期 | 智能成长规划<br>进步可视化 | 完整成长轨迹 |

### MVP 期具体任务

1. **数据库设计实现**
   - 创建 diagnosis_history 表
   - 创建基础的 user_profile 表

2. **诊断引擎增强**
   - 实现即时诊断
   - 实现会话级诊断
   - 实现基础推荐

3. **前端展示**
   - 诊断面板显示诊断结果
   - 会话历史显示诊断摘要

## 五、数据流向与权限控制

### 5.1 数据流向
```
用户输入 → 诊断引擎分析 → 结构化数据存储 → 前端展示（过滤后）
     ↓
诊断历史积累 → 用户画像生成 → 个性化推荐 → 成长轨迹记录
```

### 5.2 权限控制
- **诊断原始数据**：仅系统内部使用
- **用户可见内容**：经过过滤的中文描述
- **成长轨迹**：用户可查看自己的完整记录
