## 二、本地化部署指南

### 方案A：直接加载Prompt（最简单）

**步骤**：
1. 打开 `月笙_Agent_Prompt_V3.0.md`
2. 复制全部内容（约2100字）
3. 粘贴到本地AI工具的System Prompt位置
4. 开始对话

**适用场景**：
- 本地LLM（如Ollama、LM Studio）
- 支持自定义System Prompt的AI工具
- 不需要额外参考文件

**限制**：
- AI无法访问动作库、病症手册等详细内容
- 只能靠Prompt里的"参考抽屉"（一句话精髓）指导行为

---

### 方案B：Prompt + 参考文件（推荐）

**步骤**：
1. 加载 `月笙_Agent_Prompt_V3.0.md` 作为System Prompt
2. 将以下文件作为"知识库"或"参考文档"加载：
   - `月笙_教学动作库_一句话版_V3.0.md`
   - `月笙_病症识别手册_V1.0.md`
   - `月笙_训练任务库_V2.0.md`
3. AI在需要时可"回忆"这些文件内容

**适用场景**：
- 支持知识库/RAG的本地AI工具
- 需要完整动作定义和病症信号

**优势**：
- Prompt精简（2100字），不膨胀
- 参考文件按需调用，保持灵活性

---

### 方案C：完整知识库（最完整）

**步骤**：
1. 加载 `月笙_Agent_Prompt_V3.0.md` 作为System Prompt
2. 将全部13个文件作为知识库加载
3. AI可访问所有历史案例、验证报告、外部资源

**适用场景**：
- 需要完整历史记录
- 需要参考外部书籍方法
- 需要验证AI行为是否符合真实月笙
