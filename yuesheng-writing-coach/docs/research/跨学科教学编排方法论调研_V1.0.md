# 跨学科教学编排方法论调研报告 V1.0

> 调研目的：借鉴计算机/编程教育、设计/艺术教育、音乐/演奏教育的课程编排方法，为「月笙写作教练」世界观构建→大纲规划→角色塑造三条学习路径提供可落地的教学编排模式参考。

---

## A. 各领域核心教学编排模式

### 1. 计算机/编程教育

#### 模式 1-1：知识依赖图（DAG）

- **描述**：课程按前置依赖关系组织为有向无环图（DAG），每门课列举明确的前置要求。ASU CS 课程体系是一个典型 DAG——`CSE 110 → CSE 205 → CSE 310 → CSE 330`。孤立节点（orphan nodes）被视为设计缺陷。
- **创作教学应用**：创作技能也呈层级依赖——"基础语法→描写技术→叙事结构→类型创作"。可将"人物描写"设为前置、"多视角叙事"设为后续节点，未掌握前置则锁定。

#### 模式 1-2：技能矩阵 + 精通等级（Mastery Rubric）

- **描述**：编程教育（如 Turing School）将每项技能分为 Novice → Advanced Beginner → Proficient → Exceptional 四个等级，每级有可操作定义。升到下一模块的前提是**所有 Key Skills 达到 Proficient**。
- **创作教学应用**：对每个创作技能（如"对话写作""悬念构建"）定义 4 级标准：**Novice（能写出对话但平淡）→ Proficient（能用对话推动情节）→ Exceptional（能通过潜台词完成多重叙事功能）**。

#### 模式 1-3：精通学习（Mastery Learning）+ 知识追踪

- **描述**：Khan Academy 的核心机制——学习者必须在前置节点达到"精通"（通常正确率 80%+）才能解锁后续。系统使用 Bayesian Knowledge Tracing 追踪每个知识点的掌握概率。
- **创作教学应用**：对应创作教学中**"未掌握基础描写就进入高级叙事训练"的常见问题**。每章节设 mastery 检测，达标后方可进入下一个创作阶段。

#### 模式 1-4：渐进式项目矩阵（Progressive Project Matrix）

- **描述**：SoftUni 的模式——从第 1 周的个人静态页面 → 第 4 周待办清单 App → 第 8 周集成 API → 第 12 周全栈 SPA。每个项目复用前一个项目的知识并增加一层复杂度。
- **创作教学应用**：设计**项目序列**——写一个段落 → 写一个场景 → 写一个章节 → 写一个完整短篇。每个项目复用前一个的设定或角色，降低认知负荷。

#### 模式 1-5：自适应学习循环

- **描述**：现代 AI 课程设计（GripXTech）——[学习者输入 → 分析引擎 → AI 决策层 → 课程图更新 → 新课程计划]。系统基于弱项动态调整内容顺序和难度。
- **创作教学应用**：**AI 写作教练的诊断引擎就是自适应循环的天然载体**——根据学生作文的症候分析，动态推荐对应的训练内容和回顾练习。

### 2. 设计/艺术教育

#### 模式 2-1：阶段匹配式评审（Phase-Matched Crit）

- **描述**：建筑教育中评审反馈不再"一刀切"，而是根据项目阶段定制——概念阶段关注"方向是否正确"，深化阶段关注"结构是否合理"，终期关注"细节与呈现"。
- **创作教学应用**：**三阶段评审**——概念阶段评"创意潜力"，初稿阶段评"结构完整性"，定稿阶段评"细节与风格"。避免在概念期就开始挑剔语法。

#### 模式 2-2：作品集评审（Portfolio Review）

- **描述**：建筑/设计学生通过作品集展示成长轨迹，评审关注**完成度、工艺、清晰度、复杂度**四个维度。第一次评审决定能否进入高级工作室，第二次决定能否进入毕业项目。
- **创作教学应用**：引入**"创作作品集"**制度——学生积累写作作品，达到一定数量和质量后解锁"高级创作"通道。评审标准：完成度、语言控制、结构清晰、创意复杂度。

#### 模式 2-3：分层反馈模型（Layered Feedback）

- **描述**：从"结构→细节→风格"逐层递进的反馈方式。先确保整体框架合理，再深入到句子层面，最后讨论风格和个人声音。
- **创作教学应用**：写作反馈分层——**第一层评"情节/论点完整性"，第二层评"场景/段落流畅度"，第三层评"语言风格和修辞"**。一次只聚焦一层，避免信息过载。

#### 模式 2-4：反思性 ePortfolio

- **描述**：墨尔本大学设计的电子作品集不仅展示成果，更要求学生写反思日志，记录创作过程、碰到的困难和解决方案。
- **创作教学应用**：在每条创作路径中嵌入**"创作日志"**环节——写完一段后要求学生记录"我在这部分遇到了什么困难？是如何解决的？"。培养元认知能力。

### 3. 音乐/演奏教育

#### 模式 3-1：模仿→探索→即兴→创作（Orff 四阶段）

- **描述**：奥尔夫教学法的核心递进顺序——先模仿（跟奏）→探索（在框架内变奏）→即兴（自由创造）→创作（完整作品）。先建立"语汇"，再建立"表达"。
- **创作教学应用**：**天然路径**——先阅读经典段落并模仿写作（模仿）→用给定场景改写（探索）→基于给定世界设定自由写作（即兴）→独立创作完整短篇（创作）。

#### 模式 3-2：分解练习→组合应用→自由创作

- **描述**：将复杂技能拆解为子技能单独练习（如和弦→节奏→solo），再组合应用，最后自由创作。分解练习卡针对不同程度提供不同复杂度。
- **创作教学应用**：写作技能**分解练习**——先练"对话节奏"（独立练习）→再练"对话+动作"（组合）→最后自由创作包含对话和动作的完整场景。对不同水平提供不同脚手架。

#### 模式 3-3：三阶递进（基础→发展→高阶）

- **描述**：音乐教学（2025 版指南）将 7-9 年级分为三阶：**基础层**（消除恐惧，建立基本规范）→ **发展层**（提升表现深度，解决"有技术无情感"）→ **高阶**（个性化创造表达）。
- **创作教学应用**：对应**创作教学的三条路径**——基础层消除"写作恐惧"，建立基本叙事规范；发展层提升"人物深度"和"结构复杂性"；高阶层个性化风格和类型突破。

#### 模式 3-4：共同创作 + 回馈循环

- **描述**：音乐课堂中的小组合作创作，学生互相倾听、互相回应，形成"展示-反馈-修正"循环。
- **创作教学应用**：**写作工作坊模式（Writing Workshop）**——学生朗读作品，同学和老师给予积极反馈。知道自己会被"发表"，写作动力显著提升。（线上场景可转化为 AI 模拟的读者群反馈）

### 4. 额外参考：Duolingo

#### 模式 4-1：技能树 → 线性学习路径（Linear Learning Path）

- **描述**：Duolingo 2022 年从自由的技能树改为线性学习路径。每个 Unit 包含多种题型（语法、词汇、听力、口语），结尾设复习区。科学设计的顺序确保最优习得路径。
- **创作教学应用**：**从自由选课改为有序列的学习路径**——世界观构建 → 大纲规划 → 角色塑造三条路径但并行推进，而不是让用户随意跳转。

#### 模式 4-2：间隔重复（Spaced Repetition）

- **描述**：基于艾宾浩斯遗忘曲线，在用户即将遗忘的临界点自动推送复习。使用的算法类似于 Elo Rating + 遗忘曲线参数。
- **创作教学应用**：**定期推送"回顾练习"**——学习了"人物塑造"3 天后，推送精简版人物小传练习；1 周后再推送"人物+情节"综合练习。

#### 模式 4-3：学习前评估（Pre-assessment）+ 跳级机制

- **描述**：新用户通过"7 个快问快答"定位起点，水平高的可以直接跳级到更难课程，避免浪费时间。
- **创作教学应用**：**入场评估**——让用户写一段短文，AI 识别当前创作水平（症候分析），自动跳过已掌握的基础模块，直接进入需要的章节。

---

### 5. 额外参考：Iowa Writers' Workshop

#### 模式 5-1：工作坊（Workshop）为核心

- **描述**：研讨会是 MFA 的核心。8-12 人小组，每周提交作品，集体讨论反馈。学生既是作者也是读者。
- **创作教学应用**：虽然不是 1:1 可复制的模式，但**"读者反馈"**机制可以简化为 AI 模拟的多角色反馈（读者视角 vs. 编辑视角 vs. 作者视角）。

#### 模式 5-2：层级递进（入门→专题→研讨）

- **描述**：本科从"创意写作入门"（体验写作思维）到"进阶专题"（科幻、奇幻、世界构建），再到研究生研讨（形式分析、现代小说问题）。
- **创作教学应用**：**三路径的层级设计**——L1 基础技能（语法→描写→叙事基础）→ L2 路径专业知识（世界观构建工具包/大纲方法/角色塑造技术）→ L3 综合创作（完整作品）。

## B. 跨领域共通原则

| # | 原则 | 来源领域 | 说明 |
|---|------|---------|------|
| 1 | **知识依赖图（Prerequisite Graph）** | 编程 / 音乐 / 数学 | 新技能构建在前置技能之上。依赖图必须是无环图（DAG），不能出现孤立节点。可进行拓扑排序。 |
| 2 | **渐进难度分层（Progressive Difficulty Tiering）** | 全域通见 | 基础层（建立规范+消除恐惧）→ 发展层（提升深度）→ 高阶层（个性化+创造表达）。三层递进是跨学科共识。 |
| 3 | **能力评审节点（Gatekeeper Assessment）** | 设计 / 编程 / 音乐 | 学习路径中设关键评审点（portfolio review / pentathlon / crit），只有通过才能进入下一阶段。评审标准可操作、可量化。 |
| 4 | **螺旋式复习/间隔重复（Spiral Review / Spaced Repetition）** | Duolingo / 音乐 | 已学内容在遗忘临界点被重新激活。知识在递增的时间间隔内多次出现，而非"学完即忘"。 |
| 5 | **分解→组合→创作（Decompose → Compose → Create）** | 音乐 Orff / 编程 / 写作 | 复杂技能先拆解为原子技能单独练习，再组合应用，最后自由创造。三个阶段依次推进。 |
| 6 | **即时、分层反馈（Layered & Timely Feedback）** | 设计 Crit / 编程 / 音乐 | 反馈匹配创作阶段：概念期反馈方向、中期反馈结构、终期反馈细节。避免早期在细节层面纠错。 |
| 7 | **脚手架递减（Fading Scaffolding）** | 音乐 / 写作教学 | 初学提供高结构脚手架（模板、框架、分解卡），随能力提升逐步撤除，最终实现独立创作。 |
| 8 | **反思/元认知记录（Reflective Metacognition）** | 设计 ePortfolio / 写作 workshop | 学习者记录创作过程中的困难与决策，培养自我判断和修正能力。反思是技术训练到自主创作的桥梁。 |

## C. 落地建议

### C.1 三路径应用映射

| 共通原则 | 世界观构建路径 | 大纲规划路径 | 角色塑造路径 |
|---------|---------------|-------------|-------------|
| **知识依赖图** | 基础设定（时间/空间/规则）→ 中层体系（政治/经济/文化）→ 高层冲突（大事件/矛盾） | 三幕结构 → 情节节点 → 场景设计 | 外部特征 → 背景故事 → 内心动机 → 人物弧线 |
| **渐进分层** | L1: 想出一个世界 → L2: 让世界有逻辑 → L3: 让世界有主题 | L1: 列出事件 → L2: 编织因果链 → L3: 设计多重线索 | L1: 画出一个人 → L2: 让他有欲望 → L3: 让他有变化 |
| **评审节点** | 完成"世界设定文档"后解锁大纲路径 | 完成"故事结构图"后解锁角色路径 | 完成"人物小传"后解锁综合创作 |
| **分解→组合→创作** | 先分别练"地理设定""社会规则""历史背景"，再整合为一个完整世界观 | 先练"单场景设计"，再练"场景串联"，最后完成"全章大纲" | 先练"外貌描写""对话写作""内心独白"，再组合为"立体人物" |
| **分层反馈** | 初期关注"想象力丰富度"，中期关注"内在逻辑一致性"，后期关注"主题深度" | 初期关注"故事完整性"，中期关注"节奏与张力"，后期关注"读者体验" | 初期关注"人物辨识度"，中期关注"人物可信度"，后期关注"人物感染力" |
| **间隔重复** | 切换到大纲路径后，定期回推世界观回顾练习 | 进入角色路径后，定期回推大纲结构回顾 | 综合创作阶段定期回推人物一致性检查 |

### C.2 优先级建议

#### 第一批落地（高影响 + 低复杂度）

1. **渐进分层（Progressive Tiering）**——三条路径天然的层次结构，只需定义清楚每个层次的完成标准即可落地。
2. **知识依赖图（Prerequisite Graph）**——画出路径节点的依赖关系是后续所有功能的基础。建议先为核心路径（如角色塑造）画出一个 15-20 节点的依赖图原型。
3. **分层反馈（Layered Feedback）**——AI 诊断引擎已经具备症候分析能力，只需在反馈输出时增加"阶段过滤"逻辑——写初稿时不报语法错误，只报结构问题。

#### 第二批落地（高影响 + 中复杂度）

4. **评审节点（Gatekeeper Assessment）**——需要定义每个模块的完成条件和"精通"标准。建议对照项目的症候/动作体系，设计节点检测规则。
5. **分解→组合→创作（Decompose → Compose → Create）**——需要为每个路径的子技能设计独立的训练动作。建议先从角色塑造路径开始试点。

#### 第三批落地（高影响 + 高复杂度）

6. **间隔重复（Spaced Repetition）**——需要记录用户所有练习行为的时间戳和掌握度，基于遗忘曲线模型（如简化版 Ebbinghaus）推送复习。建议在用户数据积累到一定规模后再引入。
