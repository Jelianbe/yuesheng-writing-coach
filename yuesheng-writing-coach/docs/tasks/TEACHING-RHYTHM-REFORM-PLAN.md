## 零、教学方法定位（审查追加）

### 0.1 引导发现（原"苏格拉底方法"）的适用边界

引导发现不是万能教学方法。它在写作教学中的适用性取决于**学生对该问题的知识状态**：

| 学生知识状态 | 引导发现 | 直接教学 | 典型症候 |
|---|---|---|---|
| 感性认知到位，缺乏概念工具 | **极适合** | 没必要 | P003 情绪标签化、P007 阅读结构单一 |
| 有概念认知，缺乏技法 | **部分适合** | 更高效 | P005 视角漂移 |
| 双重缺失（既不知问题也不知方法） | **不适合** | 必须 | P004 信息硬塞、P006 节奏停滞 |
| 纯技术性问题（语法/标点/格式） | **浪费时间** | 唯一方式 | 错别字、标点规范 |

**核心原则**：教学库中 89+ 技法至少一半是几百年的创作技术沉淀，不可能通过提问让学生自己推导出来。引导发现只应在**学生已具备感性认知、只需被引导命名问题**的症候上使用。

### 0.2 B-01 设计方案修正

B-01 不再让所有症候都走 S2_GUIDE。改为：

```
TeachingStrategyRouter（Layer 2）
  → 输出 needsGuidePhase: boolean
  → 依据 syndrome-type-map.json 中每个症候的 discoverable 字段
  → 状态机根据此标志决定进入 S2_GUIDE 或直接跳到 S2_REFLECTION
```

`needsGuidePhase=true` 的症候约占 30-40%，其余直接跳过引导发现。

### 0.3 措辞规范

全文档统一使用"引导发现"替代"苏格拉底方法"。AI Prompt 中不出现"苏格拉底"一词，只需描述"通过提问帮助学生自己发现问题"的行为规则。
