# 验证2：多症候混合测试

## 测试说明

**目标**：验证 classical-principles.json + syndrome-classical-map.json + signal-weight-matrix.json 在**多症候混合文本**中的鉴别力。同一个文本内可能出现多个症候，且存在容易被混淆的"症候对"。

**测试方法**：
1. 每段测试文本呈现一个或多个症候的真实写作场景
2. 评估以下三个维度（按验证报告裁决标准）：
   - **维度匹配正确率**：识别的症候中正确部分占比（自动判定，≥85%通过）
   - **混淆检查**：不应匹配的症候是否未被匹配（自动判定）
   - **策略选择合理率**：对多症候的优先级排序是否合理（自动+人工抽检）

**评分标准**：

| 维度 | 评估方式 | 通过门槛 |
|:-----|:---------|:---------|
| 维度匹配正确率 | 命中/(命中+误报+漏报) | ≥85% |
| 混淆检查 | 每个样本检查 confusableNote 中的不应命中项 | 零误报 |
| 策略选择合理率 (样本6-10) | 多症候优先级排序是否基于严重度 | ≥80% |

**数据来源**：
- `classical-principles.json` — 原则库
- `syndrome-classical-map.json` — 症候→原则推理
- `signal-weight-matrix.json` — 信号权重+严重度

## 测试样本

### 样本 1：P003 + P006 混合「悲伤的房间里」

**文本**：
> 林晓独自坐在房间里，感到非常伤心。她想起了昨天发生的事情，心里无比难受。她觉得自己被全世界抛弃了，这种孤独感让她喘不过气来。她望着窗外的雨，觉得连天气都在为她哭泣。时间一分一秒地过去，她一动不动地坐着。三个小时过去了，她还在想着同样的事情。她真的很痛苦，痛苦到不知道该做什么。

**症候**：
- **P003 情绪标签化** — "伤心""难受""孤独""痛苦"连发，无对应的身体描写

**应命中的症候**：P003, P006
**不应命中的症候**：P004（不是信息多，是重复同一种情绪；不是读者信息过载，是叙事停滞）

**ConfusableNote**：P006 和 P004 容易混淆。P006 是"不推进"，P004 是"太多信息推不过来"。这里读者的问题是"什么也没发生"，不是"信息太多"。

**评分**：____ / 3分（匹配2+混淆1）

### 样本 2：P004 + P007 混合「家族往事」

**文本**：
> 张家的祖上三代都是读书人。曾祖父张元济是光绪年间的秀才，祖父张伯驹是民国时期的大学教授，父亲张景贤是建国后的第一批大学生。张家因此有很多规矩。吃饭的时候不能说话。筷子不能插在饭上。碗不能敲。进门要先叫人。见了长辈要低头。走路步子要小。说话声音要轻。这些都是张家代代相传的家训。张家一共有七房兄弟，大房在城东，二房在城西，三房已经搬去了南方。

**症候**：
- **P004 信息硬塞** — 同一段塞了三个家谱世代 + 七个规矩 + 七房兄弟分布

**应命中的症候**：P004, P007
**不应命中的症候**：P001（虽然涉及家谱和历史背景，但这里的问题不是"世界观膨胀"——信息本身是叙事的一部分。P001 特指无关世界观信息，这里恰好是人物背景，信息本身有意义只是表达方式有问题）

**ConfusableNote**：P001 和 P004 的边界：P001 的信息不与叙事挂钩（作者纯粹在'介绍'），P004 的信息虽然密集但确实有助力叙事理解。本样本应该判 P004 而非 P001。

**评分**：____ / 3分

### 样本 3：P001 + P004 混合「魔法学院设定」

**文本**：
> 阿斯加德学院成立于纪元前三百年的魔法议会第三次改革之后。学院的创始人是七位大魔导师，分别是火系的阿格尼、水系的尼普顿、风系的艾尔、土系的盖亚、光系的卢克索、暗系的诺克斯和雷系的托尔。学院的魔法体系分为八个学派，每个学派下设十五个分支，初阶魔法需要三年的学习才能掌握。分院制是学院的传统，五大学院分别代表五大元素……

**症候**：
- **P001 世界观膨胀** — 所有信息都与当前叙事无关
- **P004 信息硬塞** — 密度极高（时间、创始人×7、学派×8、分支×15、学院×5）

**应命中的症候**：P001, P004
**不应命中的症候**：P006（不是叙事停滞——这里根本没有进入叙事，是纯粹的设定介绍。P006 要求"有叙事但不推进"，这里连叙事都没开始）

**ConfusableNote**：P001 和 P004 在这里是共生的——P001 世界观硬塞必然伴随 P004 信息密度高（因为世界观必须以信息形式存在）。但 P001 是根因（不应该在这里介绍世界观），P004 是表现（信息密度太高）。诊断时应优先标注 P001。

**评分**：____ / 3分

### 样本 4：P002 + P009 混合「邮递员的日常」

**文本**：
> 老王是个邮递员。他每天骑着自行车送信，已经干了二十年。今天早上他像往常一样出门，路上遇到了堵车，他绕了小路。他送完了所有信，下午五点准时下班。在回家的路上，他买了一瓶酱油，因为家里的酱油用完了。吃完饭，他看了一会儿电视，十点钟上床睡觉。

**症候**：
- **P002 扁平人物** — 所有描写都是"邮递员"的通用模板，读完全文不知道老王是一个什么样的人（而不只是一个职业）
- **P009 角色动机缺失** — 为什么老王干了二十年？为什么堵车绕路？为什么买酱油？——所有行动都有"功能理由"（送信、买酱油）但没有"人性理由"

**应命中的症候**：P002, P009
**不应命中的症候**：P007（句式有变化，不是单调问题。虽然内容平淡但不是 P007 的"单调"）

**ConfusableNote**：P002 和 P009 常常同时出现——一个扁平的角色的行动必然是缺乏深入动机的。区别在于：P002 诊断问"他是一个怎样的人？"，P009 诊断问"他为什么这么做？"。建议优先标注 P002（人物塑造是根因，动机缺失是结果）。

**评分**：____ / 3分

### 样本 5：P005「走廊里的对话」

**文本**：
> 李明站在走廊里，心里忐忑不安。这是他们分手后第一次单独见面。（林晓还不确定自己有没有准备好面对前男友，她站在转角处犹豫着要不要走过去。）李明看到她站在那边，鼓起勇气走了过去。（林晓看到李明朝自己走来，心跳加速。她还没想好要说什么，但她知道自己不能逃。）（李明注意到她握紧了手。他在距离她两米的地方停下来，不知道该怎么开口。）（其实李明最近在公司升职了，他今天就想告诉她这个消息。但见面之后他才发现，升职这件事在林晓面前根本不重要。）

**症候**：
- **P005 视角漂移** — 括号内的部分在李明和林晓之间反复横跳（括号是模拟心理距离跳跃的标记）。最后一句话"其实"（〇视角）破坏了有限视角的约束

**应命中的症候**：P005
**不应命中的症候**：P006（叙事在推进——两人相遇、走向对方、停下来——每个动作都有进展。节奏正常，只是视角混乱）

**评分**：____ / 3分

### 样本 6：P006 + P007「会议室」

**文本**：
> 张经理在开会。他讲了第一季度的销售数据。数据比去年好一些。他接着讲了第二季度的计划。计划中有几个新项目。新产品会在下半年上线。他问大家有没有问题。没有人说话。他等了一会儿。还是没有人说话。他看了看手表。会议还有半小时才结束。他不知道自己还能讲什么。每个人都低着头看手机。他轻轻咳嗽了一声。有人抬起头看了一眼又低下去。他又等了一会儿。会议室很安静。

**症候**：
- **P006 节奏停滞** — 每个句子都在推进，但所有推进都不是"叙事推进"（销售数据→下季度计划→问问题→没人说话→看手表→咳嗽→安静）。读者每读一句期望有反应，但"没人说话"一直在重复。
- **P007 句式单调** — 几乎所有句子都是"主语+动词+宾语"的简单句结构，句子长度高度均匀（8-12字）

**应命中的症候**：P006, P007
**不应命中的症候**：P004（信息密度正常，不是信息太多）

**优先级诊断**：P006 是根因（叙事停滞导致读者对'还会发生什么'失去期待），P007 是表现（同一句式加剧停滞感）。如只标注一个应选 P006。

**评分**：____ / 3分

### 样本 7：P010「他是个好人」

**文本**：
> 张明是一个很好的人。他为人正直，乐于助人，从不占别人便宜。同事们都很喜欢他，因为他总是愿意帮忙。他有一个幸福美满的家庭，妻子温柔贤惠，孩子聪明可爱。他工作认真负责，领导对他很满意。他的生活平淡而充实，每一天都过得很踏实。

**症候**：
- **P010 告知而非展示** — 通篇 100% 是"作者告诉读者"，没有任何"让读者自己看见"的展示。每个句子都直接在给结论（好人、正直、乐于助人、幸福美满）

**应命中的症候**：P010
**不应命中的症候**：P003（不是情绪标签化——这里的问题不是情绪词替代描写，而是所有品质都是标签。P010 的诊断维度比 P003 更广——覆盖性格/品质/关系/生活的"告知"，不只是情绪）

**评分**：____ / 3分

### 样本 10：P002 + P003 + P009 混合「街角的咖啡店」

**文本**：
> 小王站在咖啡店门口，心里很复杂。他很喜欢她，但又不敢表白。他觉得很痛苦。他真的很想走进去，但他害怕被拒绝。他站在门口已经十分钟了。他觉得自己很没用。他恨自己的胆怯。他怎么就是不敢走进去呢？他叹了口气，最终还是转身离开了。他走在路上，心里空落落的，觉得很失落。

**症候**：
- **P002 扁平人物** — "小王"是一个通用的"暗恋者"模板——所有暗恋者都这样，不知道小王有什么独特之处
- **P003 情绪标签化** — 痛苦×2、复杂、害怕、很没用、恨、胆怯、失落——10个不同情绪词密集出现但无一有具体描写
- **P009 角色动机缺失** — "他很喜欢她"五个字替代了全部动机

**应命中的症候**：P002, P003, P009
**不应命中的症候**：P006（叙事在推进——站了十分钟→叹气→转身离开→走在路上，动作线完整）

**优先级诊断**：P002（扁平人物）是根因——因为小王没有独特性，所以他的暗恋显得套路化；P003 和 P009 是表现。如果只标注一个应选 P002。
