# CX-001-PROFILE: 用户画像深度分辨

> **优先级**: P2 | **状态**: ready | **预估**: 1d  
> **依赖**: 无 | **后续**: F-05 看点密度可视化

## 目标

优化 `StudentModelService.inferCognitiveStyle()`，提升用户认知风格识别精度。当前实现存在三个关键问题：

1. **关键词库太浅** — 仅 10 个关键词/类，且无权重区分
2. **无入场诊断** — 需 ≥5 条消息才能判定，新用户永远为 mixed
3. **置信度不精确** — 简单比例计算，不符合实际情况

本任务旨在大幅提升画像精度，让教学策略匹配更准确。

## 设计依据

- **设计哲学**: [design-philosophy_V1.0.md](../design/design-philosophy_V1.0.md) §第六章「教学自适应」

## 现有问题分析

### 关键词维度的不足

当前关键词：
```
analytical: ['为什么', '怎么理解', '本质', '核心', '逻辑', '意义', '深层', '框架', '方向', '理念']
emotional:  ['怎么做', '给范例', '改一下', '示范', '具体', '操作', '模板', '步骤', '练习', '例子']
```

问题：
- "怎么做"、"具体"、"操作"、"步骤"、"例子" 这些词其实是中性词——分析型用户也会问
- 缺少强风格区分度的词，如分析型的"对比"、"结构"、"因果关系"、情感型的"感觉"、"共鸣"、"打动"
- 所有关键词同等权重，无法区分强/弱信号

### 消息时效性的忽略

- 所有消息同等权重，但用户风格可能随着使用演化和调整
- 最早的消息（可能只是试探）和最近的消息（反映真实需求）权重相同

### 入场诊断的缺失

- 用户前 1-4 条消息完全被忽略
- 对于新用户，教学策略退化为"通用混合型"，无法针对性调整语气和格式

## 技术方案

### 1. 关键词分层体系

将关键词分为三个层级，赋予不同权重：

| 层级 | 权重 | 分析型（analytical） | 情感型（emotional） |
|------|:----:|---------------------|---------------------|
| Tier-1 强信号 | ×2 | 结构、因果关系、逻辑关系、对比、层次、一致性 | 感觉、共鸣、打动、代入、沉浸、氛围 |
| Tier-2 普通信号 | ×1 | 为什么、怎么理解、本质、核心、逻辑、意义、深层、框架、方向、理念、分析、系统、论证、批判 | 怎么做、给范例、改一下、示范、体验、情感、冲突、生动、感染力、细腻 |
| Tier-3 弱信号 | ×0.5 | 定义、规律、模式、分类、推理、原由、机制 | 故事、共鸣点、场景、对话、人物、情绪、温度 |
| 反信号 | ×(-1) | 分析型关键词出现在情感型计数中（反向排除） |

### 2. 消息时效性加权

```
最近 3 条消息 → weight × 1.5
其余消息     → weight × 0.5
```

理由：最近的消息更能反映用户当前的学习状态和风格偏好。

### 3. 入场短文诊断初始化

放宽最低消息数阈值，从 ≥5 改为 ≥2：

| 消息数 | 行为 | 置信度修正 |
|--------|------|:----------:|
| 0 | 返回 `{ style: 'mixed', confidence: 0 }` | — |
| 1 | 返回 strongest style，但置信度减半 | ×0.5 |
| 2-4 | 正常判定，置信度按数据量缩放 | ×(count/5) |
| 5+ | 完整算法，无缩放 | ×1 |

### 4. 置信度精算

```
baseConfidence = dominantScore / totalScore
recencyBonus = 最近消息中的信号比例 × 0.1
consistencyBonus = 跨会话一致性 × 0.1  // 跨会话出现的模式更可靠
dataAdjustment = min(1, msgCount / 10)  // 数据越多越可信

finalConfidence = baseConfidence × dataAdjustment + recencyBonus + consistencyBonus
```

### 5. 结果定义不变

保持 `CognitiveStyle` 类型不变（对下游无影响）：
```typescript
type CognitiveStyle = 'analytical' | 'emotional' | 'mixed';
```

## DoD（完成标准）

1. **关键词库扩展**: 从 2×10 扩展为 3 个层级的结构化关键词体系（含权重），覆盖 ≥60 个关键词
2. **入场诊断**: 2 条消息即可输出认知风格判定（置信度适当降低）
3. **时效加权**: 最近 3 条消息权重 ≥ 旧消息的 2 倍
4. **置信度精算**: 置信度反映数据量、数据质量、跨会话一致性
5. **兼容性**: 返回类型不变（CognitiveStyle + confidence），上下游代码无需修改
6. **测试覆盖**: ≥8 个单元测试覆盖各种场景（数据不足、强分析型、强情感型、混合型、跨会话一致性、入场诊断等）
7. **tsc 无错误**: 编译通过
