# 验证2：10段多症候测试文本 — 提交给上级 AI 判定

## 测试说明

请逐段诊断以下10段文本，记录：
1. 每段识别出了哪些 P 症候（P001-P010）
2. 每个症候匹配了哪些经典原则（classical-principles.json 中的原则 ID）
3. 严重度（L1/L2/L3）
4. 对于多症候样本（6-10），请给出症候优先级排序

评估标准（参照验证报告裁决）：
- 维度匹配正确率 ≥85%
- 混淆零误报
- 多症候策略选择合理率 ≥80%
