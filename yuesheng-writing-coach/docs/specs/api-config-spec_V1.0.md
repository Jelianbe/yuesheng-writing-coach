# API 配置界面 功能规范

**版本**: V1.0  
**创建日期**: 2026-06-01  
**状态**: draft  

## 1. 概述

### 1.1 背景
月笙写作教练需要用户配置 DPV4（DeepSeek V4）API Key 才能进行对话。当前项目没有配置界面，用户无法接入 AI 服务。

### 1.2 目标
提供一个简洁的配置界面，让用户能够：
- 输入并保存 API Key
- 测试 API 连接是否可用
- 查看连接状态

### 1.3 范围
**包含**：
- API Key 输入、保存、验证
- 连接测试功能
- 配置状态显示

**不包含**：
- 多模型切换（MVP 只支持 DPV4）
- 高级参数配置（temperature、max_tokens 等后续添加）
- 代理设置

## 2. 用户故事

### 2.1 主要用户故事
作为**新用户**，我希望**能输入我的 DeepSeek API Key**，以便**能够使用月笙写作教练的 AI 对话功能**。

### 2.2 验收标准
- [ ] 用户首次打开应用时，引导进入配置界面
- [ ] 用户输入 API Key 后，能点击"测试连接"验证有效性
- [ ] 测试成功后，保存配置并自动进入聊天界面
- [ ] 测试失败时，显示清晰的错误提示（如 "API Key 无效"、"网络连接失败"）
- [ ] 用户后续可在设置页面修改 API Key

### 2.3 边缘情况
- 用户不输入 API Key 直接点击测试 → 提示"请输入 API Key"
- 网络断开时测试 → 提示"网络连接失败，请检查网络"
- API Key 已保存但后续失效 → 聊天时提示并引导重新配置

## 3. 功能需求

### 3.1 必须实现（MVP）
| 需求 | 优先级 | 说明 |
|------|--------|------|
| FR-001 | P0 | API Key 输入框，支持粘贴 |
| FR-002 | P0 | 测试连接按钮，调用 /v1/chat/completions 验证 |
| FR-003 | P0 | 配置持久化存储（electron-store） |
| FR-004 | P0 | 连接状态反馈（成功/失败/测试中） |

### 3.2 应该实现（增强）
| 需求 | 优先级 | 说明 |
|------|--------|------|
| FR-005 | P1 | API Key 显示/隐藏切换 |
| FR-006 | P1 | 配置页面可从设置入口进入 |

### 3.3 可以实现（未来）
| 需求 | 优先级 | 说明 |
|------|--------|------|
| FR-007 | P2 | 自定义 API Base URL |
| FR-008 | P2 | 多模型切换 |

## 4. 非功能需求

### 4.1 安全要求
- API Key 使用 electron-store 存储，明文存储但提醒用户风险
- 不在日志中打印完整 API Key
- 测试连接失败时不暴露详细错误信息

### 4.2 性能要求
- 连接测试响应时间 < 10 秒（含超时）
- 配置加载时间 < 100ms

### 4.3 兼容性要求
- Windows 10+

## 5. 成功指标

| 指标 | 基线 | 目标值 | 测量方式 |
|------|------|--------|---------|
| 首次配置成功率 | 0 | > 90% | 测试连接成功次数 / 总尝试次数 |
| 配置页面加载时间 | 无 | < 100ms | 性能监控 |

## 6. 约束与假设

### 6.1 约束
- 必须遵循月笙教练定位（不替用户写、不给答案）
- 必须使用 Electron + TypeScript + React
- 配置数据本地存储，不上传

### 6.2 假设
- 用户已注册 DeepSeek 账号并拥有 API Key
- 用户网络连接正常
