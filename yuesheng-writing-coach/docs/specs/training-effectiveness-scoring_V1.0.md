## 一、设计哲学

**核心信念**：训练效果评分必须可解释、可验证、有教学意义。

**原则**：
1. **AI 只判对错，不打分数** — AI 输出 `targetHit: boolean`，分数由规则计算
2. **分数 = f(正确率, 完成度)** — 公式透明，可追溯
3. **每个分数对应明确的教学含义** — 不是"好不好"，而是"掌握到什么程度"

---

## 二、评分维度

### 2.1 核心维度（2 个）

| 维度 | 权重 | 计算方式 | 数据来源 |
|------|------|----------|----------|
| **正确率** | 70% | AI 判定用户回答是否命中训练目标 | `targetHit: boolean` |
| **完成度** | 30% | 用户是否提交了有效回答 | `user_response` 文本分析 |

### 2.2 维度定义

#### 正确率（targetHit）

AI 对比用户回答与训练模板，输出布尔值：
- `true` — 回答命中训练目标
- `false` — 回答未命中训练目标

**AI 不打分，只判断是否达标。**

判定标准示例（以 P001「世界观膨胀」训练为例）：
```
训练目标：用场景展示而非直接说明世界观
判定标准：
  - targetHit = true: 回答包含场景描写、角色行为、对话等展示手法
  - targetHit = false: 回答直接陈述世界观设定（如"这是一个魔法世界"）
```

#### 完成度（hasEffectiveResponse）

基于 `user_response` 文本分析：
- `true` — 回答字数 >= 10 且非空白/纯标点
- `false` — 无回答、跳过、或回答过短（< 10 字）

## 三、评分规则

### 3.1 评分表

| 分数 | 条件 | 教学含义 | 后续动作 |
|------|------|----------|----------|
| **5** | `targetHit=true` + `hasEffectiveResponse=true` | 掌握，可进入下一症候 | 降低该症候训练频率 |
| **4** | `targetHit=true` + `hasEffectiveResponse=false` | 基本掌握，但回答过短 | 建议强化练习 |
| **3** | `targetHit=false` + `hasEffectiveResponse=true` | 有思考但方向偏了 | 提供降级提示 |
| **2** | `targetHit=false` + `hasEffectiveResponse=false` | 未理解或敷衍 | 重新讲解概念 |
| **1** | 无回答/跳过/超时 | 未参与 | 标记为待补练 |

### 3.2 伪代码

```typescript
function calculateEffectiveness(
  targetHit: boolean | null,
  userResponse: string | null,
): number {
  // 无回答
  if (!userResponse || userResponse.trim().length < 10) {
    return targetHit === true ? 4 : 1;
  }
  // 有回答
  return targetHit === true ? 5 : 3;
}
```

## 五、AI 判定 Prompt 规范

### 5.1 Prompt 结构

```
你是一个训练效果判定助手。请判断用户的回答是否命中了训练目标。

## 训练目标
{trainingTarget}

## 用户回答
{userResponse}

## 判定规则
- 如果回答命中训练目标，输出 targetHit: true
- 如果回答未命中训练目标，输出 targetHit: false

## 输出格式（JSON）
{
  "targetHit": boolean,
  "reason": "简短说明（不超过50字）"
}
```

### 5.2 判定原则

1. **宽松优先** — 新手回答有方向即可判 true
2. **关注意图** — 不看文笔，看是否理解训练目标
3. **可解释** — reason 字段必须说明判定依据

## 六、与能力成长的关系

### 6.1 成长进度计算

```
成长进度 = Σ(effectiveness * 权重) / 总训练次数

权重分配：
  - 最近 5 次：权重 2.0
  - 之前 10 次：权重 1.0
  - 更早：权重 0.5
```

### 6.2 成长趋势判定

| 趋势 | 条件 |
|------|------|
| **提升** | 最近 5 次平均 > 历史平均 × 1.2 |
| **稳定** | 最近 5 次平均 ≈ 历史平均 |
| **下降** | 最近 5 次平均 < 历史平均 × 0.8 |

### 6.3 症候掌握判定

```
某症候掌握 = 该症候最近 3 次训练 effectiveness 平均分 >= 4
```
