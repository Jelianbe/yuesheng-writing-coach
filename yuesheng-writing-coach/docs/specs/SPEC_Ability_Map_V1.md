# SPEC_Ability_Map_V1.md

> 版本：V1.0 | 创建：2026-06-02 | 核心原则：病症可以增加，能力树保持稳定
> 核心认知：月笙训练的是能力，不是病症。病症只是能力缺失的表现。

---

## 一、设计原则

1. **能力树稳定**：V1 定义的核心能力和子能力，未来不轻易改动。新增病症时，映射到已有能力，不新增能力。
2. **病症可扩展**：P001-P010 只是起点，未来可以新增 P011、P012 等，但都必须映射到现有能力树。
3. **训练对象是能力**：不是"训练不要写情绪标签"，而是"训练观察能力"。
4. **三层结构**：核心能力 → 子能力 → 病症映射。

---

## 二、Level 1：核心能力（6项）

| 代码 | 名称 | 定义 | 诊断优先级 |
|------|------|------|-----------|
| **OBS** | 观察能力 | 从现实中提取细节，转化为文字的能力 | 高 |
| **CHAR** | 角色能力 | 构建立体、有逻辑、有成长的角色 | 高 |
| **PLOT** | 剧情能力 | 设计冲突、节奏、转折、结构 | 高 |
| **EMO** | 情绪能力 | 传达情绪而不直接标签化 | 中 |
| **WORLD** | 世界观能力 | 构建自洽、有质感的世界 | 中 |
| **STYLE** | 表达能力 | 文字风格、修辞、语感 | 低 |

## 四、Level 3：病症映射

### 现有病症映射（P001-P010）

| 症候 | 名称 | 映射能力 | 映射子能力 | 核心问题 |
|------|------|---------|-----------|---------|
| **P001** | 世界观膨胀 | WORLD | WORLD-002 | 展示能力不足，只会说明 |
| **P002** | 角色工具人化 | CHAR | CHAR-001 | 动机缺失，角色没有内在驱动 |
| **P003** | 情绪标签化 | OBS + EMO | OBS-001 + EMO-001 | 观察不足，只会写"他很愤怒" |
| **P004** | 信息硬塞 | WORLD | WORLD-002 | 展示能力不足，信息投放无节奏 |
| **P005** | 视角漂移 | STYLE | STYLE-003 | 视角控制不稳 |
| **P006** | 节奏停滞 | PLOT | PLOT-002 | 节奏控制失衡 |
| **P007** | 阅读结构单一 | ⚠️ 特殊 | ⚠️ 不参与评分 | 阅读输入不足，非写作能力缺失（见下方说明） |
| **P009** | 角色动机缺失 | CHAR | CHAR-001 | 动机构建不足 |
| **P010** | OC平面化 | CHAR | CHAR-002 + CHAR-003 | 行为逻辑+关系塑造缺失 |

### 未来新增病症的映射规则

```
新增病症 → 分析：这个病症反映的是哪个子能力的缺失？
        → 映射：映射到已有子能力（不新增子能力）
        → 训练：调用对应子能力的训练任务
```

**示例**：未来新增 P011 "对话呆板"
- 分析：对话没有潜台词，人物一开口就交代信息
- 映射：OBS-004 对话观察
- 训练：调用 OBS-004 的训练任务

### P007 特殊处理说明

P007（阅读结构单一）的本质是**阅读输入不足**，而非写作能力缺失。一个作者可能写作技巧没问题，但因为只读网文导致笔力天花板低。

**处理方式**：
- P007 **不参与核心能力评分**（不影响 OBS/CHAR/PLOT/EMO/WORLD/STYLE 的分数）
- P007 的训练任务（T013/T014）仍然推荐，但作为**辅助训练**
- 在 AuthorProfile 中单独展示阅读建议，不纳入能力雷达图
- 如果未来新增 READING 核心能力，P007 可映射过去

### 5.2 新增症候的训练任务扩展规则

```
新增 P011 → 分析：哪个子能力缺失？
         → 检查：该子能力是否已有训练任务？
         → 如果有 → 复用现有任务
         → 如果没有 → 新增 T021/T022（保持每个症候2个任务的节奏）
```

**示例**：新增 P011 "对话呆板"
- 映射：OBS-004 对话观察
- 已有训练：T008 潜台词练习
- 复用 T008，无需新增训练任务

## 六、核心能力评分权重（V1）

核心能力分数由其子能力聚合而来。V1 使用简单算术平均。

| 核心能力 | 子能力数量 | 聚合方式 | 说明 |
|---------|-----------|---------|------|
| OBS | 4 | 算术平均 | 观察能力是基础，各子能力权重均等 |
| CHAR | 4 | 算术平均 | 角色能力各维度缺一不可 |
| PLOT | 4 | 算术平均 | 剧情能力需要全面发展 |
| EMO | 3 | 算术平均 | 情绪表达三层递进 |
| WORLD | 3 | 算术平均 | 世界观能力三层递进 |
| STYLE | 3 | 算术平均 | 表达能力三层递进 |

**计算示例**：
```
OBS 总分 = (OBS-001 + OBS-002 + OBS-003 + OBS-004) / 4
```

> **V2 预留**：未来可为不同子能力设置权重。例如 OBS-001（感官）作为基础观察能力，权重可能高于 OBS-004（对话）。

## 七、与旧能力体系（ability-atlas.json）的映射

现有 `ability-atlas.json` 使用 ABL-001~ABL-008 体系，需逐步迁移到新体系。

| 旧体系（ABL） | 新体系（核心能力） | 说明 |
|--------------|-------------------|------|
| ABL-001 结构控制 | PLOT + WORLD | 结构控制拆分为剧情结构和世界观展示 |
| ABL-002 场景构建 | OBS + PLOT | 场景构建需要观察能力和剧情能力 |
| ABL-003 角色塑造 | CHAR | 直接对应 |
| ABL-004 角色逻辑链 | CHAR | 并入角色能力 |
| ABL-005 世界观工程 | WORLD | 直接对应 |
| ABL-006 视角控制 | STYLE | 归入表达能力 |
| ABL-007 表达能力 | OBS + EMO + STYLE | 表达能力拆分为观察、情绪、表达 |
| ABL-008 阅读素养 | （暂不映射） | 属于学习辅助能力，不纳入核心能力评分 |

**迁移策略**：
1. V1 阶段：并行维护两套体系，新规范用于 AuthorProfile，旧规范用于现有推荐引擎
2. V1.5 阶段：推荐引擎升级，使用新子能力体系
3. V2 阶段：废弃 ABL 体系，完全切换到 OBS/CHAR/PLOT/EMO/WORLD/STYLE

## 八、DoD

1. 6 项核心能力定义完整，有明确边界
2. 19 项子能力定义完整，有明确训练方向
3. P001-P010 全部映射到子能力，无遗漏
4. 新增病症的映射规则文档化
5. 训练任务与全部 19 项子能力的映射关系文档化
6. 核心能力评分权重（算术平均）文档化
7. 新旧能力体系映射关系文档化

## 九、变更规则

| 变更类型 | 允许？ | 条件 |
|---------|--------|------|
| 新增核心能力 | ❌ 不允许 | V1 冻结，V2 评估后决定 |
| 新增子能力 | ⚠️ 谨慎 | 必须证明现有子能力无法覆盖 |
| 新增病症 | ✅ 允许 | 必须映射到现有子能力 |
| 调整映射关系 | ✅ 允许 | 基于实际教学数据反馈 |
| 调整训练任务 | ✅ 允许 | 与产品团队确认 |
