## 一、设计哲学

**核心信念**：用户进步不是"训练得了几分"，而是**实际写作中症候减少**。

**原则**：
1. **进步 = 同一症候的严重度在多次对话中下降**
2. **跨对话追踪** — 不局限于单个 session，而是用户所有写作历史
3. **用户能感知** — 展示的进步是"上次犯的错误这次没犯"，不是抽象分数

---

## 二、评分维度

### 2.1 核心指标：症候严重度趋势

**唯一核心维度**：同一症候在多次对话中的严重度变化。

| 指标 | 计算方式 | 数据来源 |
|------|----------|----------|
| **症候严重度序列** | 按时间顺序排列的该症候每次出现的严重度 | 诊断记录 |
| **消失判定** | 最近 N 次对话中该症候未出现 | 诊断记录 |

### 2.2 进步计算

```
进步值 = 历史平均严重度 - 近期平均严重度

历史平均 = 所有出现该症候的对话的平均严重度
近期平均 = 最近 3 次出现该症候的平均严重度
```

**严重度数值映射**：
- L1 = 1（轻微）
- L2 = 2（中等）
- L3 = 3（严重）

**进步值解释**：
- `> 0` → 进步（严重度下降）
- `= 0` → 稳定
- `< 0` → 退步（严重度上升）

### 2.3 症候掌握判定

```
某症候已掌握 = 最近 5 次对话中：
  - 该症候未出现，或
  - 该症候严重度均为 L1
```

## 三、评分规则

### 3.1 症候级评分

| 状态 | 条件 | 展示文案 |
|------|------|----------|
| **已掌握** | 最近 5 次对话未出现或全 L1 | "✓ 已掌握" |
| **进步中** | 近期严重度 < 历史平均 | "↑ 进步中" |
| **稳定** | 近期严重度 ≈ 历史平均 | "→ 稳定" |
| **需关注** | 近期严重度 > 历史平均 | "↓ 需关注" |

### 3.2 全局成长评分

```
全局成长分 = Σ(每个症候的进步值 × 权重) / 症候总数

权重 = 该症候的出现频率（越常犯的症候权重越高）
```

**全局成长分展示**：
| 分数范围 | 展示 | 含义 |
|----------|------|------|
| > 0.5 | "显著提升" | 多个症候明显改善 |
| 0.1 ~ 0.5 | "稳步进步" | 部分症候改善 |
| -0.1 ~ 0.1 | "保持稳定" | 没有明显变化 |
| < -0.1 | "需要加强" | 某些症候加重 |

## 四、数据流

```
每次对话结束
  ↓
诊断引擎输出症候列表（含严重度）
  ↓
写入 diagnosis_results 表
  ↓
聚合：按症候 ID 分组，按时间排序
  ↓
计算每个症候的严重度趋势
  ↓
生成成长数据推送前端
```

## 五、前端展示

### 5.1 右侧栏 - 能力成长

```
能力成长

P001 世界观膨胀    ✓ 已掌握
  L2 → L1 → (未出现)

P002 对话传声筒    ↑ 进步中
  L2 → L2 → L1

P003 情绪标签化    → 稳定
  L2 → L2 → L2

P009 角色动机缺失  ↓ 需关注
  L1 → L2 → L3
```

### 5.2 一句话成长记录

```
"相比上次对话，你的世界观展示进步明显，但角色动机需要加强。"
```

**生成规则**：
1. 找出进步最大的症候 → "XXX 进步明显"
2. 找出退步最大的症候 → "但 XXX 需要加强"
3. 如果全部稳定 → "整体保持稳定，继续保持"

## 六、与训练的关系

训练不是"打分"，而是**帮助症候改善的手段**。

```
训练效果 = 训练后症候严重度是否下降
```

- 如果训练后症候改善 → 训练有效
- 如果训练后症候无变化 → 训练方式可能需要调整
- 如果训练后症候加重 → 需要重新评估教学策略

**训练记录的作用**：关联训练与症候变化，验证教学方法是否有效。
