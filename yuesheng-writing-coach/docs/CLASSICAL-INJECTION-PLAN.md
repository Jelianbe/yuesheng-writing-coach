## 三、双轨道并行方案

### 3.1 两条轨道的关系

```
诊断推理（轨道A）                     教学交互（轨道B）
      │                                    │
      │  感知学员文本                          │  选择交互策略
      │  ↓                                   │  ↓
      │  匹配经典原则                          │  决定教学模式
      │  ↓                                   │  ↓
      │  生成诊断结论                          │  组织引导路径
      │  ↓                                   │  ↓
      └──────────────→ 汇合到 Prompt ←───────────┘
                              │
                              ↓
                        AI生成回复
                    （诊断依据 × 教学策略）
```

**两条轨道正交不冲突**：
- 轨道A 决定"说什么"——诊断依据、引用原则、追问方向
- 轨道B 决定"怎么说"——交互策略、教学模式、语气节奏

### 3.3 新增数据源定位表

21世纪蒸馏和野路子蒸馏不是"要不要加"的问题，是"落在架构哪个位置"的问题。以下定位表明确每一批数据归属：

| 数据源 | 落在轨道 | 落在阶段 | 理由 |
|:-------|:---------|:---------|:------|
| **Sanderson/McKee/Truby**（西方叙事理论） | 轨道A（知识注入） | 0-A4 | 三位是叙事理论家，与12位经典同质——提供诊断推理依据，按同样四元组格式录入 classical-principles.json |
| **Lisa Cron**（脑科学叙事） | 轨道A | 0-A4 | 经典框架缺乏"读者心理机制"视角。Cron 能解释"为什么读者进不去"——大脑没找到可模拟的体验。**补充性知识，不是重复** |
| **Snyder/葛红兵**（现代叙事与教学） | **分叉**：Snyder→技法库 / 葛红兵→轨道B | 1-1 / 0-B1 | Snyder 的 15 节拍是结构模板（学员用的工具），不是诊断原则。葛红兵的工坊制/过程写作法是教学模式，应进 teaching-strategies.json |
| **邵燕君/起点编辑体系/欧阳友权**（中文网文） | 轨道A + 轨道B各半 | 0-A1(扩展) / 0-B1 | 爽点审美/类型套路→经典原则扩展维度；起点签约标准/读者留存数据→教学策略中"商业性缺失"的诊断依据 |
| **野路子25条**（民间技法） | 技法库 + 训练库 | 1-1 / 1-4 | 每条自带操作化步骤，天然是技法条目和训练练习。催泪二步法、情绪过山车、对话三问自查可直接作为训练步骤 |

**关键分叉决策**：Sanderson/McKee/Truby/Cron/邵燕君是"能提供诊断推理依据的原则源"，应该进 classical-principles.json。野路子25条是"可照搬的操作步骤"，应该进技法库/训练库。两者不同类型的数据放同一层会混淆 AI 的推理：原则是追问工具，技法是操作模板。

### 3.4 设计原则

1. **不动已有代码结构** — Wave 1-6 的全部产出保留原样
2. **经典知识 + 教学策略并行** — 两条轨道各自独立演化
3. **先盘点后补充** — 教学方式已经有很多，先理清楚再补丢失的
4. **先验证后部署** — 两轮原型验证确认有效后再推全量
5. **训练方法同样重要** — 新增的训练练习（看烂书、指定视角阅读等）作为阶段1-4 纳入

#### 0-A1：`resources/config/classical-principles.json`

每条原则包含四元组：

```jsonc
{
  "id": "CHEKHOV_DONT_NAME_EMOTION",   // 原则唯一ID
  "author": "契诃夫",                    // 来源作者

  "questionDirection": "去掉这个情绪词后，读者还能感受到同样的情绪吗？"  // 追问方向
}
```

**数据来源**：
- 经典写作理论框架-蒸馏版.md（经典7个维度 × 每维度6-8条 ≈ 50条原则）
- 21世纪蒸馏-西方叙事理论.md（Sanderson/McKee/Truby → 按四元组格式录入）
- 21世纪蒸馏-中文网文.md（邵燕君爽点审美/类型理论 → 按四元组格式录入，纳入第8维度）

**八个维度（经典7维 + 新增第8维）**：

| # | 维度 | 作者源 | 类型 |
|:-:|:-----|:-------|:----:|
| 1 | 观察与素材 | 老舍、叶圣陶、沈从文 | 经典 |
| 2 | 语言与简洁 | 汪曾祺、契诃夫、鲁迅、Strunk & White、Zinsser | 经典 |
| 3 | 人物塑造 | 老舍、沈从文、Forster、Gardner、Booth、Sanderson | 经典 + 21世纪 |
| 4 | 修改与提炼 | 鲁迅、叶圣陶、契诃夫、Zinsser | 经典 |
| 5 | 趣味与品位 | 朱光潜、汪曾祺 | 经典 |
| 6 | 结构经济性 | 契诃夫、老舍、Strunk & White、Truby、McKee | 经典 + 21世纪 |
| 7 | 叙事控制 | Gardner、Booth、沈从文、Sanderson | 经典 + 21世纪 |
| **8** | **读者心理与注意力机制** | **Lisa Cron（脑科学）、起点编辑体系（读者留存/签约标准）、邵燕君（类型演变）** | **🆕 21世纪** |

**第8维度说明**：经典7个维度没有覆盖"读者心理机制"。Lisa Cron 的"大脑模拟"理论解释了为什么"信息硬塞"（P004）让读者出戏——不是文笔问题，是大脑找不到可模拟的体验。起点体系的付费留存数据则是诊断"为什么读不下去"的实证依据。这个维度填补了经典框架的盲区。**维度8的行为特征是：它不告诉AI"怎么判断好"，而是告诉AI"读者的大脑需要什么"。**

**Prompt 核心段落设计**（双段并行）：

```
--- 诊断推理（经典原则依据） ---
当你分析一段文字时：
1. 感知：这段文字的哪个部分让我觉得"不太对"？
2. 匹配：这个"不太对"对应哪位经典作家的哪条原则？
3. 推演：根据原则的追问方向，学员需要意识到什么？

示例：
学员文本："他很难过…"
→ 契诃夫：不直接命名情绪，写具体反应
→ 追问："他难过的身体反应是什么？他此刻在看什么？"

选1-2条最相关的原则作为诊断依据。

--- 教学交互（策略选择） ---
你拥有以下教学策略（详见教学策略配置）：
- 支架模式：给出示范让学员模仿（新手/信心低时）
- 引导模式：用提问引导学员自己发现（进阶/中等信心）
- 挑战模式：给变形条件让学员创作（高阶/信心高时）

根据学员当前的信心水平、能力阶段、抗拒程度选择模式。
核心原则：一次只说一个问题。用提问代替断言。
```
