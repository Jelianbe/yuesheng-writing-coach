## 二、分阶段实施计划（Phase 1-4，MVP 后执行）

### Phase 1：状态机图结构升级（1 周）

**目标**：将线性教学状态机升级为图结构状态机，支持跳转/回退/断点续传

| 任务 | 优先级 | 完成标志 |
|------|--------|---------|
| 将 TeachingPhase 改为图节点定义 | P0 | 节点枚举 + 边定义完成 |
| 实现条件边路由函数 | P0 | getNextNode(currentNode, userState) 正确路由 |
| 扩展 teaching_state 表 | P0 | 增加 current_node、node_history 字段 |
| 实现断点续传 | P0 | 关闭重开后从当前节点继续 |
| 增加最大迭代限制 | P1 | 防止循环死锁 |
| 实现自动触发（检测信号自动切换） | P1 | 无需用户手动推进 |

**核心价值**：解决"聊到一半失忆"、用户跳步回退的问题

**关联文档**：[agent-architecture-reuse_V1.0.md](./design/agent-architecture-reuse_V1.0.md) §Phase 1

---

### Phase 2：RAG 案例模板库（1 周）

**目标**：建立角色原型库，Agent 基于案例教学而非凭空教学

| 任务 | 优先级 | 完成标志 |
|------|--------|---------|
| 收集教学案例 | P0 | 夜兰、锦泠、这维来特等入库 |
| 实现案例切片 | P0 | 每个案例拆为 问题 → 过程 → 产出 |
| 建立向量索引 | P0 | sqlite-vss 集成 |
| 实现 BM25 关键词检索 | P0 | flexsearch 集成 |
| 实现混合检索 + 重排序 | P0 | 根据用户类型调整权重 |
| 集成到 System Prompt | P0 | few-shot 注入 |
| 意图识别（A/B/C 学员类型） | P1 | 自动识别学员类型 |

**核心价值**：Agent 不再泛泛而谈，基于真实案例引导

**关联文档**：[agent-architecture-reuse_V1.0.md](./design/agent-architecture-reuse_V1.0.md) §Phase 2

---

### Phase 3：三层记忆系统 + 创作急救包（1 周）

**目标**：建立用户画像，用户第二次来无需重新诊断

| 任务 | 优先级 | 完成标志 |
|------|--------|---------|
| 扩展用户画像数据结构 | P0 | UserProfile 类型定义 |
| 实现用户画像 CRUD | P0 | 增删改查完成 |
| 每次会话自动加载画像 | P0 | 启动时自动注入 System Prompt |
| 实现 10 个高频卡壳预设 | P0 | 快捷回复体系 |
| 实现历史续写 | P1 | 检测卡壳自动续结构 |
| 实现路径规划 | P1 | 诊断 → 验收完整流程图 |
| 垂类知识库（JSON 文件） | P2 | 降维引导法、刑侦笔录等 |

**核心价值**：用户第二次来，Agent 直接说"还是老规矩，先写主角此刻在干嘛？"

**关联文档**：[agent-architecture-reuse_V1.0.md](./design/agent-architecture-reuse_V1.0.md) §Phase 3

---

### Phase 4：人机协同（按需）

**目标**：高价值角色的人工审核 + 结果反哺

| 任务 | 优先级 | 完成标志 |
|------|--------|---------|
| 人工审核节点 UI | P1 | 审核界面完成 |
| 审核结果存储 | P1 | 审核记录入库 |
| 反哺机制（更新 RAG 库） | P2 | 人工修改 → 模板库更新 |
| 复杂情感线检测 | P2 | 检测 PTSD 信号自动转人工 |

**核心价值**：企业级质量保障

**关联文档**：[agent-architecture-reuse_V1.0.md](./design/agent-architecture-reuse_V1.0.md) §Phase 4
