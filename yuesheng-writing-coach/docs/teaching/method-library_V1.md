## 结构说明

每条策略包含：

| 字段 | 说明 |
|------|------|
| 策略名称 | 简短命名 |
| 适用场景 | 什么状态下使用 |
| 前置信号 | 检测到什么触发 |
| 核心逻辑 | 策略的"为什么这么做" |
| 执行动作 | 对应 action-library 中的动作编号 |
| 预期效果 | 用完后作者应该有什么变化 |
| 禁忌 | 什么情况不能用 / 用了会怎样 |
