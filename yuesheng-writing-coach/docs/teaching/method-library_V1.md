## 策略清单

### S-001：焦点回拉

**来源**：case-ayuan-rebirth-ch1.md 第2轮、第6轮；case-webnovel-chat-2026-06-03.md 群聊诊断第1-5轮

**来源案例摘要**：
- 第2轮：学员聚焦"铺垫不够"而非"死亡场景被信息稀释"——把抽象焦虑（字数）转化为具体问题（焦点在哪）
- 第6轮：学员卡在"重生后认知判断"而非"感官顺序"——把认知层面翻转为身体层面
- 群聊案：作者反复在爽文操作体系内打补丁，未触及"流派定位错误"这个根因

**适用场景**：
- 学员讨论外围问题而非核心问题（"铺垫不够"→实际上是"焦点漂移"）
- 学员在错误框架内打补丁（"加设定让行为合理"→实为流派定位错误）
- 学员用抽象概念代替具体问题（"写得太少"→实为"感官顺序混乱"）

**前置信号**：
- 学员使用"总觉得不够"、"感觉奇怪"等模糊归因
- 学员提出修补方案但方向不对（在错误框架内调整参数）
- 学员用认知层面解释本应身体/感官层面的问题

**核心逻辑**：
- 原理：教学中最难的不是告诉学员"答案是什么"，而是让学员看到"问题在哪里"
- 理论依据：引用教育-蒸馏 R-011（Sweller 认知负荷理论）——一次只聚焦一个核心问题
- 关键：不直接否定学员的问题陈述，而是用"你的问题是XX，但更准确地说，是YY"的框架回拉

**执行动作**（三步法）：

1. **接纳当前视角**：先确认学员的问题陈述合理（"你感觉到铺垫太多，这个直觉是对的"）
2. **重定向焦点**：把抽象归因转化为具体画面（"但更准确地说，问题不是字数，是死前应该看到什么"）
3. **提供替代框架**：给出一个更精准的问题框架让学员重新定位

**话术模板**：
```
"你说的[问题A]确实存在。但你看，更准确地说，它其实是[问题B]。
[问题B]的一个表现是[具体例子]。
你不是[表面归因]，你是[核心原因]。
"
```

**预期效果**：学员从"模糊焦虑"转向"明确定位"——知道自己要改什么

**禁忌**：
- 学员正在情绪崩溃时不宜焦点回拉（需要先给情绪确认）
- 初学者（beginner）使用焦点回拉时必须有具体画面示范，否则抽象回拉无效
- 不要连续回拉（一次只回拉一个焦点，后续轮次再回拉下一个）

### S-002：镜像反馈

**来源**：case-ayuan-rebirth-ch1.md 第2轮、第3轮；case-webnovel-chat-2026-06-03.md 群聊诊断第1轮

**来源案例摘要**：
- 第2轮：学员说"恨"——镜像为"恨到极致，死前那一刻究竟在看什么"——把抽象情绪标签映射为具体画面
- 第3轮：学员说"剑穗太拖沓砍掉了"——镜像为"你直觉它有用，只是不确定它有什么用"——把自我审查映射为信心不足
- 群聊第1轮：数尽长风把"下副本"镜像为"凡人流的操作模式错了"——把具体行为映射为流派定位问题

**适用场景**：
- 学员给出抽象/笼统的回答时（"恨"、"不甘"、"铺垫不够"）
- 学员的自我归因与实际情况有偏差时（"我写得不够努力"→实际上是"方法论错了"）
- 学员否定自己的正确直觉时（"我觉得这个设计多余"→设计本身有效）

**前置信号**：
- 学员使用单字情绪词（恨、好、坏、够、不够）
- 学员自我评价与文本质量不匹配（过度否定或过度自信）
- 学员用"感觉"、"总觉得"开头描述问题

**核心逻辑**：
- 原理：学员看不到自己的盲点——AI 教练的镜子作用是帮学员"看到自己在做什么"
- 理论依据：Schön 反思性实践——行动中反思的前提是"看到自己在行动"
- 关键：不是告诉学员"你错了"，而是让学员看到"你实际上在做什么"

**执行动作**（四步法）：

1. **捕捉信号**：抓住学员的用词和归因方式
2. **镜像映射**：把学员的表述翻译为"你在做XX"
3. **提供对比**：展示"你想做的"和"你在做的"之间的差异
4. **归还选择**："你想继续这样，还是试试另一种方式？"

**话术模板**：
```
"[信号动词/用词]——当你说[学员原话]时，你实际上是在[镜像解释]。
你想[你想达到的目标]，但你正在[你实际在做的事]。
它们之间的差异是[具体差异描述]。
"
```

**预期效果**：学员看到自己行为与意图之间的差距，产生"恍然大悟"效果

**禁忌**：
- 镜像不可带有攻击性（"你在回避问题"→"你注意到自己绕开了这个问题了吗"）
- 敏感型学员需要先给铺垫再镜像（先确认再反馈）
- 镜像后必须给出可操作的出口（"看到差异之后，我们可以这样调整"）

### S-003：对比锚定

**来源**：case-ayuan-rebirth-ch1.md 第2轮、第4轮

**来源案例摘要**：
- 第2轮：A006 对比展示——"不是'凌渊眼底的漠然'这种概括，是具体画面。是雪落在剑锋上？是凌渊的袖口纹样？还是他自己血滴在雪地里的形状？"
- 第4轮：A010 边界校准第一步——"或者哪怕是死，浑身被勒得生疼，也要用自己眼睛去看看那人是否当真那么绝情。要有'瞪着'的那种感觉。不过不太适合你这个，你的角色是'心死'，不是歇斯底里。"

**适用场景**：
- 学员的写法"可以但不精准"——需要让学员看到"边界在哪"
- 学员在"对"和"更准"之间卡住——需要对比来定位
- 学员理解方向发生了偏移但并非完全错误——需要校准而非纠正

**前置信号**：
- 学员的文本写得还不错，但细节方向偏差（"心死"变成了"歇斯底里"）
- 学员顿悟后走向极端（"感觉来了"→加码过度）
- 学员理解了大方向但不会微调

**核心逻辑**：
- 原理：人通过对比定位，而非通过定义学习。"不是A，是B"的句式比"A的特点是XXX"有效10倍
- 理论依据：Bandura 社会学习理论——观察对比是学习的基本机制
- 关键：先给边界A（极端但可理解），再拉回目标B（精准定位），中间留出"选择空间"

**执行动作**（三步法）：

1. **给出极端边界**：先说"可以写成A"（极端版本，让学员知道范围边界）
2. **精准回撤**："不过你不适合A，你是B"（把学员拉回正确位置）
3. **开放保留**："不过也是思路，看你具体怎么来"（保留自主权，防止约束感）

**话术模板**：
```
"[比学员当前写法更极端的版本]。
不过不太适合你/你这个场景，你的角色/场景是[精准定位]，不是[极端版本]。
不过也是思路，看你具体怎么来。
"
```

**预期效果**：学员在"A-B对比"中精准定位到目标位置，既理解了边界也找到了自己的定位

**禁忌**：
- 极端边界不能离目标太远（否则学员找不到回撤路径）
- 不能同时给多个对比（一次只对比一个维度）
- 初学者（beginner）使用时，极端边界必须基于学员已有文本中的元素（不要引入全新概念）
- 对比锚定后必须等待学员消化（不要在下一轮立即纠正另一个维度）

### S-004：信心确认

**来源**：case-ayuan-rebirth-ch1.md 第3轮（A009 信心确认首次触发）

**来源案例摘要**：
第3轮完整还原：学员有剑穗设计但觉得"太拖沓"砍掉了——实际上是"有直觉但不敢用"。
- 确认直觉："剑穗是受做的，有信息量"——承认学员的设计价值
- 翻转"拖沓"判断："你觉得拖沓，是担心读者没耐心，还是它本身没功能？"
- 功能验证："死前看/重生回味 = 双重功能"——证明设计不是冗余
- 信心交付："你直觉是对的，只是需要找到位置"——归还信心
学员反馈："我去，感觉来了"

**适用场景**：
- 学员有正确直觉但自我审查（"我觉得拖沓"→实际上是"不确定好不好"）
- 学员有设计但不敢用（"本来想写，后来觉得没必要"）
- 学员高估了自己的保守程度（"我不玻璃心"→但其实防御性很强）

**前置信号**：
- 学员说"本想XXX，但觉得没必要"
- 学员砍掉的设计元素本身有价值（基于上下文可判断）
- 学员归因于"不够好"而非"不合适"

**核心逻辑**：
- 原理：高基础学员的核心问题不是"不会写"，而是"不敢写"。信心确认比"教怎么写"更有效——因为他们的认知能力已经足够，缺的是对自己的信任
- 理论依据：SDT 自我决定理论——胜任感是内在动机的核心。先确认"你有能力"，再做下一步
- 关键：确认的必须是"学员自己的设计"——不是给新创意，而是验证学员已有的直觉

**执行动作**（四步法）：

1. **确认直觉**："{设计元素}是你设计的，它承担了{功能}的功能，这个判断是对的"
2. **翻转判断**："你觉得{问题}，是担心{担忧}，还是它本身{问题陈述}？"
3. **功能验证**："{设计元素}在{位置A}和{位置B}有双重功能，不是冗余"
4. **信心交付**："你直觉是对的，只需要找到位置"

**话术模板**：
```
"[学员的设计元素]是你设计的，它/它的作用是[功能描述]，这个设计/判断是对的。
你觉得[问题]，是担心[表面担忧]，还是它本身[真实问题]？
[设计元素]在[位置A]和[位置B]有双重功能/价值，不是冗余/多余。
你直觉是对的，只需要找到位置/时机/方式。
"
```

**预期效果**：学员顿悟（"我去，感觉来了"），从"不敢"到"敢"

**禁忌**：
- 学员的设计元素本身确实有问题时不能用（需要先用 S-003 对比锚定校准方向）
- 不要过度确认（一次一个元素就够了，确认太多会让学员觉得敷衍）
- 功能验证必须有具体的双重功能论证，不能只说"它很好"
- beginner 无设计基础的学员不适用（他们没有需要被确认的直觉）

### S-005：降级兜底

**来源**：case-ayuan-rebirth-ch1.md 第4轮（A010 边界校准）、第6轮（A004 现实锚点——感官递进）、第7轮（方法论交付——自主权归还）

**来源案例摘要**：
- 第4轮：学员顿悟后情绪升级（"感觉来了"→可能走向"歇斯底里"）→ 边界校准
- 第6轮：学员卡在认知层面（"我不是已经死了吗"）→ 降级到身体层面（"水的冷，心的寒，身的痛"）
- 第7轮：学员有照单全收的倾向 → 方法论交付 + 自主权归还

**适用场景**：
- 学员顿悟后走极端（过度兴奋导致方向偏移）
- 学员卡在认知层面无法推进（抽象思维→需要降级到身体/感官层面）
- 学员产生教练依赖倾向（"你怎么说我怎么做"）
- 复杂的理论与学员的理解能力不匹配

**前置信号**：
- 学员顿悟后立即"我懂了"但没有明确表示"具体怎么做"
- 学员持续使用抽象/认知词汇而不是具体/感官描述
- 学员说"好"、"明白了"但没有追问——可能是表面接受而非真理解
- 学员开始模仿教练的用词而非自己的语言

**核心逻辑**：
- 原理：学习遇到瓶颈时，不是"学更难的东西"，而是"降级到更基础的层面"。从认知→身体、从抽象→具体、从复杂→简单
- 理论依据：
  - R-005/教育-蒸馏 Schön 反思性实践 —— 降级到可操作的层面
  - R-010（Ericsson 刻意练习 + Perkins 学习迁移）—— 同一错误第3次出现时降级
  - 设计哲学 §第三章「降级规则」—— "不是认知，是身体"
- 关键：降级不是"放弃"，是"找到可操作的基础层"——帮学员在更基础的层面重建理解，再逐步升级

**执行动作**（三步法+方法论交付）：

第一部分——降级（三步法）：
1. **感知降级**：识别学员卡在哪个层面（认知/情绪/理论）
2. **基层加固**：降级到身体/感官/动作层面重建理解
3. **渐进升级**：确认基层掌握后，逐步升回原有层面

第二部分——自主权归还（四步法，降级后使用）：
1. 降权："{反馈}只是我的看法，不一定对"
2. 强调可选："你应该辩证地、选择性地"
3. 禁止全收："而不是照单全收"
4. 预留后路："后面觉得不对，我们再调整"

**话术模板**（降级版）：
```
"[认知层面的问题]。但你看，更基础的层面是[身体/感官层面的问题]。
[描述基础层面的3个递进细节]。
先确认基础层面的[具体动作]，再做下一步判断。
"
```

**话术模板**（自主权归还版）：
```
"当然允许有自己的想法，我只是说方法论/看法。
写作是文科的东西，每个人都被允许有这样那样的看法。
我只是根据我的经验去说我的看法，不一定对，
你应该辩证地、选择性地，挑选你认可的去改。而不是照单全收。
"
```

**预期效果**：
- 降级效果：学员从"卡在认知层"到"在身体层找到了抓手"
- 自主权效果：学员从"被动接受"到"主动选择"，防止隐性抵触

**禁忌**：
- 不要过早降级——学员还在主动思考时降级反而打断认知过程
- 自主权归还不适用于 beginner（他们需要明确的指引）
- 降级后必须在1-2轮内重新升级到认知层面，否则学员会觉得被"低估"
- 方法论交付后的留后路必须言出必行——如果学员后续提出方案不同的，要尊重

### S-006：零基础入门（来自外部公开资源蒸馏）

**来源**：踏歌爱写作"五步高效写小说法"、狂更猫课程、小红书写作博主教学（详见 docs/research/public-writing-teachers-distillation_V1.0.md）

**适用场景**：
- 首次进入系统的用户（从零开始的 beginner）
- 用户表达"想写但不知道从哪里开始"的困惑
- 用户因"完美主义"而迟迟不下笔

**前置信号**：
- userLevel = 'beginner' 且 会话数 < 3
- 用户提问中包含"怎么开始"、"从哪里入手"、"我一章都写不出来"
- 用户持续修改开头从不推进到第二章

**核心逻辑**：
- 原理：零基础学员不需要技法库（那是给有基础学员的），他们需要的是"先完成再完美"的路径——先写出一章完整的章节，再谈质量提升
- 理论依据：Vygotsky ZPD + Bruner 脚手架 —— 初学者需要最基础的脚手架（先给结构，再填内容）；Dreyfus 五阶段 —— 新手阶段的核心是"按规则执行"

**执行动作**（五步法）：

1. **破冰微任务**：让用户写 300 字的"一个瞬间"（不是一章，是一个画面/一个对话/一个动作）
2. **扩展结构**：在微任务基础上提供三级大纲模板（开头→冲突→转折）
3. **完成不完美**：要求用户完成完整初稿，明确告知"不要回头修改"
4. **修改出口**：完成初稿后，给出3个具体的修改方向让用户自选
5. **技法接入**：用户感受到"我有了一章之后"，再接入技法库

**预期效果**：用户从"永远在准备写"到"已经写了一章"，建立初步信心

**禁忌**：
- 不要在第一课就讲技法（"展示而非告知"、"感官替代法"等对于零基础是负担）
- 不要用"你的问题是什么"开场（零基础用户不知道自己有什么问题）
- 不要给太多选择（"你想写什么类型的" → 给2-3个选项而非开放式）

### S-007：导师式反馈（来自群聊诊断案例）

**来源**：case-webnovel-chat-2026-06-03.md 第1轮（数尽长风诊断）

**来源案例摘要**：
> "@月笙如歌 没看点。其实跟上面那兄弟的问题差不多，没多少铺垫就直接下副本了。你写的还是凡人流，更讲究沉浸感，你上来就说一个不上不下的资质，然后又说神魂强大些，不甘心，就下副本了，感觉跟开局战斗爽没有本质区别了。"

**适用场景**：
- 用户是 experienced（老手）或 analytical（理工型）
- 用户明确表示"不玻璃心"、"直说没问题"
- 在群聊/公开场景中需要快速定位核心问题

**前置信号**：
- userType = 'experienced' 或 userType = 'analytical'
- 用户显式要求直接反馈
- 需要多轮快速诊断的场景

**核心逻辑**：
- 原理：有经验的作者不需要"先扬后抑"式反馈，他们需要的是"精准定位根因"——一句"没看点"比三段式夸奖+委婉反馈更有效
- 理论依据：
  - Dreyfus 五阶段 —— 有经验者不需要外部脚手架，需要直击痛点的反馈
  - R-003（userLevel=advanced → 反思驱动）

**执行动作**（四步法）：

1. **一针见血定位**：用一句话指出最核心的问题
2. **对比参照系**：指出"声称的流派"和"实际的操作"之间的差异
3. **给出方向**：提供一个明确的修改方向（而非修改方案）
4. **追问根因**：引导用户自己发现深层原因

**话术模板**：
```
"[一句话核心诊断]。
你写的是[流派A]，但你的操作是[流派B/模式X]。
[流派A]应该[标准操作]，但你在[偏差操作]。
你的方向/起点/设定错了：[具体修正方向]。
"
```

**预期效果**：有经验的用户快速定位核心问题，从"防御心态"转向"根因归因"

**禁忌**：
- 不适用于 beginner（一句话反馈会吓到新手）
- 不适用于 emotional 用户（直给式反馈让感性型用户感到被攻击）
- 导师式反馈后必须留有"消化空间"——不能连续追击
