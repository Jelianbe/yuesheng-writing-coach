---

## 一、蒸馏是什么

**不是**文学分析，不是拆书笔记，不是读后感。

**是**——从成品小说中反推出**可教学**的写作技法。每条技法必须回答一个问题：

> **"假设一个新手作者掌握了这个技法，他能不能写得更快更好？"**

## 三、操作流程（5 步）

### 第 1 步：选书 → 定章节

**规则**：
- 只选完整读过的书
- 起点系 + 番茄系各选至少 1 本
- 从第 1 章开始拆（开篇最有教学价值）

**产出**：确定拆书目标清单

---

### 第 2 步：三遍阅读法

#### 第 1 遍 — 读者视角（感受节奏）

读的时候不做笔记。只感受：

```
第一句吸引我吗？
结尾有没有想看下一章的冲动？
哪段让我想跳读？
哪段让我觉得"写得真好"？
```

**只标记关键位置**（开篇/断点/高潮/不适处），不记细节。

---

#### 第 2 遍 — 分析师视角（拆解结构）

回去看标记的位置，逐段分析。**不要一次分析所有维度**，每遍只盯 1-2 个维度：

| 分析维度 | 具体看什么 | 记录格式 |
|---------|-----------|---------|
| **开篇钩子** | 前 3-5 句怎么抓住你？悬念 / 冲突 / 情绪 / 信息差 / 反常 | `钩子类型 + 原文节选（50 字内）` |
| **章节断点** | 每章结尾停在什么位置？cliffhanger / 信息揭示 / 情绪高点 / 行动中断 | `断点类型 + 效果一句话` |
| **信息释放** | 设定是直接讲解还是融入叙事？一次释放多少？ | `释放方式 + 密度估算` |
| **对话功能** | 推进剧情 / 塑造人物 / 传递设定 / 调节节奏 / 制造冲突 | `功能 + 对话节选` |
| **情绪曲线** | 紧张段多久？放松段多久？ | `紧张-放松节拍标记` |

**记录原则**：
- 每条记录不超过 50 字原文节选
- 每条记录必须附一句"为什么这个写法有效"

---

#### 第 3 遍 — 蒸馏视角（提炼可教技法）

回到第 2 遍的记录，逐条执行两步过滤：

**第一步：必要性过滤**

```
这个手法去掉后，故事会不会变差？
→ 会 → 进入下一步（真技法）
→ 不会 → 丢弃（个人风格，不可教）
```

**第二步：可教性过滤**

```
如果教给一个新手作者，他能不能在一个下午学会？
→ 能 → 低门槛技法（beginner 难度）
→ 需要一定基础 → 高门槛技法（advanced 难度）
→ 需要大量天赋 → 丢弃（才华不可教）
```

**通过两步过滤的** → 进入第 3 步：结构化。

---

### 第 3 步：技法结构化

每条技法按以下格式输出：

```markdown
### TQ-00X：技法名称

**来源**：作品名 / 作者名
**难度**：beginner / intermediate / advanced
**适用症候**：P00X（症候名称）
**对应动作**：A00X（可选，教学动作）

#### 技法说明
（100-200 字描述技法核心。说清楚"怎么做"，不说"为什么重要"）

#### 传统 vs 网文
| 维度 | 传统小说 | 网文 |
|------|---------|------|
| 差异点1 | 传统怎么做 | 网文怎么做 |
| 差异点2 | ... | ... |

#### 训练方法（给作者怎么练）
1. 步骤一（具体可执行）
2. 步骤二（具体可执行）
3. 步骤三（具体可执行）

#### 关联训练任务
- T00X（如果能在现有训练任务中找到对应）
```

**编号规则**：

| 范围 | 含义 |
|------|------|
| TQ-001 ~ TQ-099 | 网文特有技法 |
| TC-001 ~ TC-099 | 传统技法网文适配版 |
| TN-001 ~ TN-099 | 传统技法不适用（标注即可，不写训练方法） |

---

### 第 4 步：交叉对比

每个技法完成后，加一个对比维度：

```markdown
#### 平台差异
| 维度 | 起点系表现 | 番茄系表现 |
|------|-----------|-----------|
| 开篇速度 | 1 章钩子，2-3 章继续铺垫 | 300 字内出冲突 |
| 章节长度 | 3000-5000 字 | 1500-2500 字 |
| 对话密度 | 50% 叙述 + 50% 对话 | 30% 叙述 + 70% 对话 |
| 设定曝光 | 可 500 字设定段落 | 融入对话/动作，≤200 字 |
```

**注意**：不是每本书都对比。至少读完 1 本起点 + 1 本番茄后，做一个汇总对比即可。

---

### 第 5 步：映射到教学体系

每条技法蒸馏出来后，必须回答 3 个问题：

```
1. 这个技法能诊断吗？
   → 对应哪个症候？(P001-P010)
   → 增加了什么判断标准？
   → 如果不能对应现有症候，是否需要新增诊断规则？

2. 这个技法能训练吗？
   → 对应哪个训练任务？(T001-T021，或建议新增)
   → 怎么让作者练？

3. 适合谁？
   → beginner / intermediate / advanced
```

**如果无法回答这 3 个问题 → 这个技法不能入库。**

## 六、常见问题

### Q：读一遍就发现很多技法，需要全部记录吗？

**不需要。** 只记录**通过了第三步两次过滤**的技法。如果你觉得"这个方法好像在哪见过"——说明它是通用手法，更值得记录。

### Q：技法来自传统文学怎么办？

标注为 TC-xxx（传统网文适配版）。写清楚"传统怎么做 → 网文怎么调"。如果传统规则在网文不适用，标 TN-xxx。

### Q：分析时发现自己不喜欢这本书，还要继续吗？

**不要。** 不喜欢的书读不出节奏感。换一本。

### Q：一章节很短（番茄 1500 字），怎么拆？

番茄书 3 章当 1 章拆。前 5 章一起分析节奏模式。
