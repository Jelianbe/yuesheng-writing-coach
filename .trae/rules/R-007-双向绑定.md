# R-007: 双向绑定

## 原则
所有数据变更必须保持一致性，前端显示与后端存储必须保持同步。

## 核心要求
1. **数据驱动** - UI 变化源自数据变化
2. **状态同步** - 前后端状态始终保持一致
3. **变更传播** - 数据变更必须正确传播到所有依赖方

## 实现方式
- **前端状态管理**: 使用 Zustand，确保状态变更的原子性
- **数据持久化**: 数据变更时通过 IPC 同步到 electron-store 或 SQLite
- **UI 同步**: 使用 React 的响应式更新机制

## 检查清单
```
数据变更后检查：
□ 前端UI是否正确更新？
□ 后端存储是否正确保存？
□ 相关组件是否收到通知？
□ 是否存在状态不一致？
```

## 常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| UI未更新 | 状态变更未正确触发 | 使用 immer 等不可变数据工具 |
| 数据不一致 | 异步操作时序问题 | 使用事务或队列机制 |

## 优先级
中优先级 - 保障用户体验和数据一致性
