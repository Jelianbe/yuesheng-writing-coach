# R-013: 测试覆盖率要求

## 原则
所有代码改动必须通过已有基线测试，新增功能至少覆盖一条测试用例。

## 当前可执行检查
### 每次改动必须执行
- ✅ 已有基线测试全部通过（`npx vitest run`）
- ✅ TypeScript 类型检查通过（`npx tsc --noEmit`）
- ✅ 无全新编译报错

### 新增功能建议执行
- ✅ 至少 1 个单元测试覆盖核心逻辑
- ✅ 测试数据不依赖线上环境（如 API Key）
- ✅ Mock 外部依赖（如 AI API 的 HTTP 请求）
