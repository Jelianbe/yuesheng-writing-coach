# R-011: 记忆强化

## 原则
关键决策必须被记录，确保不会因时间推移而遗忘。

## 记录位置
统一记录在 `docs/decision-log.md`（关键决策日志）

## 记录格式
```
- 日期: YYYY-MM-DD
- 类型: 决策/变更/问题
- 标题: 简洁描述
- 决策: 做了什么
- 原因: 为什么这样做
```

## 必须记录的场景
- 技术选型决策
- 架构调整
- 诊断引擎算法变更
- API 集成方式变更
- 重要的 Bug 修复方案

## 检查清单
```
关键操作后检查：
□ 是否记录了决策原因？
□ 是否更新了决策日志？
□ 是否对后续开发有参考价值？
```

## 优先级
中优先级 - 保障知识积累和项目可维护性
