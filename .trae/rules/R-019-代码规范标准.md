description: "全项目统一的代码质量标准，防止硬编码、提升可维护性、确保类型安全。依据 docs/standards/CODE_STANDARDS_V1.0.md。"
alwaysApply: true
priority: "high"
trigger:
  - "所有代码变更"
  - "代码审查"
  - "新功能开发"
  - "代码重构"
  - "Bug修复"
checkLogic:
  - "无 any 类型，使用 unknown 或具体类型替代"
  - "无 @ts-ignore，必须处理类型错误"
  - "所有 IPC handler 必须有 try/catch 和错误返回"
  - "无魔法数字（除 0, 1, -1），必须提取为具名常量"
  - "无硬编码字符串如路由路径、配置值，必须提取为常量"
  - "主进程 Service 不应直接 import { app } from 'electron'，应构造函数注入"
  - "函数不超过 50 行，文件不超过 300 行"
  - "所有 IPC 调用必须有错误处理和加载状态"
  - "无 export default，使用具名导出"
  - "变量/函数 camelCase，常量 UPPER_SNAKE_CASE，类/接口 PascalCase，文件 kebab-case"
  - "IPC 通道命名使用 domain:verb 格式如 'diagnosis:analyze'"
enforcement: "TypeScript 编译检查 + 代码审查拦截。无 ESLint 规则时由人工审查，启用 ESLint 后自动拦截。P0 级别（无 try/catch、无 any 类型）变更将被标记为不合规。"
