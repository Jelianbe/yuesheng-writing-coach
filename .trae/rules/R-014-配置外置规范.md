# R-014: 配置外置规范

## 原则
所有静态词表、映射表和常量必须有来源注释。禁止新增 A→B 业务映射表。阈值必须外置到配置文件。

## 当前可执行的核心要求
1. **不建新映射表**: 禁止新增任何"A→B"形式的静态映射表
2. **来源可追溯**: 任何保留的静态集合必须有明确来源注释
3. **未知优于误判**: 置信度不足时返回"未知"，不要强行匹配

## 标准注释模板
```typescript
/**
 * CONSTANT_NAME
 *
 * 用途：[这个常量用来做什么]
 * 来源：[基于什么文献/统计数据/教学案例]
 * 边界：[哪些应该/不应该往里加]
 * 更新日期：[YYYY-MM-DD]
 */
const CONSTANT_NAME: Type = { '...' }
```

## 禁止类
| 类型 | 示例 | 替代方案 |
|------|------|---------|
| A→B 业务映射表 | `{'三人': 'GROUP:3'}` | 正则+数量提取/规则匹配 |
| 经验型阈值 | `if score > 0.5:` | 必须外置到配置文件 |
| 病症→动作硬编码 | `{'P001': 'A001'}` | 使用配置驱动的映射 |

## 检查清单
```
新增常量前检查：
□ 是否可以用动态计算/规则引擎替代？
□ 是否有明确的来源？
□ 是否违反"不建新映射表"原则？
□ 如果是阈值，是否已外置到配置文件？
```
