# 月笙写作教练（Yuesheng Writing Coach）

> AI 驱动的中文小说写作辅导工具 · **写作教练，不是写作助手**

月笙写作教练面向中文小说写作者，**不替你写句子，也不替你做创作决策**——而是通过「诊断 → 教学 → 训练 → 复盘」的闭环，帮你识别写作中的系统性问题，并提供针对性训练。

**定位**：不生成内容，只提升能力。

### 下载地址

⚠️ **请以下载入口（项目落地页）为准。** 两个通道的状态要分开看：

- **项目落地页**：当前正式版 APK 的实际下载入口。
- **GitHub Releases**：**状态未验证**。写这份文档时未能登录 GitHub，**无法确认**现存 Release
  是否包含当前应用的安装包；你在 Releases 里看到的版本**可能仍属于早期原型**，
  与现在的手机应用不是同一个东西。**请勿假定 Releases 可以直接下载。**

> **覆盖安装前先看版本**：正式版与调试版（`flutter run` 装的、图标带 D 角标）**签名不同**，
> 签名不一致时 Android 会拒绝覆盖并报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`。
> 遇到这种情况的处理方式（含数据是否会丢的提醒）写在 `CHANGELOG.md` 对应版本条目里。

**两点须知**

- **自带密钥（BYOK）**：需自备一家大模型服务的 API Key。应用**不内置密钥**，也**不经任何中转服务器**。
- **稿件不出手机**：小说草稿、诊断结果只写入本机数据库，不上传。

**首次配置步骤（装好之后怎么让它动起来）**

1. 打开应用，进底部标签「成长」，在页面的快捷入口区点「设置」。
2. 在「AI 账号」区新建账号：应用内置六家服务预设——DeepSeek、OpenAI、Kimi（月之暗面）、通义千问、智谱 GLM、豆包（火山方舟）；也支持自填兼容的 API 地址（baseUrl）。
3. 填入你在所选服务商官网申请的 API Key，点「测试连接」确认通了，保存。
4. 把该账号「设为默认」——应用同一时间只使用一个默认账号。

密钥本身只存进本机加密存储（不上传、不中转）；这一点和上面「两点须知」一样，源码可查。

> 你不需要「相信」上面两条 —— 这正是源码公开的原因：
> 手机应用是个黑盒，源码是唯一能让你（或任何人）自己验证「怎么说就怎么做」的通道。

## 核心能力

- **五阶段教学状态机**（P0 初始 → P1 教学 → P2 训练 → P3 评估 → P4 复盘）驱动对话流程
- **诊断引擎**：分析写作片段，识别症候并排序（当前注册表 41 条，P001–P041）
- **五步训练流**：解说 → 例证 → 确认 → 尝试 → 反馈，配套写作技法库按症候动态填充
- **能力图谱与训练推荐**：基于诊断结果推荐针对性训练，支撑进度追踪
- **学生模型**：基于本地数据库（drift/SQLite）的学习画像，记录诊断历史与训练进度
- **症候跨轮次历史引用**：诊断卡可回溯历史表现，标注好转或复发的进展

## 质量门禁

开发流程内置一整套质量门禁，`bash scripts/gate.sh` 一键全跑。

> **本文不复述门禁道数与用例数。** 按 `CONTRIBUTING.md` 的约定
> （「不要在本仓任何文档里复述会漂移的数字」），一切以脚本实测为准 ——
> 本节原写「六道门禁 / 2600+ 用例」，两个数都已漂移。

门禁覆盖的方面（**增删以 `scripts/gate.sh` 自身为准**）：

- 代码格式（`dart format`）
- 静态分析（`flutter analyze`）
- 全量测试（`flutter test`）
- 循环依赖检查
- 安全 / 密钥扫描
- R-019 函数行数硬上限
- 其余：覆盖率、prompt 反模式、内容元数据、交互回归、伪拆分检查、A 类豁免
